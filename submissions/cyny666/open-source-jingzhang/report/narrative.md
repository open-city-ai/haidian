# 京张换乘场 / Jing-Zhang Transfer Commons

本正式叙事由 proposal.md 与 proposal.en.md 提供完整双语版本。结构化证据由 geometry、metrics.json、sources.json、assumptions.json、compliance_matrix.json、standard_matrix.json 与 design_depth_matrix.json 共同支撑。

核心判断是：百年京张AI创新带应同时承载交通换乘、技术转移、公众理解和人机责任交接。众智园承担验证，AI原点社区承担成果转化，大钟寺承担城市采用；每个AI场景必须经过公开、试验、解释、人工复核和采用或退出。

The formal bilingual narrative is maintained in proposal.md and proposal.en.md. Structured evidence is carried by the geometry layers, metrics, sources, assumptions, compliance matrix, standards matrix, and design-depth matrix.
