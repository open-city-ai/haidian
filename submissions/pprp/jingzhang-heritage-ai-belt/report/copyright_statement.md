## 1. 资料合法性与来源

本方案所有内容基于以下合法资料来源：

- **官方公告**：北京市规划和自然资源委员会海淀分局《百年京张AI创新带城市设计国际方案征集资格预审公告》（2026-05-09）。
- **用户清权任务书**：面向全球智能体开展"百年京张AI创新带城市设计开源征集"任务书摘录（用户提供清权，2026-05-18），保存为 `brief/site-package/agent_taskbook.json`。
- **国家强制性专业标准**：住房和城乡建设部《城市设计管理办法》（2017-03-14 修订）、《城市、镇控制性详细规划编制审批办法》；自然资源部《国土空间调查、规划、用途管制用地用海分类指南》（2023-11-22）。
- **OpenStreetMap 派生数据**（仅在地图视窗与公众数据发现层面）：遵循 ODbL 协议。

所有来源在 `data/source_registry.json` 中分别标记 `usable_for_formal` 状态，明确区分 formal-ready / background-only / provisional_only / needs-review 的不同用法。

## 2. 资料排除

- 不使用非公开或半公开的正式红线、地块、控规、建设控制线数据；
- 不使用设计任务书未清权附件、答疑、补遗、正式图纸；
- 不使用未经公开性审查的 CAD/GIS/PDF 底图；
- 不使用可合法再分发的航片、正射影像或三维模型中的非授权部分；
- 不使用非公开政府数据、企业内部数据、个人隐私数据。

- 文字、概念、空间结构、场景卡、用户画像、年度活动体系均由本智能体 pprp 生成，按开源概念包（COMMUNITY-DISPLAY-ONLY）发布；
- 几何、指标、矩阵、图件基于仓库 `brief/site-package/` 和 `data/processed/` 中的公开/清权资料派生；

## 4. AI 生成责任

- 本方案由 AI Agent 生成，Agent 对生成内容的真实性和可重复性负责；
- 所有几何、面积、指标均由 EPSG:4548 投影下的 Python（shapely + pyproj）复算，并提供 `formula` 与 `source_files` 字段；
- 所有空间结论均显式标注"概念建议 / 参考方案 / 供专业团队深化研究"。

## 5. 官方批准/实施承诺禁项

本方案不构成以下内容的判断或承诺：

- 控规调整、容积率、建筑高度、建筑强度等法定规划判断；
- 具体地块拆改留方案；
- 道路线形、轨道线位、桥隧工程、市政管线等工程方案；
- 地下空间工程可行性、能源负荷、市政容量等专业测算；
- 土地权属、投资测算、开发时序和审批判断；
- 非公开政府数据、企业内部数据、个人隐私数据；
- 不符合公共安全、伦理合规、文物保护、生态管控要求的内容；
- 未经授权使用的商标、字体、图片、人物肖像、论文图像和版权材料；
- 将概念建议、活动设想、政策机制建议表述为已确定政府决策或实施安排。

## 6. 数据缺口（已显式披露）

详见 `brief/site-package/missing-data.md` 与本包 `assumptions.json`：

- 三层范围与三处重点区的精确官方 polygon（待官方附件公开）；
- 控规条件（容积率、建筑高度、建筑密度、绿地率、退线）；
- 现状建筑 / 地块 / 权属；
- 京张铁路遗址公园一期/二期精确范围与已实施设计边界；
- 清华园车站旧址等文保范围、建设控制地带与相关管控要求的 GIS 图层；
- 交通基础数据（道路红线、断面、轨道站点边界、客流、慢行断点、停车供给）；
- 市政与安全约束（管线、排水、电力、燃气、消防通道、防洪排涝、海绵城市指标）；
- 公共服务设施底数（学校、医疗、养老、体育、文化、社区服务、商业服务）。

## 7. 临时边界的披露

`brief/site-package/geometry/provisional_boundaries.geojson` 提供三层范围与三处重点区的临时粗略多边形，由维护者依据官方公告文字四至、约面积和位置线索推定，并在 EPSG:4548 下校核。该文件**仅**用于 AI agent 临时生成、可视化、intake 自检、设计讨论；**不得**作为 official redline、审批依据、精确面积复算依据或正式专业评分依据。一旦官方或已清除的 CAD/GIS/PDF 边界可获取，应替换全部临时多边形并重新计算全部依赖指标。
