# 版权与生成方法声明

## 一、成果生成方式

本提交包（人字带 SWITCHBACK · 百年京张AI创新带城市设计概念方案）由声明的 AI 智能体
（`agent.json` 中登记为 Claude Opus 5，提交者 GitHub 账号 shiwenbin1617）生成。

- 全部 GeoJSON 图层由自有脚本从 `brief/site-package/geometry/provisional_boundaries.geojson`
  剖分与派生，未使用任何第三方空间数据文件。
- 全部指标由同一批几何在 EPSG:4548 下复算，公式、来源文件与置信度写入 `metrics.json`。
- `assets/figures/` 下的五张图纸、`drawings/` 下的 A3 文册与 A0 展板、`visual/index.html`
  均由自有绘图与排版脚本生成，未使用任何外部图库、模板或素材站资源。
- `proposal.md` 由智能体撰写，`report/proposal.html` 由仓库脚本 `scripts/render_proposal_html.py`
  从 `proposal.md` 渲染。

## 二、资料来源与授权状态

| 资料 | 来源类型 | 授权状态 | 使用边界 |
| --- | --- | --- | --- |
| 征集资格预审公告 | 官方公开 | 公开发布 | 任务、范围与面积的第一依据 |
| 面向智能体开源征集任务书摘录 | 用户提供且已清权 | 仓库内登记 | 六项必答任务与共创公约依据 |
| 项目资料包（枚举、模式、区间） | 官方公开 | 仓库内登记 | 分类口径与校验依据 |
| 公开资料可用性登记表 | 仓库公开登记 | 仓库内登记 | 证据选择的可用性判断 |
| 临时粗略边界与重点区域几何 | 智能体依据公开资料推导 | provisional_only | 仅用于概念生成、可视化与自检 |
| 全球创新街区案例 | 公开常识性背景 | background_only | 仅作定性参照，不含任何数字 |

详细登记见 `sources.json`，限制条件见 `assumptions.json`。

## 三、未使用的素材类型（明确排除）

本提交包**未**使用：未清权的字体文件、商标与企业标识、人物肖像、论文插图、
新闻图片、卫星影像截图、地图服务瓦片、第三方渲染图、社交媒体素材、
未获授权的政府数据、企业经营数据与个人隐私数据。

图纸中的中文字符使用渲染环境的系统字体渲染为位图，字体文件本身不随提交包分发，
不构成字体再分发行为。

## 四、离线与安全声明

`visual/index.html` 与 `report/proposal.html` 均为离线静态页面：不加载远程脚本、
远程样式、远程字体、地图瓦片、iframe、表单提交、外部 API，也不包含任何追踪代码；
页面中的图片全部为提交包内的本地相对路径。
