## Rights and provenance ledger

### Fonts
- **Proposal figures (PNG)**: rendered using system fonts available on the generation machine — Microsoft YaHei (msyh.ttc) / SimHei (simhei.ttf), licensed under the operating system. No font files are embedded in the submission; glyphs are rasterized into PNG images.
- **A3/A0 PDFs**: Chinese text rendered via Microsoft YaHei / SimHei TTF registered with reportlab at generation time. The font is NOT embedded in the PDF (reportlab subset embedding); if the PDF is viewed on a system without these fonts, CJK glyphs may not display. For production printing, embed a properly licensed CJK font.

### Images
- All 5 proposal figures (`assets/figures/*.png`) are generated from the submission's own GeoJSON and metrics by the AI agent using PIL/Pillow. No external images, stock photos, or third-party copyrighted images are used.
- The visual/index.html inline SVG is rendered from the submission's own GeoJSON geometry.

### Logo and visual identity
