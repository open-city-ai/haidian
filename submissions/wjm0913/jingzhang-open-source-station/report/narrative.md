# 京张开源驿站 - 摘要

一处约240平方米的原点站先试90天，只验证公共价值、可追溯、无障碍、人工接管和可维护；通过四道门后，才研究向众智园验证型和大钟寺服务型节点复制。方案默认不拆、优先既有空间、可逆改造、不虚构造价或审批。

# Jing-Zhang Open Source Station - Abstract

Start with one approximately 240 sqm Origin station for 90 days. Test public value, traceability, accessibility, human takeover and maintainability. Only after four gates are passed should a verification type at Zhongzhiyuan and a service type at Dazhongsi be studied. The default is no demolition, existing space first, reversible fit-out and no invented budget or approval.
