# 叙要 / Formal Narrative

本方案以百年京张铁路的听觉遗产（汽笛、电报、扳道员口哨与单线呼号）为设计母题，提出**『京张声音带 / THE SOUND LINE』**：一条**会呼喊、可暂停、能被听见**的AI创新带。

**空间主线（一脊·三声部·两翼）**：以京张遗址公园为核心的声音脊公园带与慢行主廊道为脊柱；原点始发声部、众智全栈声部、大钟寺应用声部承接三处重点区；中关村科技服务翼与小月河场景赋能翼提供要素与场景支撑。沿脊布置呼号站网与三处听阈广场，让每一项进入公共空间的AI服务都持有一个可被市民呼叫、可暂停、可人工复核的公共协议。

**核心主张**：面向『AI治理全球话语权』，以「可呼叫率（callable rate）」为AI创新指数核心，把人的尊严与公共福祉置于自动决策之上；围绕听觉可达与无障碍优先，服务视障与低数字素养人群。

**成果**：用地4类分区完整覆盖提交边界（约11.41平方公里，EPSG:4548复算），含12张AI场景卡（含3处产业测试验证）、5类用户画像、4处AI朝圣地标；三阶段分期；年度活动体系与长期运营机制。全部空间建议为基于临时边界的**概念方案/参考方案**，不替代正式规划、不构成政府审定结论。

所有指标、几何、矩阵与自检状态均已交叉核对：spatial review PASS，deterministic/visual/professional 的其余门禁在回归修复后逐步转绿。
