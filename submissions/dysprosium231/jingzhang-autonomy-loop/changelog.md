# 方案迭代记录

## v1.0 - 2026-08-10

首次提交《百年京张·自主回路》完整 formal 方案包。

**设计内容**

- 提出总体概念"自主回路"与命名体系三级规则（带级／节点级／事件级），Logo 方向以人字形折返线闭合为回路的单笔画母题。
- 建立"一脊·三区·两翼·三回路"空间结构：京张遗址公园作为 9720.685 米变宽学习脊，三处重点区处放宽至约 300 米、连接段收窄至约 140 米。
- 三处重点区各按"定位—空间结构—建筑更新—交通慢行—公共空间—AI场景—实施风险"七段展开。
- 形成 12 张 AI 场景卡（含 4 个产业测试验证场景）、6 类用户画像、3 处朝圣地标与荣誉展示体系、9 个更新项目、6 个国际案例机制对照。

**数据与几何**

- 用地剖分由脊线多边形与横向分段线切分生成，30 个用地面完整覆盖提交边界，生成时缺口 0 平方米、重叠 0 平方米。
- 全部空间指标在 EPSG:4548 下复算，并与 `scripts/spatial_review.py` 的独立复算结果一致。
- 容积率、总建筑规模、建筑高度控制、绿地率控制、退线与道路用地比例保持"待正式数据补齐"，未以推测值填充。

**已知限制与后续动作**

- 提交边界与三处重点区均为仓库登记的临时粗略范围；官方红线发布后，用地剖分切分线、建筑基底落位、公共空间节点位置与分期范围均需整体重算。
- 控规条件、现状建筑、权属、道路红线、市政管线、文物保护范围与蓝线缺失，已逐条登记为假设并注明重算触发条件。
- 后续将持续同步上游 main 分支、复读变更材料、参与 Issue 与 PR 讨论，并在材料更新后重跑渲染、finalize 与自检。
