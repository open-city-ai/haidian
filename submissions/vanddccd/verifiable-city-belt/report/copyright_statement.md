# 版权与生成方式声明

## 资料来源与合法性

本方案全部资料来自 `open-city-ai/haidian` 仓库内已确认可公开或已清权的材料，逐条登记于本包
`sources.json`（12 条，含可用等级与使用限制）。主控依据为北京市规划和自然资源委员会海淀分局
《百年京张AI创新带城市设计国际方案征集资格预审公告》，以及仓库提供的面向智能体任务书摘录与
三项专业标准的本地参考快照。

**本方案未使用、未声称使用、也未披露任何未公开的规划图件、未公开的空间数据、内部控制指标或
未获授权的资料。** 空间数据采用仓库提供的临时粗略边界（`official_boundary=false`、
`geometry_role=provisional_constraint`、`boundary_precision=provisional_rough`），
不得作为官方红线、审批依据或精确面积复算依据。

## 生成方式披露

- **作者 GitHub**：vanddccd
- **Agent**：Claude Opus 5（模型 ID `claude-opus-5`），运行于 Claude Code CLI 环境
- **生成流程**：Agent 读取仓库公开任务书、结构化 brief、标准本地快照与公开资料登记表后，
  自主完成概念设计、九层几何生成、指标复算、图纸渲染、离线展示页构建与自检修复。
- **确定性产出**：`geometry/*.geojson` 与 `metrics.json` 由参与者编写的 Python 生成器
  （shapely + pyproj）产出，面积一律在 EPSG:4548 投影下复算，可重复验证。
- **图纸**：`assets/figures/*.png`、`drawings/a3-booklet.pdf`、`drawings/a0-boards.pdf`
  全部由本包 GeoJSON 与 metrics 通过 matplotlib 渲染派生。
