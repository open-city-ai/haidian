# 方案迭代记录

> 共智接力 / Jing-Zhang Civic AI Relay

## v0.6 - 2026-08-13

本轮以最新 `upstream/main` 的 18 项双语评审可见窗口和持久化自检合同为准，重新检查“目标—空间—产业—人群—文化—运营—治理—证据”关系。主方案、三层空间关系、三区职责、十二个场景、Logo、geometry、Relay Receipt 与 SC-04 真实性边界均保持不变，只修复已经确认的表达链问题。

- 五张中英文核心图同步提高正文、图例、指标注释与来源脚注字号，回收卡片中的无效空白；不增加项目、指标或协议卡。
- 中英文 visual 首屏改为内容驱动高度，补齐窄屏断行、最小宽度、44px 导航触达和全局键盘焦点，消除 390px 横向溢出并让全带回路、普通路径和证据边界同屏可见。
- 中英文 A3 首屏扩大总体关系图和证据边界；A0 三板放大主图与职责关系，压缩底部空卡并提升卡片字号，避免“完整图中再嵌完整图”的缩略阅读负担。
- 中英文 report 保持既有工业编辑结构，只为目录和横向证据表补充键盘触达与焦点提示。
- 按新版工具写入 `persisted-self-check-v1` 四门自检证明；确定性 PASS、合成桌面复演和远端 intake 仍不代表真实试点、专业认可、政府审定或工程可实施。

## v0.5 - 2026-08-10

本轮不改总体概念、几何、三段式空间结构、十二个场景、Logo 或工业编辑视觉系统，只修正首轮阅读中“最小试点证据反复出现，压缩全带空间逻辑与公共价值”的叙事配重。

- 正文先说明整条带如何运行：北部形成 `TestEvidence`，中部组装 `AdoptionPackage`，南部产生 `UseFeedback`，两翼把城市问题、专业能力和负面结果送回再验证；SC-04 明确为这条关系链的最小证据切片，而非方案本身。
- `land-use-structure`、`key-areas` 和 `mobility-bluegreen` 不再重复桌面演练状态，分别回到用地与日常服务、三区不可互换职责、慢行断点与现场 Gate；`site-overview` 和 `metrics-evidence` 继续承载试点证据。
- 两个 visual 首屏与两个 report 首屏先呈现全带回路、普通路径和产业价值，再以较小层级披露 SC-04 桌面 PASS 与真实试点 G2 阻断。
- A3/A0 前三页保持原有页数和版式，只把第二页与首板的标题、说明和信息卡改为“全带回路 → 最小切片”，避免把运行协议误读为单一技术项目。
- 补充当前上游 manifest 的模型族与模型细节声明；全部真实性边界、provisional geometry、unknown 指标和未授权运营状态保持不变。

## v0.4 - 2026-08-09

本轮不改总体概念、三段式空间结构、十二个场景、双语体系、视觉方向或主标，只修正评审首轮阅读中“实施证据不够早、桌面验证与真实试点状态容易混读、空间职责被协议说明挤压”的问题。

- 新增无网络、无外部系统、无参与者、无个人数据的 SC-04 本地合成桌面复演：4/4 fixture 路由与人工查表、6/6 检查、4/4 停止分支、5/5 回滚步骤可由随包 JavaScript 确定性复跑。
- 将桌面状态 `PASS` 与真实试点 `NOT AUTHORIZED / NOT RUN` 并列展示；复演不解除 G2 的责任主体、排班、现场与真实接管阻断，也不生成运营绩效、公众反馈或成本结论。
- 在正文摘要、核心图、A3/A0 前三页和两个 HTML 首屏前置“问题—场地—数据—权限—人工 Gate—测试—证据—采用/拒绝—反馈—回滚/退役”及下一步 G0—G2。
- 补回北部验证、中部转译、南部采用三种不可互换的规划职责和三种方案取舍，使 Relay Receipt 成为空间交接合同，而不是脱离场地的通用 AI 流程。
- 保持缺失的运营主体、预算、真实服务量、现场无障碍、法定指标和公众参与结果为 `unknown` 或部署前 Gate；不把结构预检写成完整系统验证。

## v0.3 - 2026-08-09

本轮保持总体概念、三段式结构、十二个场景、双语体系和视觉方向不变，只把既有 SC-04 收敛成第三方可检查的最小试点，并把关键实施证据前置到核心交付物。

### 最小试点与 Relay Receipt

- `Relay Receipt 0.3` 固定“问题—场地—数据—系统权限—人工 Gate—测试—证据—采用/拒绝—反馈—回滚/退役”十段执行链，并为每段定义机器字段、当前状态与失败去向。
- SC-04 只读取 4 份合成工单并写入隔离日志，设置 G0—G6 七道 Gate、6 项候选验收条件、4 个硬停止条件和 5 步回滚；责任主体未指派、测试未运行、绩效结果为 `null`。
- 三个重点区分别承担风险验证、责任转译与公共采用职责，共用同一凭证但不互换空间任务、人工 Gate、输出对象或禁入条件。
- 非 AI 服务路径、人工接管、暂停、拒绝、删除、回滚和退役均成为试点合同的一部分；任一必要证据缺失即保持在前一状态。

### 核心载体表达

- 在正文开头、五张核心图、A3/A0 前三页及两个 HTML 首屏前置 SC-04 的真实状态、十段链、验收、停止、回滚和未知责任主体，不增加场景数量。
- 补强中英文标题排版、正文小字与留白、十个字段的示例映射；主标改为 AI 生成的嵌合双轨构图：墨绿大 J/Z、信号橙小 J、治理青小 Z 以平行负形形成整体，不用笔画交叉或覆盖制造结合。
- 全部新增条件均是候选部署 Gate，不虚构预算、运营主体、现场数据、公众参与结果、法定指标或已经取得的试点绩效。

## v0.2 - 2026-08-08

本轮以已合并的 PR #315 为基线，从当时最新的 `upstream/main` 重新建立独立投稿分支，并按当时有效的任务书、schema 与文件合同重做关系一致性、机器合同和展示层检查。

### 方案与运营

- 保留“北部验证—中部转译—南部采用—两翼反馈”的主判断，新增任务书点名的五类区域协同接口；每类只表达输入、最小输出和退出闸门，不声称已有合作、共享数据、结果互认或采购安排。
- 将十二张场景卡的共同治理合同从六项扩为十项，并逐卡补齐非 AI 替代与硬停止条件。
- 新增 `Relay Receipt 0.2` 机器可读 Schema、SC-04 合成最小可复现切片、八个行动包的概念 RACI 与五本资源账。
- 新增资产权利台账，逐类登记来源、生成方式、许可、限制和官方资料到位后的替换动作。

### 证据与表达

- 将公告事实、机器合同、阅读导航和外部案例分层；七个全球案例只比较机构机制，不支撑海淀的边界、规模、合作或政策事实。
- 为 23 项合规要求、6 项标准判断和 15 项设计深度要求改写逐项证据摘要，删除重复模板话术。
- 五张核心图改为“空间底图 + 交接对象 + 人工闸门 + 可替换证据链”的同屏叙事；A3 文册加入区域接口、接力协议、RACI 与资源账，A0 展板放大主图并减少空白。
- 重写离线报告渲染，支持 Markdown 表格、证据标签、目录、键盘焦点、移动端排版和本地 favicon；全部展示保持断网可读。
- 按仓库术语表补齐完整英文对照：主稿逐章保持主张、指标、证据标签和图件位置一致，并为五张含文字图、A3/A0、阅读报告与视觉展览生成 `.en` 副本；两种语言共用同一 GeoJSON、metrics、Schema 与权利台账。

### 诚实边界

本轮没有取得 official polygon、控规、道路与轨道红线、权属、建筑底数、市政、文保控制、运营主体、服务基线或预算。没有开展真实居民、残障用户、服务人员或现场接管测试；可访问性结论只限自动化浏览器、键盘、对比度和 PDF 预检。Schema 样例通过结构校验不等于接口、性能、安全、采购或部署得到验证。
