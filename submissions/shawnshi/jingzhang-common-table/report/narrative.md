# 京张共食线：叙事摘要

京张共食线以“研究—试制—首单—条件回用”为主轴，把全球案例压缩为研发与小试、持证共享生产与孵化、市场与物流验证、生产性景观示范、材料循环与许可接口五项待验证能力。众智园承担研发与标准验证，AI 原点承担开源复现、共享试制和经营辅导，大钟寺承担批次市场与首单测试；海淀的开源、运筹、具身验证和成果转化基础被写成操作协议，不被写成既成合作。

三个节点都按受控后场、可观察界面和公共前场组织，访客、员工、食品物流与剩余物分开。九个建筑图斑只是三层界面的占位测试，不是九栋固定建筑。每项共享设施必须公布八字段设施卡，并在资产、平台、持证食品、研究评估、法定或专业复核五类角色之间明确人工否决权；0—90、90—180、180—365、365 天后四道闸门均允许暂停、缩减或退出。

G1—G7 继续作为生产—交换—材料—土壤规范主链。每个交接记录对象或批次、来源与权利、责任运营者、人工签核、异常和退出；AI 只提出候选，不裁决食品安全、可食性、过敏原、许可或材料去向。十二个场景中四个只在受控工作室运行，所有公共界面保留纸质和人工替代，不建立个人饮食画像。

提交临时边界在 EPSG:4548 下复算为 11.41 km²，概念绿地比例 16.2%，概念公共空间比例 0.57%。这些值描述投稿图层，不是法定或审批指标。Issue #846 记录了与外部背景可能错位的线索，但不足以移动 polygon；官方范围、权属、现状建筑、道路红线、遗产、市政、消防、污染、土壤、运营者、许可和真实绩效均待补。
