# 京张共食线：叙事摘要

京张共食线以“从共厨生产到土壤回用”为主轴，把食物科技、共享生产、小微经营、公共市集、低速物流、剩余物分流和生产性景观组织为 G1—G7 规范主链；五段流程只是物质流速记。每个交接记录对象或批次、来源与权利、责任运营者、人工签核、异常和退出；只有经检测及景观、环境与运营专业批准的回用材料才可返回来源端，否则账页在合规处置后结束。AI 只提出候选，不裁决食品安全、可食性、过敏原或材料去向。

三张桌分别是众智食物系统实验桌、原点共厨桌和大钟寺世界市集桌；中关村技术—经营链与小月河食物—材料链连接研发、试作、在地经营和回用。十二个场景中四个只在受控工作室运行，所有公共界面保留纸质/人工替代，不建立个人饮食画像。

提交临时边界在 EPSG:4548 下复算为 11.41 km²，概念绿地比例 16.2%，概念公共空间比例 0.57%。这些值描述投稿图层，不是法定或审批指标。官方 polygon、权属、现状建筑、道路红线、遗产、市政、消防、污染、土壤、运营者、许可和真实绩效均待补。
