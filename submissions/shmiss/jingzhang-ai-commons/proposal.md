# 京张世界客厅：AI Commons 未来长街

## 设计依据与资料清单

本方案是对原《京张智脉：AI Commons 共生创新走廊》的实质性重构。原方案的投稿结构、证据链、临时边界披露和机器校验机制可保留，但“四条纵向用地带+若干节点”的空间组织过于抽象，无法充分表达北京国际化大都市应有的人文厚度、花园城市品质、AI创新可见度与时尚街区活力。新版不删除合规底盘，重做概念、用地结构、公共空间、场景体系、重点片区和视觉表达。

现状诊断同时承认资料边界：仓库没有可用于逐栋判断的现状建筑、权属、交通流量、市政、文保控制线或正式地块图则，因此本轮可以重构空间关系和设计方法，不能把概念图升级成审定现状结论。[depth:existing_conditions_diagnosis]

任务主控依据仍是《百年京张AI创新带城市设计国际方案征集资格预审公告》、经清权的智能体任务书和仓库资料登记表。[source:OFFICIAL-ANNOUNCEMENT] [source:AGENT-TASKBOOK] [source:SOURCE-REGISTRY]

公告与智能体任务书同时作为两项项目专业标准响应。[standard:PROJECT-OFFICIAL-ANNOUNCEMENT] [standard:PROJECT-AGENT-OPEN-CALL-TASKBOOK]

`brief/site-package/` 是任务、枚举、允许设计空间、范围与标准的机器可读底座；`data/processed/agent_fact_pack.md` 只是对这些材料的导航和处理层，不产生新的官方事实。[source:SITE-PACKAGE] [source:PROCESSED-FACT-PACK]

北京城市总体规划、花园城市专项规划和国际消费中心城市实施方案用于校准以人为本、国际交往、文化自信、生态宜居与商业文化科技融合的价值方向。[source:BEIJING-MASTER-PLAN-2016-2035] [source:BEIJING-GARDEN-CITY-PLAN-2023-2035] [source:BEIJING-INTERNATIONAL-CONSUMPTION-CENTER]

海淀城市更新和AI创新带公开政务信息用于校准街区—校区—园区—社区融合与AI生活体验方向；上述政策均不提供本项目地块红线、开发强度或实施批准。[source:HAIDIAN-URBAN-RENEWAL-GUIDE-2025] [source:HAIDIAN-AI-INNOVATION-BELT-202603]

公开信息表明，京张铁路遗址公园沿线街区控规曾完成草案公示采信，2026年一季度官方进展表披露其已通过市级部门联审；2026年8月新闻报道进一步称街区控规获批。由于正式地块图则和批准文件尚未进入仓库来源登记表，本方案只把“一带一轴、两心多点”和绿色更新方向作为背景校核，不生成地块 polygon、容积率、高度、密度、退线或法定中心结论。[source:HD-JINGZHANG-CONTROL-PLAN-DRAFT-202502] [source:HD-JINGZHANG-CONTROL-PLAN-PROGRESS-202604] [source:HD-JINGZHANG-BLOCK-PLAN-APPROVAL-NEWS-202608] [assumption:A-BLOCK-PLAN-001]

由于 official `SITE_BOUNDARY` 和三处 official `KEY_AREA` polygon 仍未入库，本方案继续使用 `brief/site-package/geometry/provisional_boundaries.geojson`。`geometry/site_boundary.geojson` 与 `geometry/key_areas.geojson` 保持 `official_boundary=false`、`geometry_role=provisional_constraint`、`boundary_precision=provisional_rough`；它们只用于生成、可视化、自检和设计讨论，不是 official redline、审批依据或精确面积依据。[source:BOUNDARY-SOURCE] [source:KEY-AREA-SOURCE] [assumption:A-BOUNDARY-001]

official polygons 或正式图则到位后，必须一次性重算 site boundary、key areas、land use、roads、green space、public space、buildings、phasing、metrics、五张图、HTML 与两套 PDF。不得只替换一张图或一个面积数字。

### 一轨四境、三核十二场

- **一轨**：京张百年轨廊。以遗址公园为南北连续公共骨架，承载历史、慢行、生态和公共活动。
- **四境**：人文艺廊、花园绿环、AI城市试场、世界潮街。四境是贯穿全线的网络，不是四个互不相干的颜色分区。
- **三核**：众智园“AI花园实验城”、AI原点“开源策源院”、大钟寺“世界潮智街”。三核分别验证花园研发、近校策源和国际时尚型AI街区。
- **十二场**：每个主题设置三个可读、可运营、可退出的公共场景，合计12个。

空间语法概括为 **“轨·院·园·街”**：

1. **轨**保存百年京张的工程记忆与南北连续性。
2. **院**以北京熟悉的院落尺度组织共享、讨论、照护和成果转化。
3. **园**把绿地从背景色转为气候适应与公共健康基础设施。
4. **街**用连续首层、步行界面、创意商业和夜间活动形成世界城市日常。

## 统筹研究范围产业与未来城市研究

### 从“产业走廊”转向“世界城市生活廊”

AI产业集聚是项目底层逻辑，但城市设计不能只回答企业落在哪里。京张世界客厅把“研究—测试—转化—消费—公共反馈”组织为一条开放循环：高校和研究机构提出问题；众智园完成全栈评测、标准与安全验证；AI原点完成开源协作、成果转化与人才服务；大钟寺完成产品首发、创意消费与国际交往；居民、访客和运营者通过日常使用把问题重新带回研发和治理。

这套循环要求空间同时满足五个条件：可以步行进入、可以不使用AI、可以看到谁负责、可以停止测试、可以把公共反馈写回下一轮设计。AI因此是城市服务层，而不是遍布公共空间的监控层或展示屏。

七个国际案例只提取机制，不进行面积、强度、客流或产值对标：

| 案例 | 可转化机制 | 京张转译 |
| --- | --- | --- |
| Punggol Digital District | 大学、产业和社区一体化与开放测试平台 | 三核共享场景申请、测试、评估和退出规则 [source:CASE-PUNGGOL-DIGITAL-DISTRICT] |
| Mila / Mile-Ex | 研究、创业与负责任AI社群紧凑集聚 | 原点社区的开源策源院和夜间协作空间 [source:CASE-MILA-MILE-EX] |
| Vector / MaRS | 研究节点嵌入孵化和企业网络 | 从高校成果到城市测试的连续服务界面 [source:CASE-TORONTO-VECTOR-MARS] |
| Knowledge Quarter London | 多机构联盟与公众知识门户 | 公开议题库、成员协议和年度开放日 [source:CASE-LONDON-KNOWLEDGE-QUARTER] |
| Paris-Saclay | 多中心研究教育产业与城市生活协同 | 三核分工而非一个超级园区 [source:CASE-PARIS-SACLAY] |
| Kendall Square | 从产业区转向混合开放创新社区 | 住房、零售、开放空间与创新空间同步评价 [source:CASE-KENDALL-SQUARE] |
| Brainport Eindhoven | 知识、产业、政府和共享设施协作 | 标准协作、共用设施与跨主体项目库 [source:CASE-BRAINPORT-EINDHOVEN] |

品牌采用 **“京张世界客厅 / Jing-Zhang World Commons”**。视觉以青色表示开放AI与可参与，金色表示京张文脉，绿色表示花园韧性，珊瑚色表示时尚与需要人工确认的活动界面。品牌、活动、招商和国际合作均为概念建议，不构成政府承诺。

### 城市更新顺序

1. **先开界面**：打通公园与街区、校园、园区、社区之间的步行关系，开放可进入首层，补足休息、厕所、饮水、无障碍和人工服务。
2. **再导内容**：导入开源发布、气候花园、AI安全测试、设计生产和夜间创意等可逆场景。
3. **后做工程**：建筑更新、新建容量、桥隧、市政和站点一体化，在正式红线、图则、权属、文保和工程条件到位后深化。

建筑基底、慢行线和公共空间节点均为概念原型。容积率、建筑高度、密度、退线、道路红线、四线和设施容量保持 unknown；“设计深度完成”表示缺口、方法和证据链完整，不表示法定指标已确定。[standard:MOHURD-CONTROL-DETAILED-PLANNING] [depth:development_intensity_controls]

## 重点区域详细设计

![三处重点区域详细设计图](assets/figures/key-areas.png)

### 众智园：AI花园实验城

定位不是“可参观的技术园”，而是全栈自主创新、安全治理与花园研发同时成立的街区。

- **空间结构**：清河气候花园—安全评测沙盒—国际标准协作院三点成环；东西研发花径连接公园主脊与园区首层。
- **功能业态**：AI研发、测试评估、标准治理、共享实验、科技服务、人才餐饮运动和小型国际交流。
- **建筑更新**：优先保留可改造厂房和研发楼，打开围墙与首层；结构安全、权属、容量确认后再决定改造或替换。
- **生态动作**：清河界面以雨洪、生境、遮荫和慢行为先，不把传感器展示替代生态修复。
- **AI边界**：具身智能只在限定时空和低速试环运行；现场安全员、地理围栏、日志、断电和复盘缺一不可。

[data:geometry/key_areas.geojson#PROV-KEY-001] [source:OFFICIAL-ANNOUNCEMENT]

### 北京AI原点：开源策源院

定位是近校型创新街区，不是单一孵化器。核心是让高校、园区、街区和社区在首层共享问题、知识与日常服务。

- **空间结构**：校园园区开放缝—开源首发院—全龄人才生活院；公共主脊连接五道口与清华东路西口方向的慢行关系。
- **功能业态**：开源维护、成果首发、知识产权与法务、孵化转化、人才居住配套、社区学习和生活服务。
- **建筑更新**：先做首层通透、共享门厅、院落和街角空间；逐栋拆改留等待现状调查和正式控制。
- **人文动作**：开源贡献以可验证的维护、修复和公共问题解决排序，不以企业付费决定可见度。
- **AI边界**：公共服务默认最小数据、可解释和人工复核；老人、儿童和无障碍使用者保留实体导视与人工窗口。

[data:geometry/key_areas.geojson#PROV-KEY-002] [source:HAIDIAN-URBAN-RENEWAL-GUIDE-2025]

### 大钟寺：世界潮智街

定位是城市型AI创新街区。国际化不靠封闭会议中心，而靠每天可进入的商业、文化、科技和公共生活界面。

- **空间结构**：四象限步行缝合—AI设计工坊—全球首发秀场—夜间创意市集；与京张公园和轨道接驳形成全天候步行环。
- **功能业态**：AI原生内容和终端、设计工作室、品牌首发、独立零售、餐饮、展演、多语服务和企业会客。
- **建筑更新**：利用低效楼宇和可开放首层导入复合业态；不以新建地标塔替代街区更新。
- **时尚动作**：形成“设计—打样—首发—零售—反馈”闭环，让时尚是生产与消费共同发生的街面系统。
- **AI边界**：试衣、推荐和内容生成必须明示数据用途；拒绝授权不影响进入、消费和普通服务。

## AI 创新生态、人才画像与 AI+ 场景

### 八类用户画像

| 用户 | 核心需求 | 主要空间响应 | 不可接受的替代 |
| --- | --- | --- | --- |
| 周边居民 | 通勤、买菜、休闲、照护、安静夜间 | 连续步行、全龄邻里台、日常商业 | 产业活动挤占通学与生活路径 |
| 儿童、老人和无障碍使用者 | 清晰、安全、可休息、可人工求助 | 无障碍路线、实体导视、人工服务台 | 强制手机、人脸或语音交互 |
| 高校师生 | 成果转化、跨校协作、低成本试验 | 开源策源院、近校转化街 | 未授权公开科研成果 |
| 开源开发者与初创团队 | 协作、测试、算力、维护者声誉 | 开源贡献院、共享实验和夜间协作 | 用流量代替真实贡献 |
| 头部企业和产业服务者 | 研发、标准、法务、资本、国际接待 | 众智园标准协作、大钟寺城市会客 | 封闭园区占用公共空间 |

## 用地、建筑规模与拆改留方案

用地完整覆盖临时总体边界且互不重叠，公园主脊先从总体边界中切出，其余空间形成六个城市房间。[data:geometry/land_use.geojson#LU-001] [standard:MNR-LAND-USE-CLASSIFICATION-GUIDE]

`geometry/buildings.geojson` 中12个建筑基底与十二场景对应，只表达需要何种空间，不表达现状轮廓或建设规模。[data:geometry/buildings.geojson#BLDG-001] 拆改留采用四步法：

1. 核实年代、权属、结构安全、现状用途、租赁关系和历史价值。
2. 对有使用价值的建筑优先保留，打开首层与院落。
3. 对设备、消防、节能和无障碍不足的建筑进行适应性改造。
4. 只有在正式图则允许且保留改造无法满足安全与公共利益时，才讨论拆除或新建。

建筑风貌不规定伪精确高度：沿公园和遗产节点控制连续、低扰动的公共界面；重点片区允许以院落、连廊、退台和可进入首层形成中小尺度组团；高点、屋顶、色彩和天际线服从正式控规、文保、消防、日照和景观视廊。[depth:retain_renovate_demolish] [depth:height_massing_character]

容积率和建筑高度在 `metrics.json` 保持 unknown；概念建筑基底只作空间比较。[metric:building_footprint_area_sqm] [metric:floor_area_ratio] [metric:building_height_m] [assumption:A-BUILDING-001]

`MOHURD-ARCH-DESIGN-DEPTH-2016` 在仓库中缺官方来源文件且不是本次 mandatory standard，本方案仅记录该缺口，不把第三方镜像或记忆中的条文当作权威依据。[standard:MOHURD-ARCH-DESIGN-DEPTH-2016]

## 交通、轨道、市政与公共服务设施

交通系统由一条南北未来长街和五条东西城市缝组成：大钟寺四象限时尚步行缝、学院南路文化生活缝、AI原点校区园区开放缝、清河气候花园缝、众智园国际研发骑行缝。它们表达需要打通的关系，不是道路红线或工程线位。[data:geometry/roads.geojson#ROAD-001] [data:geometry/constraints.geojson#CONSTRAINT-001] [assumption:A-ROAD-001]

实施优先级：

- 近期先验证连续步行、骑行、无障碍、夜间照明、非机动车停放和人工服务点。
- 轨道站点一体化先做站口到街区首层的步行链和四象限通行，不预设桥隧方案。
- 跨环路、道路改造和工程节点必须等待交通流量、红线、地下管线、消防和产权资料。
- 端侧算力、微电网、雨洪和环境感知设备优先嵌入既有公共服务或产业空间，设置能耗计量、人工关闭和离线运行方案。

公共服务设施采用“双轨服务”：AI可以辅助导航、翻译、设施报修和信息检索，但实体导视、人工窗口、电话或纸质说明保持等价可用。无障碍和老人服务要求按具体法定场景判断，不把政策原则泛化为已完成合规。[depth:traffic_rail_slow_parking] [depth:municipal_new_infrastructure]

## 蓝绿空间、公共空间与城市风貌

![四境网络与十二场景图](assets/figures/mobility-bluegreen.png)

花园绿环由京张公园主脊与五条东西绿缝构成，承担四类绩效。[data:geometry/green_space.geojson#GREEN-001] [data:geometry/public_space.geojson#PUBLIC-001]

1. **连续慢行**：南北通勤与东西接入不被活动、展台或测试设施切断。
2. **气候适应**：树荫、通风、可渗透地表、雨洪调蓄和夏季休息点形成冷岛网络。
3. **生境连续**：清河、小月河与公园植物群落的具体设计等待生态与水务资料，避免用单一“智慧绿地”概念代替生境。
4. **公共交往**：院、亭、台、街角分布在日常路径上，可被居民、研究者、国际访客和服务人员共同使用。

风貌基调为“百年工程理性 + 北京院落尺度 + 花园城市底色 + 当代创意街面”。材料优先采用耐久、可维护、可逆的砖、木、金属和透水地面；数字设备嵌入设施而不是主导立面。夜景控制屏幕亮度、噪声和活动时段，形成可长期生活的国际街区，不制造24小时科技展场。[standard:MOHURD-URBAN-DESIGN-MEASURES] [depth:blue_green_public_space]

四个概念地标由 [metric:landmark_count] 记录：

- **百年时门**：用轨距、里程与时间刻度呈现京张工程史，保留人工讲解。
- **开源贡献院**：展示经授权、可核验的开源维护和公共问题解决记录。
- **花园算法亭**：公开气候监测方法、设备状态和人工维护人，不把算法包装成自然。
- **世界智造秀场**：连接设计、打样、首发和反馈的小型开放街面，不以企业广告占据公共空间。

## 指标体系、面积复算与合规矩阵

指标分三类：

- **可复算空间值**：临时边界投影面积、建筑基底面积、蓝绿空间比例、公共空间比例、概念慢行长度和三处重点区数量。它们来自GeoJSON和EPSG:4548复算，但仍受临时边界与概念图层限制。
