# 本象之城：设计宪章 v0.1

## 一句话命题

任何改变城市的高影响提议——无论来自 AI 还是人——都必须以可核对的事实为前提，优先以可撤回的方式落地；不可逆事项须显式标记并进入加严门槛；最终由依法有权且受影响的人在同一公开门槛前共同签署。

## 为什么不是“另一个数字孪生”

数字孪生解决“如何呈现城市”，本象之城解决“谁能改变城市、依据什么、影响谁、怎样撤回”。这里的“唯一真源”不是唯一结论或唯一数据库，而是每个稳定对象唯一的规范记录：它同时保存证据、来源、时间、置信度、适用范围、异议和当前裁定。多方可以对同一对象提出相互冲突的证据；冲突本身进入真源，裁定值只是可更新的状态，不得删除少数意见或伪装成永恒事实。

方案将 2Origin 作为可替换、可开源实现的方法层，不把公共基础设施绑定到某家企业、某个大模型或某个云平台。依法有权的机构、专业人员与受影响群体仍可由五个核心概念表达：主体是稳定对象，权限与适用范围是对象状态和约束，签署是语义事务的证据，提交编译器校验签署者是否满足约束。因此无需向协议核心新增“权威主体”概念，最终判断仍属于人类和法定程序。

本协议只覆盖会改变公共空间、公共服务、他人权利或共享资源的高影响提议。散步、休息、聊天、摆摊、游戏和无需公共授权的普通生活不生成“城市提交单”；沿线必须保留不被感知、不必登录、无需 AI 的日常空间。城市首先是生活世界，协议只是少数高影响变更的护栏。

## 本象核心如何落成城市方言

| 协议 | 城市作用 | 可见空间 | 最小可验收物 |
| --- | --- | --- | --- |
| 本象协议 | 以稳定 ID 保存对象、关系、状态、约束与来源 | AI 原点社区“本象馆” | 城市对象卡、真源引用、版本与新鲜度 |
| 投影 / 影子 | 从同一本象生成居民、规划、施工、运营与 Agent 多端可重建视图 | 沿线“投影窗”与无障碍解释台 | 多视图一致性测试、通俗解释、非数字替代 |
| 影核协议 | 把一个语义动作交给多个执行器完成，并管理前置条件、失败回退与撤销 | 三站“动作路由台” | 动作合同、执行器记录、失败回退证据 |
| 叠象 / Redline | 比较改动前后状态，显式列出受影响的人、空间和规则 | 大钟寺“叠象议场” | 城市红线单、影响清单、公开意见与采纳理由 |
| 影域 | 在有限地点、时段、人群和权限内隔离试错 | 众智园“影域试证场”与小月河场景翼 | 沙盒边界、人工急停、退出演练、事故账本 |
| 本境 | 保存 detector、rule、adapter 与版本的环境指纹 | 试证场“环境指纹门” | 可复现实验环境、依赖哈希、差异说明 |
| 提交编译器 | 解析语义事务，检查约束、影响和依赖，更新状态、留证并重新投影 | 京张“城市变更门 / Review Gate” | 通过/挂起/退回回执与机器可读校验报告 |
| AI2Work 城市扩展 | 用真实城市任务评价 Agent，不以演示视频代替能力 | 三站共同维护的“城市工单台” | 任务包、工具记录、结果证据、人工评分与复现包 |

城市方言仍只依赖五个核心概念：对象、引用、投影、事务、校验。上表的空间设施和工具都是方言，不向本象协议核心偷塞新概念。

## 空间结构：一线三站两翼六类接口

“一线”是京张城市本象线：遗址公园既是慢行与文化公共脊，也是城市变更记录的公共阅读界面。临时边界只作为生成和自检约束，以低对比虚线表达，不被包装成官方红线。

“三站”对应三处重点区域：

1. 众智园——影域试证场与本境指纹门。面向全栈自主、机器人、端侧算力和城市智能体，建立“任务登记—隔离仿真—环境指纹—有限实测—公众观察—回滚复盘”的验证链。任何具身试验都保留人工看护、物理急停和普通行人的默认路权；任何结论都附 detector、rule、adapter 与版本指纹，避免换环境后仍冒充可复现。
2. AI 原点社区——本象馆与城市提交编译站。高校、开发者、规划专业人员和居民在这里查看同一城市对象的来源、状态与争议，把 Agent 建议翻译成可签署的城市提交单；社区模型诊所为非技术公众提供人工解释和线下入口。
3. 大钟寺——叠象议场与日常采用市集。商业、通勤、社区服务与公共空间成为验证公共价值的真实场景；所有变更先展示“前/后差异”，商户、居民和无障碍使用者可以拒绝、申诉或要求恢复非 AI 服务。

“两翼”不是封闭园区：中关村科技服务翼提供标准、法务、资本、知识产权和国际服务；小月河场景赋能翼提供生态、照护、运动、社区和日常公共问题。两翼持续向本象线提交工单与评测结果。

六类公共接口是：城市对象卡、城市提交单、红线比较窗、影域沙盒、人工签署台、回滚里程标。它们同时是导视系统、公共家具、开发者工具和治理凭证。

### 三站空间原型

三站不是三块软件屏幕，而是可在官方红线、权属和现状资料到位后迁移、缩小或取消的空间类型：

- **众智园“影域试证场”**优先复用既有室内场地或封闭院落，形成测试单元、安全缓冲、公众观察廊、人工控制室和设备撤场口五层剖面。机器人与普通行人不共用默认通道；无法形成物理隔离、人工急停和完整撤场路线时，只能停留在仿真。
- **AI 原点社区“本象馆”**优先复用开放首层或公共服务空间，以中央城市对象台、四类投影席、安静人工解释室、纸质档案台和不采集数据的穿行通道组成。居民可以只看、只问或绕行，不因拒绝数据授权失去服务。
- **大钟寺“叠象议场”**优先使用商业前场或社区广场的可逆时段，把同一空间分成“改变前”“建议后”“受影响者席”“专业复核席”和连续绕行带；活动结束后家具、标识与设备可以全部撤离，不把公共广场永久变成审批大厅。

正式图纸将为三者分别提供平面、剖面、进入/退出流线、无 AI 路径、日常/测试两种时态和撤场条件；任何尺寸都是可供专业团队深化的类型学包络，不是已审定点位或工程条件。

### 八项可验收物的判词

| 可验收物 | 最小机器判词 | 失败状态 |
| --- | --- | --- |
| 城市对象卡 | 对象 ID 唯一；真源引用可解析；引用版本与当前水位一致 | 挂起 |
| 多端投影 | 所有投影指向同一对象版本；丢弃信息被声明；可从真源重建 | 挂起 |
| 动作合同 | 目标、前置条件、执行器、撤销动作和失败回退均存在 | 挂起 |
| 红线单 | 当前状态、建议状态、结构/语义/空间差异和受影响对象可枚举 | 挂起 |
| 影域沙盒 | 地点、时段、人群、权限、急停、人工接管与撤场条件完整 | 挂起 |
| 本境指纹 | detector、rule、adapter、版本与依赖哈希齐全；环境差异可解释 | 挂起 |
| 城市变更回执 | 高影响自动终局、取消非 AI 服务或无申诉路径 | 退回 |
| AI2Work 工单 | 任务数与台账一致；工具记录、结果证据、人工评分和复现环境齐全 | 挂起 |

这些判词将由投稿内可运行的城市方言编译器与测试样例证明；无法自动核对的专业、法律和公众判断必须显示为待人工签署，不得由 PASS 字样冒充完成。

## 六项任务的第一轮落地

### Agent.1 命名与识别

主名称“本象之城”，英文名 “THE GROUND-TRUTH CITY”。Logo 方向由一条连续轨线、一个可见差异层和一个人工签署点构成；实线表示已核验状态，虚线表示待复核建议，朱红标记表示人类签署或暂停。它不使用第三方品牌与人物形象。

### Agent.2 生态与案例

案例研究将选 7 个机制型样本，覆盖开放城市模型、城市 AI 试验场、算法登记、居民共创、空间智能基准和创新街区运营。每个案例只转译机制，并明确不照搬的制度风险。产业链不是“招多少企业”，而是“城市工单—数据/权限—仿真—实测—专业签署—采购/采用—维护/退役”的可验证服务链。

### Agent.3 场景与人物

第一版 12 张场景卡：无障碍路径修补、慢行断点诊断、低速机器人配送、AI 医疗导诊、AI 教育资源导航、AI 法律服务转介、商户经营辅助、公共空间时段编排、树木水系养护、京张多语导览、应急信息核对、城市更新公众红线。前三类具身/高影响任务在影域中做至少 3 个产业测试验证，并用本境指纹固定环境条件；所有场景必须有人审、非 AI 等价路径、数据最小化、申诉和退出。

人物至少覆盖：附近居民与老人、残障/无障碍使用者、学生与青年开发者、科研/创业团队、小商户与服务人员、规划/运营专业人员、国内外访客。画像用于设计服务与保护权利，不用于不透明筛选。

### Agent.4 公共空间与朝圣地标

三个核心地标不是巨型雕塑：

- “零号本象库”：展示城市对象如何被记录、质疑和修订。
- “百年红线墙”：把一次城市变更的前后差异、采纳与拒绝理由转成公共展陈。
- “回滚里程标”：记录成功下线、修复与恢复的项目，把承认失败变成公共荣誉。

配套组件包括可替换信息牌、低功耗状态灯、触觉/语音解释台、纸质服务盒、移动观察台和物理急停柱；正式布点必须经过文保、绿地、交通、安全、无障碍和运营复核。

### Agent.5 文化叙事

京张文化不被简化为火车造型。叙事提取的是工程纪律：勘测、记录、统一接口、现场验收、问题复盘和百年维护。中关村文化提供开放协作和知识转化，AI 新文化补充可复现、可质疑、可回滚。三者共同形成“先记录事实，再提出改变；先证明，再合入”的城市气质。

### Agent.6 长期运营

年度节律分四季：春季“城市问询”公开征题；夏季“共同制作”形成可复现方案；秋季“本象验证周”在受控环境和公共空间复核；冬季“城市签署会”公布采纳、退回、暂停与退役清单。贡献荣誉分为首提者、维护者、复核者、受影响群体守门人和长期运维者，不以资本规模或模型参数排序。

## 城市提交单：最小语义事务

每一项高影响城市变更至少包含：对象 ID、当前状态、建议状态、来源、适用时空、受影响群体、专业责任人、公众解释、成功指标、失败触发器、人工接管、回滚动作、数据删除/归档规则和签署记录。缺少阻断字段时显示“挂起”，不得进入现场；高影响自动终局、强制取消非 AI 服务或没有申诉路径时直接“退回”。

这个合同可先作为投稿包内的机器可读样例和离线交互演示，再由专业团队决定是否采用何种数据库、标准或软件实现。协议名称不等于政府标准，演示通过也不等于规划批准。

## 评审验收线

- 叙事：六项 Agent 任务全部在正文可读，不靠矩阵打勾。
- 空间：三站、两翼、公共接口、12 个场景和实施阶段均能定位到 GeoJSON 概念要素。
- 计算：提交至少一个可运行的城市提交编译样例和 AI2Work 工单台账，聚合指标可复算。
- 人本：每个场景同时给出人工复核、非 AI 等价服务、申诉、退出和受影响群体签署。
- 专业：官方控制缺失项保持待确认；不编造红线、控规、权属、投资、企业或政府承诺。
- 表达：中英双语正文、五张双语核心图、双语离线 HTML、A3/A0 双语 PDF 全部有效。
- 生产门禁属于投稿团队内部流程，不进入城市制度叙事；正式发布前仍须通过仓库规定的渲染、定稿、自检和参与者预检。
