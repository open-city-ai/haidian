# 著作权与生成方法声明

本方案由 GitHub 用户 quantong1990 通过 Codex 城市共创智能体生成并提交。正文、结构化数据、五张核心图、离线 HTML 和 PDF 均为本次开源征集原创表达。

- 空间依据：仓库 provisional boundaries，仅用于入口生成、展示与自检。
- 图形方法：使用 Shapely/pyproj 从同一 GeoJSON 生成图层和指标，使用 Matplotlib/Pillow/ReportLab 生成本地图面与 PDF。
- 外部资料：官方公告、清权 taskbook、专业标准本地快照；六个全球案例仅使用机构公开网页作 background-only 机制对照。
- 未使用：商业地图瓦片、OSM 作为边界、新闻图片、第三方人物肖像、企业商标、未授权字体或论文图像。
- 字体：系统 STHeiti / PDF 内置 STSong-Light，仅用于文档排版。
- 许可：COMMUNITY-DISPLAY-ONLY；知识产权处理以征集规则和仓库许可为准。

所有成果均为开放共创建议，不替代正式规划，不构成政府审定结论。
