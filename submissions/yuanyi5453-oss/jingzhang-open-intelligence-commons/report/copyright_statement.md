# 版权与素材说明

## 资产范围与生成方式

- `proposal.md`、`proposal.en.md`、`report/` 下的 HTML 与摘要、`visual/` 下的离线页面、五组中英文信息图以及 A3/A0 图纸，均由本投稿工作流基于本包的结构化数据和登记来源生成、排版或栅格化；它们不是组织方审定图纸。
- `geometry/*.geojson`、`metrics.json` 与 `assumptions.json` 是对仓库登记资料的概念性整理和派生复算。总体边界与重点区几何明确标为 provisional，不能作为法定红线、权属或精确工程量依据。
- `compliance_matrix.json`、`design_depth_matrix.json` 与 `standard_matrix.json` 来源于 Waterfak3r 的 PR #863；Waterfak3r 已在 2026-08-14 的[公开回复](https://github.com/open-city-ai/haidian/pull/863#issuecomment-5293699053)中确认有权授权，并明确允许 PR #909 在署名 PR #863 与 `@Waterfak3r` 的条件下复制、修改、再分发和公开展示这三个文件。本提交不将三个矩阵表述为独立原创。
- 文本、图形和页面没有嵌入商业底图、在线地图瓦片、远程字体、第三方照片或第三方商标。图形只使用本地系统字体进行栅格化，字体文件未随包分发，也不主张对系统字体作再许可。

## 外部来源与使用边界

- `sources.json` 登记的官方公告、智能体任务书、公开资料登记表、标准快照和六项外部案例，只用于任务范围、方法或机制参考；案例仅以文字机制和链接引用，不复制其图像、商标、版式或受保护表达，也不把宣传性数据当作本地绩效证据。
- 任何新增网页、数据、字体、代码或图像都必须先补充发布者、日期、访问日期、许可、用途和限制，再进入正式论证。本包没有把未登记材料包装成官方或已清权资料。
- 生成脚本与数据转换在本地工作流中运行；本次交付没有把第三方代码、模型权重或远程服务作为可再分发资产。若后续工程复用脚本或依赖，应另行核对其许可证和版本。
