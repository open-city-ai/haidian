八项就绪条件

资产与时段 → 连续实体导向 → 无锁无扫码 → 设备与附件巡检 → 具名责任 → 分时段训练机往返 → 用后补件复位 → 120 专业边界。AI 只做冲突提示、聚合和工单辅助。

一票停止

  1. 资产、开放时段或责任主体无法核实
  2. 柜体上锁、要求扫码或实体导向中断
  3. 训练机往返未达门槛却将点位标绿
  4. 用后未补件、复核、复位仍显示可用
