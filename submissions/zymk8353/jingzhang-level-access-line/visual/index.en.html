03 / STATE + RESPONSIBILITY

REPAIRED DOES NOT MEAN RECOMMISSIONED

FOUR PUBLIC STATES + INTERNAL MACHINE

UNKNOWN → AUDITED → READY → DEGRADED/CLOSED → REPAIR → RECOMMISSION_REVIEW → READY. Expiry returns UNKNOWN; recovery requires qualified human signature.

STOP GATES

  1. Asset, using unit or licensed maintenance cannot be verified
  2. The only vertical link fails with no equivalent alternative
  3. A public report or repair record is treated as safety release
  4. Expired, conflicting or offline state remains green
