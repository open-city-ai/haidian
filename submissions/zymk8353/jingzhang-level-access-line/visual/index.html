01 / THESIS

有电梯图标，不等于此刻能通行

AI 只识别状态冲突、聚类复发和辅助工单；它不控梯、不停梯、不维修、不检验，也不自行放行。基本服务不采集身份、健康、影像、声音或连续轨迹。

03 / STATE + RESPONSIBILITY

修好了，不等于已经复验放行

公开四态与内部状态机

UNKNOWN → AUDITED → READY → DEGRADED/CLOSED → REPAIR → RECOMMISSION_REVIEW → READY。证据过期自动 UNKNOWN；恢复必须有适格人工签名。

一票停止

  1. 资产、使用单位或持证维保无法核实
  2. 唯一垂直节点故障且没有等价替代
  3. 公众报障或维修记录被当作安全放行
  4. 证据过期、状态冲突或断网仍保持绿色
04 / 90 DAYS

先证伪，再复制

0–15 天做授权、台账、路径和责任证据门；16–30 天建立状态牌、纸图、对讲与替代；31–60 天演练断网、停电、维保、积水和缺人；61–90 天有限发布并验证人工复验放行。
