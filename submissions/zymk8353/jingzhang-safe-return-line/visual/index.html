03 / CUSTODY

真实药品只走专业责任链

四次可核交接

受理 → 封存 → 运输接收 → 处置确认。AI 只做提示、异常和路线备选；每一步都有人工最终决定。

一票停止

  1. 公众或志愿者运输散装药品
  2. 收集身份、疾病或处方字段
  3. 任何容器去向不可追溯
  4. 无运输/处置确认仍开放
