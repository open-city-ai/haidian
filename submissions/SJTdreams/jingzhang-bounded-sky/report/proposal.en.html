BOUNDED SKY: A Low-Altitude Public Protocol for Centennial Jingzhang

Urban sky is not an empty page for efficiency. Every flight spends safety, quiet, energy, ground occupation, and public time. Those costs should enter a public ledger before a city asks how far a low-altitude economy can fly.

This proposal is a governance and spatial protocol, not an approved route. It divides the overall design area into three conceptual airspace-budget cells linked to the three key areas. A city Agent receives medical, maintenance, research, accessibility, and commercial requests; checks hard requirements such as authorization, weather, operator responsibility, identification, and human fallback; then explains, schedules, holds, rejects, pauses, or replays a request within five public budgets. No route, altitude, frequency, operator, or facility is authorized by this package.

Core Concept and Mechanism: The Low-Altitude Budget Compiler

The low-altitude budget compiler is the proposal's differentiating mechanism. It compiles a natural-language request into a reviewable urban action instead of treating the Agent as an automatic planning chat interface. The input layer accepts only mission class, beneficiary, conceptual location, time window, minimum data, named owner, and fallback option. The constraint layer overlays five ledgers, sensitive areas, authorization, weather, and equipment state. The decision layer returns only four states: accept, hold, ground transfer, or reject. The evidence layer stores the version, budget cost, triggered stop_if, human reviewer, and recovery action.

This binds space, algorithm, data, and civic governance. The same request is a closed validation task at Zhongzhiyuan, a resident-and-university fairness replay at AI Origin, and a pedestrian and staffed-logistics test at Dazhongsi. When a rule or official boundary changes, the Agent recompiles every task, layer, and metric. A human committee can freeze a rule, rewrite a budget, or veto the result; the replay returns to the public ledger. The difficulty is not drawing a beautiful route, but making every machine recommendation understandable, contestable, stoppable, and recoverable 空间数据 空间数据 深度.
