# 天空有边 / BOUNDED SKY

本方案把低空视为需要向地面公共生活负责的稀缺资源。城市 Agent 在安全、安静、能源、地面占用和公共时间五类归一化预算内协商 12 个合成任务；人类保留许可、操控、预算设定、隐私、应急和最终否决。

三处重点区域被转译为可独立关闭的验证舱、协商舱和城市服务舱。当前几何为 provisional，所有飞行高度、航路、运营、噪声、气象与工程结论均未授权或待补。离线压力测试只证明控制分支可复演，不证明真实飞行性能。

差异化机制是“低空预算编译器”：它将请求、空间约束、五本公共账和人工责任编译为接受、等待、转地面或拒绝四种可回放状态。规则或边界变化时，Agent 全链重算；人类可以冻结规则、改写预算或否决结果，居民可以查看理由并要求复演。
