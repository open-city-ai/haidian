# 评审叙事索引

本包的权威顺序为：来源与假设 → GeoJSON → EPSG:4548 指标 → 矩阵 → 中英文正文与展示。空间主张不是“一轴三核”，而是 MAIN TEXT + MARGINALIA：15个可引用段落、8条横向页边注、12个脚注公共节点。

评审时先看 `assets/figures/site-overview.png` 与 `land-use-structure.png`，再由 feature ID 回到 geometry；三处重点区总览见 `key-areas.png`，真实临时几何、概念功能、流线与概念断面见 `key-area-01/02/03.png`；日常通行、无屏兜底和蓝绿系统见 `mobility-bluegreen.png`；来源、指标、风险和复算链见 `metrics-evidence.png`。任何 official 边界、控规、权属、文保、交通、市政、运营与权利资料到达后，必须整包再生成。

## 后续生成任务规划

1. **官方空间数据门**：接收带 CRS、版本和来源说明的 official polygon；先替换 `SITE-001` 与三处重点区约束，再从单一真源重建用地、建筑、道路、绿地、公共空间和分期，随后同步重算指标、矩阵、正文、16张图、双语 HTML 与四份 PDF。禁止只换底图或手改面积。
2. **现状调查门**：补齐现状建筑与结构、权属和租赁、文保与考古、全天交通和无障碍、轨道接口、市政容量、防洪排水、成熟树木与日常使用调查；未经专业确认的高度、容积率、退线、道路红线和拆改留继续保持 `unknown`。
3. **权利与共创门**：建立逐资产的模型、数据、文化内容、材料、劳动、公共决定与维护清单；设计自愿、可撤回、分用途授权和未成年人高保护流程。先进行无账号、纸质和人工路径测试，再决定任何数字采集。
4. **产业验证门**：为 SC-04 转码存续、SC-05 撤回传播、SC-06 史实—修复—合成辨识建立可复现实验基线、失败样本、人工复核和独立评审；没有样本量、方法和失败条件前，不生成成功率或绩效承诺。
5. **详细设计门**：将三处临时概念详图推进到经测绘支持的 1:500 总平、1:200 首层与剖面，并完成消防、结构、交通、市政、声光环境、无障碍、雨洪和施工分期协同；所有功能保留移动、降级和取消选项。
6. **运营治理门**：明确运营主体、公众监督、申诉与下架、五年以上维护预算、备件和退役，形成公共采购的出处交付条款以及贡献者署名、补偿和公共价值回流规则。无责任主体或维护经费的永久项目不得进入建设清单。
7. **发布与交接门**：每次生成先跑 deterministic、spatial、visual、professional 与 self-check，再逐页渲染中英 A3/A0、检查离线 HTML、文件大小和无软链接；最后刷新 manifest hash，保留版本差异与回滚说明后再提交评审。
