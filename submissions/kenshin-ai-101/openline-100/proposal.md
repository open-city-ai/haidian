# 何以京张：The Openline 100

## 总体概念：三章并进——路与票 · 资本闭环 · 以人为轨

评委对照图版，应读到同一代叙事，而不是开篇一套、图上另一套。本方案用三章并进回答「何以京张」——路怎么用、钱怎么转、人怎么当轨。任务书要的空间结构、三区两翼、场景卡仍是支撑，不另立第四个统领 [source:AGENT-TASKBOOK] [depth:overall_spatial_structure]。

| 章 | 一句 | 图版 |
| --- | --- | --- |
| **路与票** | 路是 Openline，票是 Open Ticket；铁路没有票制只是工程 | `open-ticket-governance` |
| **资本闭环** | 每期同时回答建设 / 出钱 / 运营 / 回流；可逆即低风险 | `phasing-capital` |
| **以人为轨** | 1909 的「人」字写线路形状；这个世纪的「人」字写价值归属 | `heritage-soul` |

### 第一章 · 路与票

**如果评审只记住一件事：路是 Openline，票是 Open Ticket。** 1909 京张争的是路权自立；2026 续写的是数字时代的市民路权。铁路没有票制只是工程，有了票制才是公共服务。Openline 不是一条新画的红线，而是这条**路本身**——空间 + 数据 + 参与三重载体。AI 是路上跑的车，不是票的客体。一带不缺车，缺的是谁可以上路、如何核验、如何下车、如何把路交给下一班。

### Open Ticket 制度剖面：四层 × 四道闸

票制是全线同一套闸，不是第三套 Logo，也不是已定制度。治理概念图，机制待与街道 / 数据主管部门共建。

![Open Ticket 制度剖面：治理 / 空间 / 数据 / 时间四层 × 加入 / 核验 / 退出 / 继承四道闸](assets/figures/open-ticket-governance.png)

| 层 | 一句 | 空间落点 |
| --- | --- | --- |
| **治理** | 独立理事会四方受托：政府 · 高校 · 居民 · 技术社群 | 公开议事廊；账目每季公开 |
| **空间** | 街与轨免票进入，上路不先买许可 | L1 / L2 地面；Kilometer Zero / The Join 只办加入仪式，不设收费闸 |
| **数据** | 城市数据信托金库上锁：传感器只进不出，受托人持证开启 | 驿站传感杆；算法审计界面临街 |
| **时间** | 像考古层一样留痕的继承：1909 路基 → 2026 证据线 → 2035 组件库 | 组件库版本化；失败案例库强制收录 |

四道闸把 Join · Verify · Exit · Inherit 写成可执行的票制，而不是口号 [source:AGENT-TASKBOOK]：

| 闸 | 许可怎么发 | 退出/继承怎么兑现 |
| --- | --- | --- |
| **加入 Join** | 空间使用免票；数据授权三档自选；场景参与签微合约 | 可随时退出名单与空间预约 |
| **核验 Verify** | 信托账目每季公开；算法审计临街；失败案例库强制收录 | 结果可公开或授权撤回 |
| **退出 Exit** | 一键撤回 + 删除回执；免识别通道与遮蔽标识 | 退出后服务不降级，不留画像 |
| **继承 Inherit** | 组件库版本化留痕；退出者贡献署名移交 | 下一版可续建，不重写 |

### 第二章 · 资本闭环

可落地性不是把时间轴画得更细。每一期必须同时回答：**建设什么 / 谁出钱 / 谁运营 / 收益怎么回流公共空间**。三种融资情景——专项债 / 片区统筹 / 企业认养——是接力，不是三选一；全部是带适用前提与 B 计划的可比较概念情景，不是已确定的融资安排。三期认养受 Open Ticket 许可链约束，公共界面仍属公共。

![分期资本逻辑：每期同时回答建设 / 出钱 / 运营 / 回流](assets/figures/phasing-capital.png)

**可逆即低风险。** 五道口甲板螺栓连接、不浇筑：资产可迁移，示范段错了不是沉没成本——这是敢先做一期的真正理由。量级估算挂 `A-CAPITAL-001`，非概算。分期全表与 OL 出资逻辑见后文「分期资本逻辑」与实施经济学。

### 第三章 · 以人为轨

人字坡的「人」，1909 年写的是线路的形状；这个世纪的「人」字，写的是价值的归属。三次转身不是复活已退役的「人字轨」品牌，而是续写京张的换向术 [depth:blue_green_public_space]：

| 转身 | 在哪换向 | 不做什么 | 当代对应 |
| --- | --- | --- | --- |
| **1909 · 地形** | 火车在山脊转身 | 不炸山 | 33‰ 坡度，道岔换向 |
| **2026 · 存量** | 城市在 13 号线上转身 | 不拆既有 | 螺栓借墩，可逆甲板 |
| **这个世纪 · 价值** | AI 在人的轨道上转身 | 不拿算力当轨 | 算力的坡挡不住，必须回人处换向 |

铁路解剖学的当代对应物：道岔 = Open Ticket 核验 / 退出闸；避难线 = 失败案例库；试车段 = 治理沙盒；**轨 = 人类价值观，不是算力**。

![遗产显魂：考古三级 × 口述三声 × 人字坡三次转身](assets/figures/heritage-soul.png)

从保护遗产到续写京张，三带各就各位：

| 带 | 对谁 | 做法 | 诚实边界 |
| --- | --- | --- | --- |
| **考古分级** | 对物 | A 原位只读 · B 可触可坐 · C 无存新作；清华园站房 1910 为有据文保锚点 | 文献比对框架，待勘察校核（A-HERITAGE-001） |
| **口述声景** | 对人 | 道口工 / 沿线老居民 / 站房老职工；空位「＿」待真声，经许可入碑 / 牌 / 码 | 采集计划 30 位，不编造引语 |
| **三次转身** | 对时代 | 地形 → 存量 → 价值 | 不把人字坡做成第三套 Logo |

五种物质转译（铺装 / 沟 / 家具 / 碑 / 声）是显形；本章是显魂。显形图见总体设计章。

### 一个统领，五层支撑

三章是叙事主线。其余系统都是这条路的支撑件，不另立概念：

| 层 | 系统 | 与三章的关系 |
| --- | --- | --- |
| 空间层 | 双线主脊（L1 证据线 / L2 服务线）+ 一轴 + 三缝合 + 两心一核 | 路的物质层：把「找到协作、完成复核」的空间成本降到最低 |
| 地标层 | Kilometer Zero · The Join · The Strata Wall | 三座朝圣地标：加入钉 / 换向场 / 继承墙；不是收费站，不是改名家具 |
| 票制层 | Open Ticket（四层 × 四道闸）+ 三区三种创新机制 | 全线同一套闸；全栈协同 / 开放提问 / 城市采纳是闸在三区的执行 |
| 场景层 | 十张全深度场景卡（S-01–S-10 各一张八件卡） | 票的日常层；卡 01–03 是三区生产函数，其余七张覆盖索引号 |
| 未来层 | 形态八题 · 前瞻矩阵 · 不变量清单（附录 A） | 路的寿命层；资本闭环与以人为轨分别见第二、三章 |

### 现状诊断：不是缺 AI，是有路无票

在公告文字四至与 provisional 足迹可读的范围内，本方案把问题诊断写成四条可操作的城市病症（均属讨论级，非正式勘察结论）[depth:existing_conditions_diagnosis]：

1. **有路无票。** 京张遗址公园已提供南北文化与绿廊，但上路没有票制——谁可以进入创新过程、如何核验、如何退出、如何继承，缺少可执行的闸。公园易变成观赏带，而不是工作—学习—发布—验证的日常路。 
2. **三区任务同频，空间模板却趋同风险高。** 众智园（全栈/标准）、原点（近校/开源）、大钟寺（站域/消费转化）在公告中分工清晰，若仍按同一园区模板填功能，会消解三区价值差 [data:geometry/key_areas.geojson#PROV-KEY-001]。 
3. **东西向被切开，南北向被拉长。** 高校、社区、企业与站点多在 Openline 两侧腹地；若只画南北大道，五道口、清华东路西口、大钟寺站四象限仍会「看得见、走不通」。断点只标研究问号，不画假桥隧 [data:geometry/roads.geojson#ROAD-STITCH-M]。 
4. **数据与权属缺口是设计条件，不是借口。** 2026-08-11 街区控规已批，「一带一轴、两心多点」与四至、面积为公开已知；地块 polygon、容积率、高度、密度、退线仍待正式图则。本包用空 `constraints.geojson` 登记缺口，把「结构已知、强度未知」写成工作纪律，不把新闻面积升级成图则 [depth:risk_missing_data] [source:HD-JINGZHANG-BLOCK-PLAN-20260811]。

### 在地调研：五道口—大钟寺日常生活的空间证据（证据分级）

本页把诊断钉到可核验的在地证据上。证据分三级：**A＝官方或权威媒体公开报道（注明来源日期）；B＝公开学术/设计文献；C＝待现场核验（附拍摄清单）**。本页不放任何现状照片——真实影像只能来自现场，C 级清单完成前，相关设计判断保持概念级。

## 三层范围工作框架

公告确定三层工作：统筹研究约 43.6 km²，回答 AI 创新生态与未来城市形态；总体设计约 11.4 km²（京张遗址公园周边 1–2 km），达到控规深度城市设计；重点区域合计约 368.4 ha，达到规划综合实施方案深度。本方案把三层转译为同一条工作方法——**Openline**：不是新画红线，而是把遗产廊道、慢行缝合、产业锚点与 Open Ticket 票制叠成可加入的市民路 [standard:PROJECT-OFFICIAL-ANNOUNCEMENT] [depth:three_level_scope_framework]。

![触媒意图如何挂在 Openline 上](assets/figures/land-use-structure.png)

总体概念命名为「何以京张：The Openline 100」。中文问「何以」——一百年前何以争得路权自立，这一百年何以把路权续写成可继承的市民票制；英文 Openline 是路，Open Ticket 是票，Join · Verify · Exit · Inherit 是四道闸。空间结构叠合已批街区控规后是：**一带（双线 Openline 主脊）+ 一轴（中关村大街）+ 两心（五道口 Question · 创新策源地 / 大钟寺 Adoption · 智能原生街）+ 一核（众智园 · 花园型创新街）+ 东西缝合**。临时足迹只作淡约束；图面强调廊道、节点与活动层，不让粗略外形主导构图 [data:geometry/site_boundary.geojson#SITE-001] [depth:overall_spatial_structure] [source:HD-JINGZHANG-BLOCK-PLAN-20260811]。

**驿站建筑概念（端侧算力驿站 · 形态八题第 4 题落地，以 E-02 为先行原型）：**

- **体量与界面：** 约 600–900 m²、两层；首层全开放，执行「三可」（可进入 / 可发生 / 可退出）；背街面设服务院，设备物流与公共慢行分行。
- **三个部件：** ① **响应站**——未呼先应人工坐席与智能体界面并置，人工始终在场；② **机器人巢**——背街面，充电 / 调度 / 编号可投诉，与公共空间物理隔离；③ **余热暖座温室**——端侧算力余热供给的可坐空间：冬天是暖座，夏天是荫棚，算力的温度可坐可触。
- **能源与接口：** 光伏廊架兼遮荫；预留接入「第三条轨」浅埋公用脊的接口位；井盖刻接口容量，井盖即 API 文档。
- **构造：** 可拆装、材料银行登记、低扰动基础；一次技术换代只换模块，不拆驿站。
- **禁忌：** 公私算力物理隔离；供应商另行授权；不做说教装置、不做个人追踪；任何场景试题可一键关闭。

**两翼共同的成功判据（自检）：** 西翼——不进入任何封闭写字楼，能否在大街上碰上四张接口桌中的至少一张（必须能）；东翼——沿小月河走 20 分钟，能否碰上至少一个正在出题的真实场景、且能拒绝参与（必须能）；两翼——都不另起园区围墙（必须没有）。

**诚实边界：** 两翼节点均为概念落点，无宗地权属与现状测绘；小月河蓝线、防洪与遗址保护范围待正式资料；驿站原型须在驿站专项（OL-05）与权属、市政容量确认后深化。现场核验清单增补：P-09 中关村大街三节点首层界面与遮荫现状；P-10 小月河全线步道连通性、遗址保护标识与 800–1000 m 站距实测。

#### 信息图视觉规范（Sasaki v1.1 · 图面表达标准）

全案图面——五张必交图、「走进去」氛围图、A0/A3 展板与电子展板——统一执行 Sasaki 风格城市设计视觉规范 **v1.2**（BOARD v1.1 WINNING + 地点剖面）。取色与版式以下列要点为准，不另挂投稿包外文件。要点如下：

**设计哲学：图即思考。** 一张图只讲一个观点，标题即结论；复杂论证用「问题 → 机会 → 策略 → 空间 → 场景」图组序列完成。同一张图须同时通过三类读者检验：政府读得出格局与可实施性，开发商读得出价值与密度，公众读得出「我的生活会怎样」。人的尺度永远在场；生态为底盘，建设量是嵌入物。

**轴测与五层模型。** 全部轴测图统一平行投影（无灭点、尺度可量测、同角同朝向）：总体 30°/60° 平面斜轴测，节点 45° 等轴测，剖轴测沿主轴剖切，爆炸轴测与总体同角竖向拉开。所有分析图遵循自下而上五层：① 基底（地形水文，浅灰蓝/米白退让）→ ② 生态（绿色明度梯度，强调网络连通而非斑块）→ ③ 基础设施（中性灰、线宽分级）→ ④ 功能（功能色块或白模体量）→ ⑤ 活动（人物剪影与暖色点缀——唯一允许高饱和的层，任何情况下不被下四层压住）。爆炸轴测层间等距、0.1pt 引导线对齐、每层配一句 ≤12 字问句标注，且必须回扣一张合成图证明分层逻辑能「合回去」。

**生态配色（唯一取色来源）。** 基底三色：米白 `#F7F5F0`（默认）/ 浅灰蓝 `#EEF2F3`（滨水水文主导）/ 暖灰 `#E8E6E1`（建成区密集）。生态与功能色板：深绿 `#2D6A4F`（生态保育）、中绿 `#52B788`（城市公园）、浅绿 `#95D5B2`（社区绿地）、黄绿 `#D8F3DC`（草甸/屋顶绿化）、水蓝 `#168AAD`（水系骨架）、浅蓝 `#A9D6E5`（雨洪湿地）、珊瑚橙 `#E76F51`（活力节点）、暖橙 `#F4A261`（混合功能）、赭黄 `#E9C46A`（活动事件，仅第⑤层）、灰粉 `#B5838D`（创新政策区，克制）。禁忌：禁纯红 `#FF0000`、纯蓝 `#0000FF` 及荧光色；全图主色 ≤5 个色相；绿蓝为主角、建设量为配角；高饱和暖色面积 ≤ 图面 10%；同一色相跨图必须同值，不凭感觉取色。

**图面技术细则。** 线宽四级：外轮廓 0.5–0.8pt / 次级边界 0.3pt / 内部细节 0.15pt / 等高线与引导线 0.1pt。中文思源黑体或等效人文无衬线，西文 Helvetica/Avenir，图内字号 ≥6pt。人物为尺度准确的简洁剪影，植物有季相与冠幅变化。单层 45° 定向软阴影、透明度 15–25%，禁多重投影与镜面反射。标注引出线 0.1pt、文字 ≤ 两行、问句式优先。导出：汇报 150dpi / 展板 300dpi，sRGB，保留分层源文件归档。

**渲染质感六修正（针对 AI/程序化出图）。** ① 爆炸轴测每层承载真实空间内容（等高线+水系 / 成群树冠 / 真实路网 / 有高度有明暗侧面的体量 / 成组人物场景），杜绝空白灰板；② 大面积低饱和 + 小面积高饱和强对比：基底 S 5–15%、生态绿 S 40–60%、锚点橙蓝 S≥70% 且面积 ≤10%；③ 落地感：层板有可见厚度，45° 定向软投影 + 物体根部接触阴影（AO），板厚侧面暗于顶面 10–15% 明度；④ 结构边线一律 crisp 矢量线 `#37474F`（0.1–0.8pt 四级），道路中性灰分级、慢行暖灰虚线，手绘晕染只允许发生在色块纹理内部；⑤ 人物为姿态化剪影（骑车、闲坐、遛狗）、成组出现、密度 ×3，配长椅/自行车架等场景道具；⑥ 版式去 dashboard UI 语言：大标题左对齐深灰、图占画面 70%+、图注一行一句、侧栏只放图例不放段落。

**水彩×矢量双层语言。** 结构是矢量的，气质是水彩的：用地边界、道路红线、轮廓等结构性边线一律 crisp 深灰 `#37474F` 矢量线；绿地、水面、铺装等色块填充走水彩晕染（不透明度 60–80%、边缘羽化 2–4px、Multiply 混合），整体叠纸纹 5–10% 且不干扰文字细线。树冠为松动外形的笔刷簇、同树种 2–3 种明度（禁正圆矢量填充）；水面 `#A9D6E5` 平涂 + 5–8% 明度渐变或稀波纹线（禁 CAD 式纯色）。边界共存规则：水彩色块的轮廓线仍须为干净 0.3pt 矢量线，晕染只发生在 fill 内部。分工：正式分析图矢量为主、水彩仅作底色纹理；「走进去」氛围图走水彩手绘轨——轴测轨与水彩轨双轨并列为强制基准，禁止效果图回退硬边图解。

**出图检查清单（任一不符即退回）。** 视角朝向与全案轴测一致；五层顺序正确且活动层未被压住；每层有真实内容、无空板；色值取自规范色板、主色 ≤5 色相；高饱和锚点色 ≤10%、基底低饱和但不洗白；人物成组、有姿态、尺度准确；标题即结论、一图一观点；爆炸轴测配回扣合成图、层板有厚度与三级阴影；线宽四级可辨、晕染仅在色块内部；版式无圆角卡片等 UI 元素、侧栏仅为图例；政府/开发商/公众三类读者各有对应图面；效果图承诺的材质与空间尺度可追溯、可兑现。

### 国土空间与产业融合的创新思路（讨论级）

在不改写法定控规的前提下，本方案提出三条「空间—产业」工作原则 [standard:MOHURD-URBAN-DESIGN-MEASURES] [depth:overall_spatial_structure] [source:HD-JINGZHANG-BLOCK-PLAN-20260811]：

1. **廊道优先于地块填空**：先锁定 Openline 双线与缝合可达，再谈地块触媒；避免产业园式大地块打断步行。控规已把绿带写成更新引擎，本方案把增量放在贴边，不重做已开放的廊心。 
2. **制度差 > 业态清单**：三区差异首先是开放规则（全栈研发与治理 / 可提问 / 可采纳）。控规点名的大模型、智能体、具身智能是业态方向，不是三个园区的同一张功能表——大钟寺负责城市采纳，五道口提出原创问题，众智园完成全栈研发、工程化与治理协同。
3. **结构已知、强度未知时用界面与首层协议控风险**：街区层面「一带一轴、两心多点」已批；容积率/高度仍 `unknown`。用首层开放率、连续遮荫、慢行优先断面与公共组件库约束城市体验，而非编造 FAR。存量路径优先老厂房与低效楼宇，不把新闻里的卫星制造厂科技园写成已纳入实施。

### AI 时代城市形态创新：八题与前瞻矩阵（概念专项，全文见附录 A）

**理论地基一句话：** 每次通用技术革命都以"成本坍缩 → 区位重排 → 旧范式变城市病"的逻辑重写城市形态——蒸汽坍缩物资位移成本带来站台城市，电力带来摩天楼，汽车坍缩个人位移成本留下宽马路与「看得见、走不通」。**AI 坍缩的是认知与协调成本**：程式化认知变廉价后，溢价的是只能当面完成的四件事——默会知识、信任与验证、意外相遇、责任承担。故 AI 创新带不是更大的办公室，而是一台**信任基础设施**；形态任务一句话——**把「验证一件事」的空间成本降到最低**。

八个现在就能开工的形态动作：可编程街道（4D 分区）、机器人路权四级断面、能源—数据公用脊、端侧算力驿站、开源院落、可核验首层 + 机器可读形态代码、离线庇护所、试验场即公园；五域前瞻矩阵（技术·经济·社会·生态·治理 × 信号→触发→响应，不预测、只预埋）、分支稳健与不变量清单（**变量预埋接口，不变量焊死形态**）——全文见**附录 A**，全部量化值为概念量级、不伪精确。

### 总体空间结构：一带一轴 · 两心一核 · 双线 Openline · 三缝合

空间结构落实为可核对的图层语言，并与已批街区控规对读 [depth:overall_spatial_structure] [source:HD-JINGZHANG-BLOCK-PLAN-20260811]：

1. **Openline 主脊（N–S）＝控规「一带」。** 贴京张遗址公园产业创新带，采用**双线**：
   - **L1 历史证据线（Fact Line）**：慢行优先、遗产叙事、树冠连续 [data:geometry/roads.geojson#ROAD-FACT-001]；
   - **L2 Openline 服务线（Openline Spine）**：驿站、场景入口、端侧原型与导视主轴 [data:geometry/roads.geojson#ROAD-SPINE-001]。
   双线并行而非重叠：L1 保「走得慢、读得懂历史」，L2 保「用得上、接得上服务」。廊心公园已开放，主脊的城市设计增量在两侧贴边。
2. **中关村大街＝控规「一轴」＝西翼科技服务的空间载体。** IP、资本、标准接口沿此轴布置，与南北主脊在五道口正交；不是另画一条平行大道，也不把西翼写成高校园区。
3. **三条东西缝合**：北缝合服务众智园腹地与清河界面（**征集总体内、本份街区控规公开北界之外**，接二期已建成的鱼骨状慢行）；中缝合对准原点—五道口—清华东路西口（两心之一）；南缝合对准大钟寺智能原生街与站域四象限（两心之一） [data:geometry/roads.geojson#ROAD-STITCH-M]。缝合是「研究—设计—实施」清单入口，不是已批准道路工程。知春路、四道口作为控规「多点」挂在 L2 上，不另立核。小月河场景翼走河廊，不占用南缝合冒充东翼。
4. **两心 + 一核**：五道口 / 原点 = Open Question（创新策源地），大钟寺 = Open Adoption（智能原生街），二者是已批两心；众智园以**花园型创新街**为片区概括、以**可升级的城市主板**承载全栈协同，属于**征集三区必做**，但本份街区控规公开四至未覆盖——禁止把三区画成三个并列的「心」，也禁止写成任务书规划外 [data:geometry/key_areas.geojson#PROV-KEY-001]。

### 竞赛水位｜空间设计含量优先

这是一场**城市设计竞赛**，不是策划咨询标书。本包坚持：制度与协议必须能落到可走、可坐、可剖的空间；图面以场景氛围、节点放大、剖透视与物质转译为主干，文本为辅。当前空间图件栈（必交五图 + 铁轨显形 + 「走进去」氛围图 + 缝合甲板 + **重点区中标级五件套**）用于把评审的注意力拉回**人如何进入这片地**——资料不全处仍敢给概念，并显式标注 provisional / 待红线深化，拒绝虚假精确 [depth:overall_spatial_structure]。

### 物质遗产五种转译｜让铁轨「长」进空间

不要只写「遗产廊道」——铁轨必须变成可触、可坐、可问、可听的城市构件；评审必须看见**京张的钢轨扎进土地肌理** [depth:blue_green_public_space] [data:geometry/roads.geojson#ROAD-FACT-001]：

![铁轨显形：钢轨坐在这条地面上](assets/figures/rails-in-fabric.png)

![让铁轨长进地面：五种物质转译](assets/figures/heritage-five-translations.png)

| 层 | 转译动作 | 空间做法（概念） | 禁忌 |
| --- | --- | --- | --- |
| **地面层** | 轨作铺装 | 保留段铁轨不做围栏隔离，嵌入步行道；人可走在轨上，像走在历史上 | 不把轨变成不可达展品 |
| **剖面层** | 考古式展示沟 | 关键节点切开地面，暴露原始路基断面与道砟层理，加护栏与解说 | 不大规模开挖未评估区 |
| **设施层** | 轨成家具结构 | 旧轨转用为栏杆、座椅骨架、灯柱基座（清权与安全检测后） | 不伪造「原址原件」叙事 |
| **叙事层** | 里程思辨碑 | 约每公里一块碑：不刻编年史，而刻 AI 伦理追问（如「算法偏见如何被看见？」），与历史里程并置 | 不娱乐化、不歪曲京张史 |
| **声景层** | 蒸汽节奏 × 数据白噪 | 选定段落保留或模拟蒸汽机车节奏性声响，与低音量数据流白噪交替，形成时空对话；可关闭 | 不做扰民噪声装置 |

组件进入公共空间组件库，随 Inherit 版本化；声景与碑文须许可与人工审核后试点。

五种转译是**显形**。开篇第三章「以人为轨」是**显魂**——考古分级 A/B/C、口述空位「＿」与三次转身见 `heritage-soul`。显形不另立第四套遗产品牌；人字坡只作铁路解剖学，不复活「人字轨」。

用地按国土空间分类语义完整覆盖提交边界、无缝无重叠，作为概念触媒分区而非法定图则 [standard:MNR-LAND-USE-CLASSIFICATION-GUIDE] [data:geometry/land_use.geojson#LU-001] [depth:land_use_layout]：

| 分区角色 | 意图 | Openline 关系 | 证据 |
| --- | --- | --- | --- |
| 西岸研发与协作带 | 全栈研发、开放提问、评测与开源协作 | 贴 L2 西侧，首层可协作/可发布 | [data:geometry/land_use.geojson#LU-001] |
| Openline 蓝绿公共脊 | 遗址公园活力带、慢行与树冠 | 承载 L1/L2 与三个地标 | [data:geometry/green_space.geojson#GREEN-SPINE-001] |
| 东岸生活与转化带 | 人才生活、社区服务、近校转化 | 缝合线接入高校/社区腹地 | 见 land_use 分区图层 |
| 南端智能原生街 | 智能体 / 终端 / 内容消费、数据会客、国际交往 | 大钟寺重点区首层协议；站域四象限只做到达 | [data:geometry/key_areas.geojson#PROV-KEY-003] |

**界面与首层协议（街区结构已知、地块强度未知时的城市设计替代工具）：** Openline 两侧建议连续开放首层（展示/发布/服务），禁止长段封闭围墙；路口视距与无障碍连续；遮荫树列优先于装饰性铺装。以上为设计建议，待权属与图则确认。

### 众智园 · 花园型创新街（AI 自主创新加速区 · 可升级的城市主板）

**真实使命与规划地位：** 众智园不是以参观、消费或单次测试为主的科技园。任务书赋予它的核心职责，是建设 **AI 全栈自主创新体系**，并形成中国参与全球 AI 标准、安全与治理讨论的长期能力。它是征集范围最北部的必做重点区，公告面积约 192.1 ha，锚点为中关村东升科技园学北园，任务明确要求回应五环路、清河和花园型创新街区。2026-08-11 获批街区控规的公开四至北至成府路，未覆盖本片；这不影响详细设计继续开展，但不能把众智园写成该控规已批「第三心」 [source:OFFICIAL-ANNOUNCEMENT] [source:AGENT-TASKBOOK] [source:HD-JINGZHANG-BLOCK-PLAN-20260811]。

**设计命题：** AI 技术几年一代，城市空间几十年一代。若按今天的产业清单把每栋楼一次性写死，下一轮技术变化就会带来搬迁和反复拆建。众智园因此被设计成一块**可升级的城市主板**：长期稳定的是花园、慢行、服务交通、共享技术平台和治理接口；持续变化的是研发团队、实验室配置、设备与应用场景。它不是把电路板造型贴到地面，而是一条规划规则：**共享底板保持稳定，技术单元持续更新；让 AI 上下游成为步行可达的邻居，让每次升级都有标准与责任接口。** [depth:overall_spatial_structure]

**现状不是白纸（A 级，不重做）：**

#### 空间公式：一块共享底板 · 五类可升级单元 · 一条全栈协作街 · 一个全球治理中心

**共享底板**是长期不重复建设的公共能力：连续花园与无障碍慢行、公共首层、共享会议与工程服务、设备物流和维护接口，以及经授权的算力、数据、网络、能源和安全服务。底板不等于把所有基础设施集中进一栋楼，而是让不同组团能够按统一接口接入、退出和升级。

**五类可升级创新单元**把全栈关系变成邻里关系，而不是五座彼此封闭的园区。单元边界可随技术演进调整，名称表达当前任务而非永久用地性质 [data:geometry/key_areas.geojson#PROV-KEY-001] [data:geometry/buildings.geojson#BLDG-PROOF-001]：

| 可升级单元 | 当前全栈任务 | 共享空间配置 |
| --- | --- | --- |
| 芯片与算力协同 | 芯片、计算系统、端侧基础设施及能效协同 | 可适配技术大厅、共享装卸与运维接口 |
| 基础软件与工具链 | 基础软件、开发框架、工程工具与互操作 | 联合工程工作室、兼容性空间与安全协作室 |
| 数据与模型 | 基础/行业模型、数据治理、训练与评估 | 受控数据空间、模型工作室、人工复核与文档接口 |
| 智能体与行业应用 | 城市智能体、企业智能体、应用集成与服务设计 | 场景工作室、运营室、跨团队协作空间 |
| 具身智能与场景 | 机器人、端侧设备及受控场景集成 | 可重组场地、安全隔离、设备工位与操作员界面 |

**全栈协作街**从学知园站、学北园共享首层接到既有鱼骨慢行、公园北段、清河与箭亭桥。它是研发协作、人才服务、设备预约、成果发布与公共沟通的共同地址，不是新造一条仪式性大道。五类单元的公共首层面向同一条街，共享会议室、组件库、餐饮休息和技术服务放在相邻单元之间，让上游部件到下游应用不再经历一串门禁。

**全球 AI 标准与治理中心**与研发单元并列为核心功能，面向清河公共界面设置标准工作坊、安全与伦理协作、开源治理、国际论坛、人工复核和公众资料空间。它不是偶尔启用的会议中心或荣誉展厅；主要产出应是双语标准草案、接口规范、事件复盘、责任记录与可复用治理组件。每个技术单元升级前，都要在这里说明系统边界、数据权利、责任主体、人工复核点、维护责任与退役路径 [standard:PROJECT-AGENT-OPEN-CALL-TASKBOOK]。

#### 城市与建筑如何跟着团队成长

团队的成长路径不再是「孵化器毕业后搬走」，而是：**进入共享底板 → 使用小型研发单元 → 接入公共技术平台 → 扩展为联合实验室或工程团队 → 完成标准、安全与风险协同 → 扩展为独立楼层、楼栋或专业组团。** 收缩与退出同样被设计：团队归还部分单元，设备与数据按协议迁出，空间恢复到可再次使用的标准状态。

| 层 | 长期稳定的部分 | 可以持续升级的部分 |
| --- | --- | --- |
| 城市底板 | 慢行与无障碍、公共界面、消防与服务通道、蓝绿空间 | 可逆家具、活动与局部场地组织 |
| 建筑底板 | 可保留的大跨结构、院落、结构网格与核心筒 | 隔墙、实验室配置、共享工作室与首层界面 |
| 技术层 | 标准化的装卸、维护、网络与安全接口 | 计算模块、设备工位、受控房间与软硬件环境 |
| 治理层 | 责任记录、人工复核、公共说明、事件与退役程序 | 标准版本、评估方法与协作议题 |

拆改留先看测绘与结构条件：大跨与院落优先保留，封闭首层在业主协议下分时打开；新增技术空间优先采用可维护、可替换的构造。一次技术换代应尽量只更换模块和内部配置，而不是重建一个园区 [depth:retain_renovate_demolish]。

#### 五个在地空间动作

1. **以学北园为首发主板，不重造校园。** 盘点现有楼宇、院落和共享设施，选择可改造首层作为共享技术与人才服务入口；设备物流从服务侧进入，公共慢行从花园侧进入。
2. **接上现有鱼骨慢行，不另画一套道路。** 全栈协作街利用学知园站—月泉路—学北园—公园北段—清河的既有关系补齐断点，访客、员工、设备物流与应急流线分层组织 [data:geometry/roads.geojson#ROAD-STITCH-N]。
3. **让五类单元沿同一条工作街相邻。** 研发空间可以重组，公共技术平台和会议服务放在单元交界处；创新发生在接口，而不是各自门禁后的孤岛。
4. **把全球治理放进研发过程。** 治理中心紧贴技术单元和清河花园界面，标准、安全、伦理与国际协作从项目早期介入，而不是产品完成后的补审。
5. **把花园作为创新基础设施。** 公园和清河承担降温、雨洪、慢行、户外讨论、国际交往与人才日常生活；产业展示嵌入共享首层，只展示经授权成果、标准演进与治理贡献，不做科技主题乐园 [data:geometry/green_space.geojson#GREEN-PROOF-001]。

**15 分钟城市主板路径（讨论级）：** 学知园站 → 月泉路共享门厅 → 学北园公共技术平台 → 可升级单元样板庭院 → 全球 AI 标准与治理中心 → 清河花园客厅 → 公园北段。对访客，它应讲清「底层能力—工程工具—模型与智能体—应用—标准治理」的完整关系；对工作者，它意味着从研发单元步行可达共享平台、治理服务、轨道入口和花园休息空间。正式道路红线、门禁和权属到位后再实测，走不通就调整入口，不在图上宣布完成。

**公共空间与场景接口：** 共享工作庭院、可预约会议与工程服务、组件库、无障碍环线、多语导视、遮荫、清河文化与低碳展示。S-02 安全治理沙盒作为受控技术工具嵌入治理中心与具身单元；S-06 清河低碳创新廊成为共享绿色底板。卡 03 写的是时间分层，不是园区导览：共享底板是不变层，五类单元是可变层，治理门是许可层。治理中心的公众议事廊是治理门的公众面（遗憾条款、地层墙），不再当众智园名片。15 分钟路径只检验换代后是否仍可读。学北园约 3.53 ha 是种子，不是征集重点区 192 ha。

**成功判据：** 技术模块能否在不重建街区的情况下升级；小团队能否在园内扩展、收缩或退出；上下游团队能否共享一条连续工作环境；每个进入场景的系统是否都有明确的人工复核与责任接口；公众能否在不进入受控实验室的前提下理解全栈体系如何工作。

**诚实边界：** 当前没有众智园官方精确 polygon、地块图则、权属、蓝线、道路红线和经核验的建筑/市政容量。本节不声称业主同意、国家平台落地、运营主体确定、工程获批或具身智能获准上路；算力、能源、消防、数据安全和防洪需求须在正式资料和专业专项到位后校核 [data:geometry/key_areas.geojson#PROV-KEY-001]。

**分期：** **0–1 年**完成建筑、接口、设施容量与权属普查，接续既有慢行，启动共享门厅、开发者工作坊和标准议题的轻量试点；**1–3 年**改造一组可升级研发单元，启动一处公共技术平台和轻量治理中心，实测 15 分钟路径与团队扩缩容过程；**3–10 年**在正式边界、强度、能源、市政、安全与运营责任确认后扩展五类单元网络和全球治理中心，并深化五环区域交通联系 [depth:phasing_implementation]。

### 北京 AI 原点社区 · 创新策源地（Open Question · 可提问）

**定位：** 近校型开源协作与成果转化社区——这里回答「问题如何被公开提出、人才如何留下来协作」。**规划地位：** 对位已批两心中的**五道口中心**（人工智能产业创新集聚区、顶尖人才交流中心，草案公开口径）；与官方「AI 原点社区 · 创业首选」同核，不另立地名 [source:HD-JINGZHANG-BLOCK-PLAN-20260811]。

**设计命题：** 任务书给原点的是世界级 AI 创新生态。官方三个产品是全球首发地、栖息地、全要素生态服务站；政策层已经说尽。本区回答政策买不到的空间问题——实验室成果如何过墙。近校转化、开源发布、人才停留是片区工作。一句话：**不经授权窗口，校园成果不能上街。** 官方约 3 km²（五道口核心）不以征集重点区约 104 ha 替代。

片区概括是**创新策源地**——官方定位「创新策源、创业首选」的空间落实；片区产品是**策源过墙生态**。卡 01 写的不是走廊观光，而是策源过墙的必要关系（附录 C-1）：权→配→证→用→遗。约 200 m 走廊只是切片，不是 104 ha 的名字。Kilometer Zero 退成缝合甲板上的测量钉（讨论 φ150 mm，旧轨钢），不是仪式广场 [data:geometry/public_space.geojson#PUBLIC-KM0] [data:geometry/public_space.geojson#PUBLIC-JOIN]。

**五个必要环节（概念，非正式控规；对位卡 01；跳过任一步原点只是近校园区）：**

1. **权（授权窗口）。** 过墙捆绑的是许可，不是人流：使用范围、期限、可否开源、出事找谁。没有许可条，匹配与首发都是违法或违约。**不得声称已获高校或业主同意** [data:geometry/buildings.geojson#BLDG-QUESTION-001]。
2. **配（八找并置）。** 政策、资金、算力、人才、伙伴、智力、空间、场景必须在步行内成交。跑四个园区才找齐，全要素服务站就是目录。栖息地挂在匹配边上，让人留得够久把八找做完，不另起创业宿舍品牌。
3. **证（开源 / 首发）。** 官方「全球首发地」只在公开、可失败的声称里成立。关起门转化是技术转移办公室，不是策源地。独立运营见 S-01。
4. **用（社区微场景）。** 食堂、配送、导览、物业做真实交易。没有非表演客户，首发是路演。脱敏摘要回流众智园，供卡 03 升级许可。
5. **遗（失败案例库）+ 缝合甲板。** 失败不留给下一届，生态每届清零。记录可撤、可改写。OL-07 把校园侧接到街上——谁能不走甲板从学校进公园，墙还在，只是没被设计。

**成功判据：** 不经授权窗口校园成果能否上街（必须不能）；八找是否必须跑四个园区（必须不必）；不走缝合甲板能否从校园进公园（必须不能）；3 km² 官方口径是否被画进 104 ha（必须没有）。
**诚实边界：** 甲板待红线与桥墩权属；授权窗口与失败案例库落在社区界面，须业主、街道与高校协议；不把平面符号再写成地标。

### 场景卡 01｜AI+原点社区 · 策源如何过墙（摘要 · 详案见附录 C-1）

**核心概念：原点生产的是可过墙的策源，不是近校园区。** 官方三个产品（全球首发地、栖息地、全要素生态服务站）政策层已经说尽。本卡写的是它们之间的**必要关系**：没有授权，八找是非法匹配；八找不在步行内，全要素服务站是目录；没有可失败的公开首发，全球首发地是会场；没有社区真实交易，首发是表演；失败不留给下一届，生态每届清零。空间只是这五环的落点，200 m 走廊是切片。官方约 3 km² 不以 104 ha 替代。完整因果链与自检见附录 C-1。

### 场景卡 03｜众智园 · 全栈如何升级而不拆城（摘要 · 详案见附录 C-3）

### 五道口缝合甲板（概念性工程方案）

选中缝合最痛断点——**五道口**：铁路与城市道路长期把两侧「看得见、走不通」。在尚无精确红线的前提下，提出结构概念方案，图脚强制声明「待红线确认后深化」[depth:traffic_rail_slow_parking]。

![五道口缝合甲板：切开才能认的地点](assets/figures/wudaokou-stitch-deck.png)

**结构概念：** 利用既有铁路桥墩（或同位置可承接的墩位逻辑）架设**三层缝合甲板**——不发明未论证的深隧，而做可逆、可分期的跨线公共结构：

| 层 | 功能 | 体验意图 |
| --- | --- | --- |
| **下层** | 电动车与物流慢行通道 | 把冲突车流从步行层剥离 |
| **中层** | 步行、自行车与临时市集 | 日常缝合；可办近校/社区市集 |
| **上层** | 朝向京张遗址公园的观景平台 | 把「看得见公园」变成「走得到廊道」 |

**设计勇气边界：** 本方案给出剖面逻辑、层间关系与接驳口概念位置；**不**给出跨度、荷载、施工组织或已批准线位。文保、桥墩权属、道路红线与噪声控制到位后，整段进入工程深化；深化前仅作城市设计讨论武器。项目编号进入清单 **OL-07**。

市政与公共服务：创新服务平台、人才生活服务、分布式能源与端侧算力作为 Openline 驿站原型；管线、消防、防洪资料缺失时列为深化前置条件。`constraints.geojson` 刻意保持空集合并登记缺口，优于编造控制线 [depth:municipal_new_infrastructure]。

### 分期资本逻辑：每期同时回答四问

可落地性不是把时间轴画得更细，而是每一期同时回答：**建设什么 / 谁出钱 / 谁运营 / 收益怎么回流公共空间**。三种融资情景——政府专项债 / 片区统筹 / 企业认养——是接力，不是三选一。三期企业认养受 Open Ticket 许可链约束，公共界面仍属公共。**以下全部按可比较的概念情景陈述：每一情景逐项给出适用前提、审批程序、失败条件与 B 计划；任何情景都不是已确定的融资安排，年份只是分期锚点，不是资金承诺。**

**可逆即低风险。** 五道口甲板螺栓连接、不浇筑：资产可迁移，示范段错了不是沉没成本——这是敢先做一期的真正理由。

| --- | --- | --- | --- | --- |
| **一期 2026–28 · 可逆示范段** | 原点段 L1 地面约 600 m + 甲板示范约 400 m（可逆钢木，约 3,200 ㎡） | 情景 A：政府专项债 + 市级遗址公园专项 | 街道 + 公园管理处联合工作站 | 市集摊位 + 活动周 → 公共维护基金 |

底部回流环：土地溢价 → 地下空间 → 场景运营 → 公共维护基金 → 回到街与甲板。右栏三种融资情景各自明示风险，主张接力；每一情景都有自己的 B 计划，接力断在哪一棒，方案降级但不死。

## 附录 A｜AI 时代城市形态创新：形态八题 · 前瞻矩阵（全文）

> 本附录自正文统筹研究章移入，内容不变；正文仅保留理论地基与一句话索引，以保持 Openline 100 单一统领的叙事主线。

**理论地基：** 每次通用技术革命都以"成本坍缩 → 区位重排 → 旧范式变城市病"的逻辑重写城市形态——蒸汽坍缩物资位移成本带来站台城市，电力带来摩天楼，汽车坍缩个人位移成本留下宽马路与「看得见、走不通」。**AI 坍缩的是认知与协调成本**：程式化认知变廉价后，溢价的是只能当面完成的四件事——默会知识、信任与验证、意外相遇、责任承担。故 AI 创新带不是更大的办公室，而是一台**信任基础设施**：Openline 规则是其协议层，以下形态八题是其物质层；形态任务一句话——**把「验证一件事」的空间成本降到最低**。五个物质动因：智能具身化、空间可排程、基础设施分布化、生产组织微粒化、感知全面化。完整机理、概念指标与分期见**附录 A**，全部量化值为概念量级、不伪精确。

## 附录 C｜三区生产函数详案（卡 01–03 · 1:1 对三重点区）

> 正文保留摘要。本附录写三区生产逻辑——少一步即假——不是观光站。未呼先应见东翼索引 S-09。

### C-1 场景卡 01｜AI+原点社区 · 策源如何过墙

**本卡生产什么：可过墙的策源。**
> 官方给原点三个产品——全球首发地、栖息地、全要素生态服务站——政策已经买齐。缺的不是又一座孵化器，而是它们之间的必要关系。没有授权，八找是非法匹配；八找不在步行内，服务站是目录；没有可失败的公开声称，首发地是会场；没有非表演客户，声称是路演；失败不留给下一届，生态每届清零。200 m 走廊是切片。官方约 3 km² 不以 104 ha 替代。

**墙不是一道门，是四项许可绑在一起：** 谁拥有、可否公开、用到哪里、出事找谁。人可以从校园走进公园；许可过不去，策源就还在墙里。

**一句话场景**：许可条没办下来，转化街拒收原型——不是窗口不热情，是后四环会全部变成违法。许可办完，八找仍要跑四个园区，她不会留下来完成首发。食堂付了第一笔钱，失败被下一届读到：原点开始像生态，而不像每学期清场的近校园区。

**因果链（不是观光站；跳过任一步即假）**

```
权（Join）──► 配 ──► 证 ──► 用（Verify）──► 遗（Exit → Inherit）
许可过墙      八找步行成交   公开可失败声称   非表演客户         负知识留作公地
跳过→泄密/违约  跳过→目录     跳过→转移办公室  跳过→路演         跳过→每届清零
```

| 环节 | 它在生产函数里做什么 | 空间落点 | 跳过则假 |
| --- | --- | --- | --- |
| **权** | 让后四环合法。许可条最小必要：范围、期限、可否开源、责任人。地图、72 小时工坊、见面日程替代不了许可。 | 校缘授权窗口 | 无许可的匹配与首发 = 泄密或违约。原点变成无墙的园区。 |
| **配** | 把官方八找从目录变成步行内成交的要素市场。栖息地挂在匹配边上，只为让人留得够久把八找做完。 | 一条可走的并置界面 | 仍要跑四个园区 = 全要素服务站是海报。「10 分钟找伙伴」无法成为空间事实。 |
| **证** | 把「全球首发地」落实为可失败的公开声称。关起门转化是技术转移办公室。失败不进宣传片，进失败案例库。 | 开源发布厅（S-01） | 无公开声称 = 近校办公，不是策源地。 |
| **用** | 需求侧核验。食堂、配送、导览、物业做真实交易。居民知情同意、可退出。脱敏摘要回流众智园，供卡 03 升级许可。 | 社区微场景 | 只有路演客户 = Verify 没发生。原点无法向大钟寺交出可上街的东西。 |
| **遗** | 负知识成为公地。下一届不必付同一笔学费。可撤、可改写；退出者协助注销，不社死。 | 失败案例库；到达仍是 OL-07 缝合甲板 | 失败带走 = 每届清零，不是生态。不走甲板就能进公园 = 墙还在，只是没被设计。 |

**与另两区：** 小月河出题 → 原点把题过墙并公开声称 → 众智园工程化并过治理门 → 大钟寺上街采用 → 失败回流本库与治理门。原点不代替众智园做全栈，不上大钟寺的街。

**自检边界**：不承诺投资与政策待遇；不虚构高校合同；不把 3 km² 画进 104 ha；不做成功学排名；居民不是试验品。

### C-2 场景卡 02｜大钟寺 · 核验过的能力必须能上街

**本卡生产什么：可拒绝的采用。**
> 资格预审公告给大钟寺的是城市型街区，不是领军企业园区，也不是站前装置。深度不在「从地铁走到厅再到社区」的观光顺序，而在三层必须同时成立的结构。未呼先应见东翼 S-09。1733 已是城市更新样本，不是白纸。

**三层并置（不是五站）**

```
        ┌─ 街面法则（主产品）：核验过的能力占用首层；说明条四项；可试用、可拒绝
路过 ───┤
        ├─ 下街例外（分流，不是下一站）：数据要素 / 国际交往 → 1733 既有可预约厅
        └─ 生活剩余（不可让渡）：通学 / 买菜 / 古钟导视
8 分钟到达只检验：上述三层能否被没预约的人碰上；它本身不是产品。
```

**一句话场景**：她没预约。街面上有一件写着「谁核验、失败过什么、出事找谁、如何拒绝」的试用——她试了，拒绝了。数据会客在她不必经过的厅里。东南象限仍能接孩子。营业没有切断她的路。若试用只在封闭厅、数据摊在过道、或通学被展位占掉：大钟寺就不是城市型街区。

**三层分别生产什么**

| 层 | 它在生产函数里做什么 | 空间落点 | 跳过 / 弄反则假 |
| --- | --- | --- | --- |
| **街面法则** | Adoption 的定义：没预约也能碰上已核验能力。说明条四项缺一不准上街。试用可拒绝，否则是广告。 | 总部界面、1733 外沿、公园贴边的连续首层 | 无说明条 = 广告廊。只能进封闭厅才碰上 = 园区展厅。营业切断通行 = 法则对员工有效、对城市无效。 |
| **下街例外** | 不够格上街的东西必须离开公共通行。数据要素要授权清单与审计；国际路演要清权与预约。西翼提供 IP / 资本 / 许可，不在此另造基金大厦。 | 1733 既有可预约厅（S-08 / S-05） | 把厅写成「下一站」= 目的地是商场。数据摊上街 = 泄露的街。新建塔楼 = 不承认 1733 已是样本。 |
| **生活剩余** | 城市型街区的非产业部分不可让渡。产业吃掉通学、买菜、古钟导视，街区就变成园。规划绿地只在贴边可逆插入，不占廊心。 | 东南通学、东北买菜、西北古钟导视 | 四象限被展位或车行切断 = 产业园冒充街区。仿钟、改名中庭 = 用符号代替城市。 |
| **到达（检验，不是层）** | 测试法则对路过者是否成立。既有约 8 分钟路径保持公共通行；东端无障碍 P0；四象限步行。2027 站内归地铁，街面规则留下。 | OL-04 | 把换乘写成全区产品 = 站前装置冒充 72 ha。挖新隧 = 不承认既有路径。 |

**三个冲突（设计必须站队）**

1. 领军企业校园 vs 城市型街区：能力必须在无通行证的首层被碰上。
2. 上街 vs 预约厅：够格上街的才上街；不够格的进厅，不占路。
3. 产业占用 vs 生活剩余：四象限不是街面的配景，是街区仍是城市的证据。

**与另两区：** 上街的东西必须先在原点过墙、在众智园过治理门。大钟寺不发明能力，只采用；采用失败回流治理门与原点失败案例库。

**自检边界**：首层协议须业主与街道同意；不把字节跳动写成已签约业主；不报容积率；街面不是广告廊。

### C-3 场景卡 03｜众智园 · 全栈如何升级而不拆城

**本卡生产什么：可许可的换代。**
> 全栈自主要求模块会被替换；全球治理要求替换必须有人负责；花园型街区要求替换不拆街。学北园约 3.53 ha 是种子，不是 192 ha。国家平台不画成已落地的楼。15 分钟路径是检验，不是导览产品。人机共生落在治理门的公众面，不另立展厅品牌。

**时间分层（不是园区环线）**

```
不变层  共享底板（电 / 网 / 空间 / 市政 / 安防）     ← 换代不拆城的物理含义
可变层  五类单元邻里（可扩、可缩、可退）           ← 全栈是可替换模块，不是五座园
许可层  治理门（人工复核 / 责任 / 退役 / 遗憾条款） ← 换代的唯一合法入口
可读层  全栈说明书（无通行证能读懂关系）           ← 换代之后城市仍可被理解
同一许可出海  底板+门一起走，不另造平行园
```

**一句话场景**：她把设备接到底板上，下午在治理门提交一次模块换代——三个不可通约方案，一条反对写进决议的遗憾条款。明年她扩一间或退一间，街还在。一个没有实验室通行证的中学生走同一条底板，仍能读懂底层能力到标准的关系。若换代要拆街、或换代不必过门、或过门后公众读不懂：众智园就只是会过时的园。

**各层分别生产什么**

| 层 | 它在生产函数里做什么 | 空间落点 | 跳过则假 |
| --- | --- | --- | --- |
| **不变层** | 承诺街区比模型活得长。换模块，不换底板。 | 共享门厅、公共技术平台、市政接口 | 底板跟着模块改 = 换代拆城。 |
| **可变层** | 芯片算力 / 基础软件 / 数据模型 / 智能体应用 / 具身场景做成邻居。小团队 Exit 写进邻里：扩、缩、退不必搬出园。 | 全栈协作街、可升级单元样板庭院 | 五座封闭园 = 全栈是口号。不能退只能走 = 升级驱逐小团队。 |
| **许可层** | 模块换代、上路、对外展示的唯一合法入口。S-02 沙盒是受控工具，公众可见、不可闯入。 | 全球 AI 标准与治理中心的治理门 | 无门的换代 = 无人负责的拆除。门无公众面 = 实验室政治。 |
| **可读层** | 换代之后城市仍可被理解。共享首层只说明全栈关系与治理贡献，不是科技主题乐园。 | 共享首层、清河花园客厅 | 无通行证读不懂 = 国家平台是黑盒。 |
| **同一许可出海** | 出口的是底板+门，不是第二套天际线。五环 / 清河只锁关系，不报线位。 | 同一套接口 | 另造平行园 = 复制天际线，不输出治理。 |

**治理门的公众面（压缩自原议事廊，不另起英文剧名）**

换代许可必须被路过看见，否则许可层是内部手续。感知：聚合数据公开，红开关按下写「此处数据已被公民选择隐藏」。推演：至少三个不可通约方案，标置信度与盲区，不得输出单一最优解。争议：异议登记墙，决议必须回应至少一条反对。决议：遗憾条款由反对者起草、支持者认可，下期先回应执行。遗产：治理地层墙，新砖滑入正面，旧砖侧移仍可见——失败的升级仍承重。接诉即办高频问题可进入推演层。**被算法决定的人，有权看见算法。**

**15 分钟只检验分层是否仍可读：** 学知园站 → 共享门厅 → 公共技术平台 → 单元样板庭院 → 治理中心 → 清河花园 → 公园北段。走不通就改入口，不在图上宣布完成。正式红线到位后再实测。

**与另两区：** 原点交来过墙后的声称与微场景证据；本区工程化并过门；大钟寺只采用过门的能力。采用失败与升级遗憾回流本门与原点失败案例库。

**自检边界**：不声称业主同意、国家平台落地或具身智能获准上路；AI 不得替代政治判断；学北园面积不以 192 ha 替代；能读懂全栈不意味着可以闯入受控实验室。

### D-04 安全治理沙盒（S-02 · 测试验证 · 众智园）

**核心概念：受控测试必须有一扇公众看得见的门。** 沙盒不是黑箱实验室，是治理门的工具间。

| 件 | 内容 |
| --- | --- |
| 用户 | 具身智能与模型安全研发团队、评测专家、公众观察员 |
| 场所 | 众智园治理中心评测间 + 具身智能单元受控场地（物理围栏、独立出入口，临全栈协作街设公众说明界面） |
| 触发 | 团队申请入盒 → 治理门受理 → 签测试协议（含停机条款） |
| 运营 | 脱敏评测集 + 红队日程；说明界面公示「测什么、谁在测、怎么停」；公众可预约旁听 |
| 数据最小化 | 只用脱敏评测集与合成数据；不采真实个人数据；测试日志按季销毁 |
| 人工复核 | 评测结果须专家签字复核后生效；说明界面设人工值守时段 |
| 退出·停机 | 每场地设红色物理停机钮并演练；团队可随时撤场，数据随退出删除并给回执 |
| 指标 | 测试次数与旁听人次、说明界面开放时长占比、停机演练覆盖率、未经授权采集事件数（目标恒为 0） |

### D-05 端侧算力驿站（S-03 · 测试验证 · Openline 节点）

**核心概念：算力像图书馆座位一样可预约、可离席。** 驿站是端侧原型的公共试机位，不是数据采集点。

| 件 | 内容 |
| --- | --- |
| 用户 | 端侧硬件与模型开发者、创客、路过体验者 |
| 场所 | Openline 驿站亭（与 S-09 共享空间、物理隔离；单点原型先行，3–4 点成网） |
| 触发 | 线上预约 → 到店人工核验 → 上机计时 |
| 运营 | 分时预约；能耗日志公示；设备损坏按组件价目赔付；运营现金流覆盖运维的模型见实施经济学 |
| 数据最小化 | 只记预约与能耗，不读设备内容；测试镜像离站即清 |
| 人工复核 | 工作人员在场时段全覆盖；安全事件人工定级后才处置 |
| 退出·停机 | 一键结束会话即清镜像；驿站为可逆组件，可整体关停撤场 |
| 指标 | 预约完成率、单站能耗、镜像清除合规率、运维收支比 |

### D-06 AI 慢行导航（S-04 · 交通生活 · Openline 主脊）

**核心概念：导航默认可关，城市不靠它也能走。** 系统是建议层，物理导视是兜底层。

| 件 | 内容 |
| --- | --- |
| 用户 | 步行与骑行通勤者、通学家庭、无障碍出行者 |
| 场所 | L1 / L2 全线 + 东西三缝合断面（物理导视柱为永久兜底） |
| 触发 | 默认关闭；用户主动开启或扫码即用即走 |
| 运营 | 路线建议 + 断点提示；断点数据供街道排维护计划 |
| 数据最小化 | 只用聚合拥堵与路面状态；不采个人轨迹；端侧计算优先 |
| 人工复核 | 封路、事故等异常推送前须人工确认 |
| 退出·停机 | 一键关闭、无残留画像；系统停机不影响物理导视与通行权 |
| 指标 | 开启率与关闭率并公示、断点修复时长、无障碍路径可用率 |

### D-07 国际路演客厅（S-05 · 产业交往 · 大钟寺）

**核心概念：国际交往用既有厅，不为路演建塔。** 1733 可预约厅是「下街例外」的正面资产。

| 件 | 内容 |
| --- | --- |
| 用户 | 国际访客、路演团队、本地公众（开放日） |
| 场所 | 大钟寺 1733 既有可预约厅（存量物业，不新建） |
| 触发 | 活动预约 + 内容清权审查通过 |
| 运营 | 业主与运营方收场租；公共侧订规则、不分成；清权内容清单随活动公示 |
| 数据最小化 | 报名最小字段；不做人脸签到；影像发布须被摄者授权 |
| 人工复核 | 内容清权人工审；涉外议题配人工合规顾问 |
| 退出·停机 | 内容可撤回；活动可取消，厅回归公共预约池 |
| 指标 | 路演场次、清权通过率、公众开放日占比 |

### D-08 清河低碳创新廊（S-06 · 公共空间 · 清河—小月河）

**核心概念：生态数据全公开，监测本身就是承诺。** 本廊是 A-ECO-001 监测闭环的空间落点。

| 件 | 内容 |
| --- | --- |
| 用户 | 居民、跑团、环境教育者、低碳技术团队 |
| 场所 | 众智园共享绿色底板 · 清河界面，延伸至小月河翼 |
| 触发 | 全天候开放；环境传感数据自动入信托并按季发布 |
| 运营 | 水质 / 噪声 / 热岛传感 + 人工巡检；读数接「生态的数字承诺」看板（Verify 闸公开） |
| 数据最小化 | 只采环境量、不采人；廊道不设人脸识别设备 |
| 人工复核 | 异常读数经人工复核后才发布预警 |
| 退出·停机 | 传感杆可拆（可逆组件）；看板可关，廊道物理开放不受影响 |
| 指标 | 读数公开率、巡检响应时长、廊道使用强度（匿名计数）、对应生态承诺达标率 |

### D-09 数据要素会客厅（S-08 · 测试验证 · 大钟寺）

**核心概念：数据交易在楼下厅里，绝不上街面。** 下街例外规则的合规正面。

| 件 | 内容 |
| --- | --- |
| 用户 | 数据供需双方、合规顾问、审计方 |
| 场所 | 大钟寺 1733 既有可预约厅（与街面物理与规则双隔离） |
| 触发 | 数据产品挂牌申请 → 授权清单审查 |
| 运营 | 授权清单 + 审计追踪 + 合规顾问窗口；交易记录入城市数据信托 |
| 数据最小化 | 只审授权与元数据，不经手原始个人数据 |
| 人工复核 | 每笔挂牌人工合规复核；争议人工仲裁 |
| 退出·停机 | 产品可随时下架；授权可撤回并给删除回执 |
| 指标 | 挂牌合规率、撤回处理时长、审计追踪完整率 |

### D-10 未呼先应（S-09 · 公共服务 · 小月河翼）

**核心概念：人工智能先听懂人，人工永远在场。** 听懂 / 想到 / 办妥；办不了，规范工单直转 12345。

| 件 | 内容 |
| --- | --- |
| 用户 | 居民（老中幼优先）、商户、路人；重点是数字弱势群体 |
| 场所 | 小月河翼 Openline 驿站网络（约 3–4 节点，间距 800–1000 m） |
| 触发 | 语音 / 按键 / 路过三种唤起；红色「我要跟人说话」召唤钮永远可见 |
| 运营 | 高频诉求先办；办不了生成规范工单直转 12345；服务清单与边界公示 |
| 数据最小化 | 不建档、不追踪；会话级上下文，事了即清 |
| 人工复核 | 人工始终在场；任何自动答复可一键转人工 |
| 退出·停机 | 拒绝使用不受惩罚、服务不降级；驿站可关停，电话与窗口渠道不受影响 |
| 指标 | 转人工率、工单一次办结率、响应时长、退出率与零惩罚核查 |

### D-S01 开源发布厅（S-01 · 产业协作 · 原点）

**核心概念：公开议程、人工主持，发布厅不是会场租赁。** 卡 01 的「证」环节在此独立运营，但仍走授权窗口，不另起第二套过墙规则。

| 触发 | 公开议程报名；无授权窗口出具的权属说明不得上墙 |
| 运营 | 人工主持；议程、许可与失败记录当场公示；观众可提问、可离席 |
| 数据最小化 | 只记场次与许可类型，不采人脸、不建开发者档案 |

### D-S07 近校成果转化街（S-07 · 转化服务 · 原点）

**核心概念：授权窗口—原型工坊—发布厅必须连续，缺一环则八找是目录。** 卡 01 的「权→配」界面，不是第二条转化产品线。

| 件 | 内容 |
| --- | --- |
| 用户 | 师生、技术转移人员、企业对接人、社区首批用户 |
| 场所 | 原点近校转化街连续界面（授权窗口 + 原型工坊 + 通向发布厅的步行） |
| 触发 | 成果持有人预约授权咨询；无校/所授权不得进入匹配 |
| 运营 | 人工法务窗解释许可档；步行范围内完成八找并置；不设封闭会员区 |
| 数据最小化 | 只保留授权状态与许可档编号，不建师生画像 |
| 人工复核 | 每份授权人工签字；匹配结果可申诉 |
| 退出·停机 | 授权可撤回；窗口可关，街面通行不受影响 |
| 指标 | 授权办理时长、步行连续率、撤回回执完整率 |
