# 第三章 A3 大钟寺 · AI 产业集聚区

> 本章为「百年京张 AI 创新带」城市设计方案（方案 B）第三章，与前两章 A1「大学城科创织补区」、A2「AI 原点社区」同构于同一哲学命题：**铁路链接物理距离，大学链接思想。AI 时代，最重要的是最大限度链接思想。** A3 负责「思想链接的下游落地」——思想从 A1 矿场出来、经 A2 冶炼厂变成原型，在 A3 出厂码头规模化为产品。

## 3.1 本章定位：A3 是创新带「下游落地端」

A3「大钟寺 AI 产业集聚区」位于三层范围南端（大钟寺一带），公告面积约 72 ha（provisional，见 PROV-KEY-003），**三区中规模最小、产业密度最高**。它是中国**生成式 AI 应用规模化最具代表性的集聚区**——**抖音（字节跳动）大本营**与**火山引擎**（字节系云与 AI 服务品牌）已落地多年。

A3 与 A1/A2 形成「思想 → 原型 → 产品」的下游落点：
- **A1 输出**：基础研究成果、底层模型、原始创新人才；
- **A2 输出**：可孵化创业公司、可路演原型；
- **A3 接收**：在 A2 站城缝合带完成的「从论文到公司」转化，到 A3 进一步实现「从公司到规模产品」的跃迁。

### 「智能原生态 AI 产业聚集区」的含义

与一般「先规划后招商」的产业园不同，A3 是**先有产业、再定规划**：
- 抖音/字节跳动**大本营**——短视频/直播/推荐算法的全球级总部，是中国最大的 AI 应用公司之一；
- **火山引擎**——大模型、推荐系统、内容生成等 B 端输出能力，与抖音共享算法与算力底座；
- 两块招牌共同构成 A3 的「智能原生态」基底——**AI 已经在产出，不在规划中等待实现**。

### 「思想的出厂码头」隐喻

沿用 A1/A2 章末「矿场—冶炼厂—码头」三段隐喻：A3 是最后一公里——思想从矿里挖出、经冶炼厂定型，最终以「产品/服务/应用」的形式向社会规模输出。

## 3.2 定型逻辑：边界精确化 + 5 类地块差异化设计

### 范围四至

| 方位 | 边界 |
|------|------|
| **北** | 大钟寺古钟博物馆文物保护边界 |
| **东** | 京张铁路遗址公园、地铁 13 号线 |

### 用地逻辑：留 / 改 / 增（按地块差异化）

| 地块 | 空间属性 | 用地逻辑 | 主导产业方向 |
|------|----------|----------|--------------|
| **蓝景丽家更新地块** | 新建综合体（A3 核心） | **拆 / 增**（拆除重建） | AI 国际交流中心、智能体与 AI 原生企业总部、数字资产试点、**具身智能测试平台（AI 产品常年展示+测试场所）** |
| **方恒广场、中坤广场** | 存量更新楼宇（现状） | **留 / 改**（功能升级，保留建筑） | AI 内容消费、多模态 AIGC、数字人、内容工具链龙头及上下游 |
| **大钟寺古建北侧缓冲区** | 低密更新空间 | **改**（严控强度，文保敏感） | AI + 文博数字文创、AR 文化试验 |
| **京张遗址公园（东侧）** | 开放公共绿廊 | **留 / 改**（提升为主，不新建） | 产业非正式交流、户外路演、慢行系统 |
| **京仪科技大厦、华杰大厦** | 存量写字楼 | **留 / 改**（功能置换） | AI 知识产权、AI 合规审计、科技投融资、数据配套服务 |

### 5 个重点赛道 ↔ 5 个地块 一一对应

| 重点赛道 | 落地地块 | 空间策略 |
|----------|----------|----------|
| **智能体** | 蓝景丽家更新地块（核心） | 智能体与 AI 原生企业总部 + 具身智能测试平台（AI 产品常年展示+测试） |
| **AI 内容消费 / 多模态 AIGC / 数字人** | 方恒广场、中坤广场 | 存量楼宇功能升级，给字节系与上下游扩张空间 |
| **智能终端** | 蓝景丽家更新地块（具身智能测试平台部分）+ 京仪/华杰（配套） | 智能终端硬件的常年展示、人类试用、研发测试 |
| **数据要素 / 数字资产** | 蓝景丽家更新地块（数字资产试点）+ 京仪/华杰（数据配套） | 数字资产交易所雏形、数据要素流通试点 |
| **AI 合规服务** | 京仪科技大厦、华杰大厦 | AI 知识产权、审计、合规、投融资专业服务集聚 |

> 这种「**一地块一赛道**」的明确分工，是 A3 区别于一般产业园的关键设计——避免「挂 AI 牌子、搞通用办公」的内卷。

## 3.3 设计目标

**让「已经在中国 AI 产业最前线」的人们，能在这里完整地生活、长期地扎根；同时让 5 个重点赛道在 5 个具体地块上各得其所。**

A3 的核心矛盾不是「缺企业」而是「缺城市的厚度 + 缺赛道分工」——产业规模上去了，但配套的城市生活品质没跟上；产业地块之间缺少明确的功能分工，赛道的物理承载不清晰。A3 的设计目标：让抖音员工、火山引擎工程师、5 大赛道的创业团队能在 10 分钟步行圈内完成「居住—工作—社交—休憩—学习」的完整日常，同时让每个赛道都能在 A3 内找到**具体的地块、具体的邻居、具体的生态位**。

## 3.4 五大设计动作

### 动作一：新建综合体（蓝景丽家更新地块）—— A3 的「永久产品展厅 + 测试大厅」

**设计定位**：AI 国际交流中心 + 智能体与 AI 原生企业总部 + 数字资产试点 + **具身智能测试平台（AI 产品常年展示+测试场所）**。

**为什么是「具身智能测试平台」而非「公共算力平台」**：
- 原蓝景丽家是**家居大卖场**——大尺度连续展厅 + 常年陈列 + 人类试用空间（试坐沙发、试用厨电、走完整屋样板间），这些特征天然适配**机器人 / 智能体 / 智能终端产品的物理测试 + 常年展示 + 人类试用**；
- 具身智能（机器人、智能终端、AI 硬件）的产品化路径**必须有物理空间承载**——机器人要在真实环境里测试导航、避障、操作，人要试用、试坐、试交互；
- 算力是「云端」概念，**不必自建**，可通过阿里云 / 火山引擎 / 腾讯云等第三方云服务获得，避免自建物理算力平台的高资本支出与运维负担。

**设计策略**：
- **AI 国际交流中心**：作为 A3 的国际级会客厅，承接国际 AI 大会、跨国 AI 企业峰汇、海淀 AI 形象展示；空间形态上**应当是「公共客厅」而非「纪念碑」**（沿用 A1 章节对「朝圣地标」的功能性重定义）。
- **智能体与 AI 原生企业总部**：以字节系生态为基础，引入新一代 AI 原生公司（智能体、多模态、具身智能），形成 A3 头部企业梯队。
- **数字资产试点**：作为北京市数据要素 / 数字资产流通试点的物理承载地，可参考上海数据交易所、深圳数据交易所的初期空间形态。
- **具身智能测试平台（核心保留空间）**：
  - **AI 产品常年展示大厅**：从原家居大卖场的「常年家具陈列 + 整屋样板间」改造而来——变成 AI 机器人 / 智能体 / 智能终端的常年展示厅 + 试用场景；
  - **机器人 / 智能体物理测试区**：原家居大卖场的「大尺度连续展厅」改造为机器人导航、避障、人机交互、操作能力的实物测试空间——支持研发测试、产品路演、行业 demo day；
  - **AI 产品试用人流空间**：原家居卖场的「逛店流线」改造为 AI 产品试用流线——访客可在一天之内体验多种 AI 产品；
  - **不封闭、不高高在上**：具身智能测试平台是**公共性设施**，向产业人士、媒体、普通公众开放参观、试用，而非内部专用实验室。
- **拆除重建的尺度（用户决定）**：
  - 容积率 **≤ 2.5**（采纳用户判断，**不追求「盖楼盖到底」**）；
  - 在文物保护（大钟寺古建北侧敏感区）和现有产业（方恒、中坤、京仪、华杰）之间取得平衡——**重建但不「盖楼盖到底」**，须留出视廊、通风廊、与古建的对话空间。

### 动作二：存量更新（方恒广场、中坤广场）—— A3 的「内容工厂」

**设计定位**：AI 内容消费、多模态 AIGC、数字人、内容工具链龙头及上下游。

**设计策略**：
- **保留建筑，升级功能**：方恒、中坤是字节系现状锚点，**不拆除**，在现有建筑结构上做功能升级、垂直绿化、底层活化；
- **内容生态垂直集聚**：除字节系总部外，引入上下游企业（数字人 / AIGC 工具链 / 直播电商 / 内容运营服务），形成「内容工厂」垂直生态；
- **24/7 街区生活**：底层裙房强制混合功能（餐饮 / 零售 / 咖啡 / 24h 便利店 / 共享办公夜间时段），与新建综合体形成「白天办公 + 晚上生活」的双层活跃。

### 动作三：低密更新（大钟寺古建北侧缓冲区）—— A3 的「文化敏感区」

**设计定位**：AI + 文博数字文创、AR 文化试验。

**设计策略**：
- **严控开发强度**：紧邻大钟寺古钟博物馆文物保护边界，**建筑高度、密度、形式须服从文保要求**；
- **数字文创 + AR 试验**：把古钟博物馆作为 A3「AI + 文博」应用场景的天然实验场——AR 导览 / 数字文物 / AI 讲解 / 沉浸式展览；
- **低密度 + 小体量**：拒绝大体量商业开发，倾向小体量、低层、文化设施为主的空间形态。

### 动作四：开放绿廊活化（京张遗址公园 A3 段）—— A3 的「非正式客厅」

**设计定位**：产业非正式交流、户外路演、慢行系统。

**设计策略**：
- **京张公园 A3 段提质**：A3 东侧的京张公园绿廊是 A3 产业人群最近的「户外客厅」，增设可移动家具、户外路演场地、临时展览设施；
- **非正式交流空间**：在公园与产业地块之间设 2-3 个「产业+公园」过渡节点，让工程师可以「走出写字楼 5 分钟到公园开会」；
- **A3 与 A1/A2 的步行贯通**：A3 段是京张公园南端起点，须与 A1 段（学院路/八大学院）连续贯通——这是 A1/A2/A3 步行叙事完整的关键一段。

### 动作五：配套服务（京仪科技大厦、华杰大厦）—— A3 的「专业服务带」

**设计定位**：AI 知识产权、AI 合规审计、科技投融资、数据配套服务。

**设计策略**：
- **专业服务垂直集聚**：把京仪、华杰两栋存量写字楼功能置换为 AI 时代专业服务集聚——AI 律所、AI 审计、AI 投行、数据合规；
- **A3 内部「服务中台」**：服务 5 大赛道（智能体 / AI 内容消费 / 智能终端 / 数据要素 / AI 合规）的合规、融资、上市、并购需求；
- **与新建综合体的功能互补**：新建综合体（蓝景丽家）做「硬件 + 空间」承载，存量楼宇（京仪/华杰）做「软件 + 服务」承载——避免内部同质化竞争。

## 3.5 如何织补（机制）

### 跨地块总机制

- **政府建骨架**：站点周边、街区缝隙、京张公园 A3 段、慢行系统的公共投资；文物保护与产业开发的协调。
- **市场填内容**：5 个地块内部的功能填充与产业招商——其中蓝景丽家更新地块由字节系/合作方主导，方恒/中坤由字节系自营，京仪/华杰由市场+区科创局共同引导。
- **政府 + 平台公司长期持有**：参考 MITIMCo 与 A2 「平价空间预留」机制，A3 内具身智能测试平台、京张公园 A3 段过渡节点等公共性资产由**专门平台公司长期持有运营**，防止「地块红了、生态却空了」。

### 5 个地块分别的运营机制

| 地块 | 主导方 | 机制要点 |
|------|--------|----------|
| 蓝景丽家更新地块 | 字节系 + 海淀区/市区两级科创平台联合 | 重建（容积率 ≤ 2.5）+ 具身智能测试平台 + 数字资产试点 |
| 方恒、中坤 | 字节系自营 + 上下游招商 | 存量功能升级 + 内容生态垂直 |
| 古建北侧缓冲区 | 海淀区文旅 + 文物部门 | 严控强度 + 数字文创试验 |
| 京张公园 A3 段 | 海淀区园林 + 街道 | 公共绿廊提质 + 非正式客厅 |
| 京仪、华杰 | 市场 + 区科创局 | 专业服务垂直集聚 + 功能置换 |

### 与 A1 / A2 联动

- **北上连 A2**：京张公园 A3 段（动作四）+ 13 号线轨道走廊。原型从 A2 出发，30 分钟内可达 A3 出厂码头规模化为产品。
- **跨 A1 联动**：A3 资深工程师作为 A1 校际小火车（自动驾驶小巴）系统的潜在 mentor/技术顾问，反哺大学城原始创新；A1 学生可在 A3 完成实习/产业实践。
- **产品 / 测试互济链（三级）**：
  - **A1 算料 + 学术**：实验室 GPU + 数据 + 论文产出（A1 是「思想矿场」）；
  - **A2 试产空间**：初创期产品化补贴空间（办公室、共享实验、demo day）；
  - **A3 具身智能测试平台**：成长期物理测试（机器人/智能体/智能终端的实物验证）+ 常年展示（公共客厅）+ 人类试用流线；
  - 算力按需接入云服务（阿里云 / 火山引擎 / 腾讯云），不需各区自建。

## 3.6 指标设计（provisional，概念建议）

### 整体指标（A3 片区总盘）

| 指标 | 目标值 | 说明 |
|------|--------|------|
| `site_area_sqm` | 约 720,000 | PROV-KEY-003 公告值（provisional） |
| `green_ratio` | ≥ 25% | 含京张公园 A3 段 + 口袋公园 + 蓝景丽家重建区公共绿地 |
