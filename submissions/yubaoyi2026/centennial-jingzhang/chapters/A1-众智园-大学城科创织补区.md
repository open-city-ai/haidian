# 第一章 A1 众智园 · 大学城科创织补区

> 本章为「百年京张 AI 创新带」城市设计方案（方案 B）首章。全案 guiding philosophy：**铁路链接物理距离，大学链接思想。AI 时代，最重要的是最大限度链接思想。** 百年京张始于一条缝起物理距离的铁路；今日这条廊道要缝的，是思想的距离。

## 1.1 本章定位

A1 众智园位于三层范围北端（五环—清河一带），公告面积约 192.1 ha（provisional，复算 1,929,201.88 m²，见 PROV-KEY-001）。它处在 1952 年院系调整定下的「八大学院」大学走廊北段——**这里不缺思想的源头，缺的是让思想彼此碰撞、彼此放大的「接缝」**。本章设计，即沿这条走廊织补那些接缝，并把 A1 接入纵贯三区的「百年穿越轴」。

本章与 A2（AI 原点社区）、A3（大钟寺）同构于上述哲学命题；A1 负责「大学城」这一端。

## 1.2 定型逻辑：为什么不能推倒重来

- **历史定型**：1952 年院系调整，八所理工科高校在学院路集中布局，校址自此固定；校园规模相仿、共享周边基础设施，与清北不在同一片区。
- **空间实证**：官方 provisional 边界与 OSM 实地核对存在数百米偏移（街道中线东偏均值约 667 m），恰说明「文字四至画框」与「固定校区走廊」之间的差距——**边界是 provisional，校园是 real**。
- **结论（用地逻辑：留 / 改 / 增）**：校园本体 = **留**；校园之间与周边的低效边角地 = **改 / 增**。设计不触碰校园，只织补缝隙。

## 1.3 织补什么（四项）

**① 共享中试 / 实验室平台**
将学院路街道已在运行的「线上 355 台大型科研仪器共享」实体化、可步行到达：在织补带设分布式共享中试舱，供八校学生与初创团队共用，降低「从论文到样机」的门槛。

**② 校际慢行连廊 + 校际小火车（双系统）**
缝合被学院路（道路）与北四环切断的八校园。
- **慢行连廊**：沿京张铁路遗址公园轴北延段布设连廊与慢性道路，把 A1 接入纵贯三区的「百年穿越轴」，使步行 / 骑行成为校际往来的默认方式。
- **校际小火车**：在八大学院之间跑**穿梭小火车**（轻轨/智轨/自动驾驶小巴均可），**用动态交通替代静态打通**——中国大学的围墙是行政边界，不能像 Kendall Square 那样静态打通校园与街区，但 5-10 分钟一班的穿梭小火车能实现同样的「穿越边界」效果。**精神内核不变**——最大限度链接思想；**手段本土化**——不拆墙，动起来。

**③ 第三方空间 / 双创街区**
在八校学生自然相遇的节点设咖啡、共享办公、maker 空间（呼应学院路氪空间模式），制造「偶然碰撞」——Kendall Square 已验证其为创新发生的关键机制。

**④ A1「大学城科创客厅」（A1 核心功能地标）**
**一座 MaRS 式共享枢纽**——不是某一栋被特别赋予纪念意义的建筑，而是把上述三项功能汇聚成一个**可识别的复合空间系统**（共享平台实体节点 + 校际小火车主要站点 + 双创街区汇聚点），承载 A1 作为「思想矿场」的身份。这是 A1 的**功能地标**——它的地标性来自其承载的「链接八大学院」功能，而非纪念性外观。

## 1.4 如何织补（机制）

- **不动校园、织缝隙**：识别校园间低效边角地（老厂房、闲置大院、断头路、停车场）作为「织补带」，避免大拆大建。
- **校地共建机制**：把学院路街道已有的「重点实验室党建联盟 / 校地共建」固化为空间交付载体——机制已存在，本方案接住它而非另起炉灶。
- **平台数字化 + 实体化**：线上共享仪器平台 → 步行可达的实体共享设施。
- **长期持有 / 运营**：借鉴 MIT（Kendall Square）「不卖地、做长期地主 / 策展人」模式（MITIMCo），明确织补带由校地联合体长期持有运营，策展整个生态而非一次性开发。**这是从 Kendall Square 学到的最关键机制**——中国大学不能拆墙打通，但可以学它的「不卖地」哲学保护织补带的公共性。
- **校际小火车运营机制**：建议由学院路街道 + 八校 + 市区两级科创部门联合设立**「八大学院穿梭运营公司」**，统一调度、票价补贴（学生免费/教职低价）、班次密（高峰期 5 分钟一班）；不靠单一高校运营，避免「谁主导谁吃亏」的恶性博弈。
- **指标口径修正**：`site_area_sqm` 取 PROV-KEY-001 公告 / 复算值；`green_ratio`、`public_space_ratio` 在「织补带」可开发缝隙内复算，`public_space` 计入校门界面与校园周边广场，避免整块 A1（含校园绿地）虚高。

## 1.5 织补带落位（概念建议 · provisional）

基于现有资料，织补带沿三类「接缝」布设（具体 parcel 待官方 GIS 替换）：

1. **学院路（道路）两侧缝**——八学院东西两列的分割线，路侧低效用地优先织补；
2. **京张遗址公园轴南缘接口**——A1 与纵向带状公园的接入点，作校际慢行连廊北段；
3. **八校园校门界面**——校门外的「院墙—城市」过渡带，作第三方空间节点。

> ⚠️ 上述边界、线位、面积均依 provisional 数据（来源 `DATA-SRC-PROVISIONAL-BOUNDARIES-20260605`，衍生自 2026-05-09 公告），**非官方红线**；强度 / 高度 / 权属均标「概念建议」，待官方 CAD/GIS 边界获取后替换（替换规则见 provisional_boundaries.geojson metadata）。

## 1.6 本地与国际佐证（参考，非规划依据）

- **学院路街道（本地，2025–2026 公开报道）**：已落地「大学城型街区 / 环高校创新街区 / 校地共建」、355 台仪器线上共享、氪空间创新中心——本方案机制与之同构，是对已发生事实的空间化放大。*（确切链接待补入 sources.json）*
- **Kendall Square（MIT，剑桥）**：**首要参照 + 必须本地化改造**。真实机制是「依托地铁 Kendall 站 + 强化步行网络 + **打通 MIT 校园与街区——消解园区与城市围墙割裂** + MITIMCo 长期持有运营」。**本案不能照搬「打通围墙」**——中国大学的围墙是行政边界；但可借鉴：①长期持有运营机制（MITIMCo 模式）②从 9-5 到 24/7 的功能混合演进路径 ③**反例教训**——Kendall Square 当前最大的痛点是可负担住房短缺导致早期创新生态外溢，本案 A2 已设「平价空间预留」机制提前应对。
- **MaRS（多伦多）**：多机构共享平台枢纽 + 交叉补贴 + AI 机构作锚。
- **uCity Square（费城）**：夹在多平等校区（Penn / Drexel / CHOP）缝隙中织补、恢复原街道、免费接驳环线、Quorum 聚集厅——结构最贴近 A1；其被批「generic innovation district」的教训提醒我们：京张遗址 + 八大学院 1952 历史才是本地 authenticity，杜绝通用模板。
