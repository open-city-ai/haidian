# CITY HANDSHAKE / 城市握手 — 设计说明与审计附录

## 1. 独立性声明

本方案由 GPT-5.6 Sol 作为 `wangqj646-hub` 账号下第二条独立提案线生成。它不复写既有 `jingzhang-ai-for-all` 的“硅基伙伴 / AI 原生第一代 / 一带三核一原点”概念。两稿仅共享官方任务、仓库规则、provisional geometry 与参与者账号这一事实。

本稿的核心对象是 **delegated agency（受委托行动权）**：当 Agent 可以支付、预约、提交、调度、申请或控制设备时，城市应如何确认它“凭什么替人行动”、留下什么凭证、何时必须归还给人。

## 2. 原创性骨架

一句话：**城市不把权力交给 AI。城市允许人把有限、可审计、可撤回的行动权委托给 Agent。**

三层创新链：

1. **Mandate Object / 委托对象**：谁、做什么、在哪里、最大限额、到什么时候、数据范围、是否可二次委托。
2. **Action Receipt / 行动凭证**：每个后果性动作都同时留下机器可读和人可读记录。
3. **Return Interface / 归还接口**：暂停、撤销、迁移、申诉、转人工与高风险强制 handback。

四闸门为 Intent → Mandate → Action → Return。任何权限增长都必须重新握手，禁止静默扩权。

## 3. 空间转译

- **一带：城市握手脊 Civic Handshake Spine** — 以京张遗址公园为连续的低技术公共底盘，让责任交接可见。
- **众智园 · 协议工场 Protocol Foundry** — 造规则、做红队、验证可撤回性。
- **AI 原点社区 · 委托公社 Mandate Commons** — 日常委托、人工服务、查看/撤销/迁移权限。
- **大钟寺 · 交接市场 Handoff Market** — 在高频交易、退款、内容消费、机器人与争议里压力测试规则。

三个地标不做 AI 奇观：Red-Line Pavilion / Handshake Hall / Return Gate，分别让“不能做什么”“我授权了什么”“怎样回到人”成为可见公共设施。

## 4. 视觉识别

主色：深海军蓝 `#193B64`（公共责任） + 信号橙 `#E46C3A`（主动委托） + 暖纸色 `#F5F1E8`（可读公共界面）。

Logo 是两侧主体通过中央 mandate credential 发生连接。两边不直接相碰：没有授权对象，就没有代理行动。禁止机器人脑袋、神经网络、赛博城市和巨大 hologram 作为主识别。

## 5. 风险与人类兜底

- 越权：动作超出 mandate 立即拒绝，写入失败凭证。
- 静默扩权：权限扩大必须生成新握手，不允许模型自行解释为“用户大概同意”。
- 责任漂移：外部服务不得把“AI 做的”当免责理由，责任回到对应的人类/机构主体。
- 锁定：mandate、撤销状态和 receipt history 必须可迁移，不由单一模型独占。
- 数字排斥：基本公共服务保留人类/静态/无设备等价路径，拥有 Agent 不是服务资格条件。
