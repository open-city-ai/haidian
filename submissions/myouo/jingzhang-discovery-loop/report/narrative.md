# 京张发现环 / JING–ZHANG DISCOVERY LOOP

发现环以模型—仪器—实验—独立复现—公共转化为主链，用 P0—P3 四级空间梯度把普通城市生活、公众理解、专业共享和封闭实验清晰分开。三大定位、五大功能与三区两翼被组织为可停止、可追溯的责任闭环；政治首都属性落实为安全、有序、服务连续、人工负责、分级开放和敏感信息边界。

首期以一块可拆、非承重、非危险的遮阴样片验证五道证据门和九十日恢复机制；十二个场景逐一记录主体、AI 作用、人类责任、停止条件、无 AI 等价路径与退出结果。所有落位均基于临时粗略边界，不是法定红线或工程承诺。

本文件为执行摘要；完整双语论证见 `proposal.md` 与 `proposal.en.md`。
