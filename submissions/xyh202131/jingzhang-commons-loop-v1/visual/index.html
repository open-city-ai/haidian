建筑 / 更新项目

先留、再修、后谈新增。15 个建筑对象支持量体关系检查，但不提供法定高度、密度、容积率或工程结论。

buildings + phasing

留

优先保留可承载公共服务和铁路记忆叙事的对象，采用可逆再利用。

改

围绕无障碍、采光、能源、消防和运维建立待核改造清单。

新增 / 拆

权属、结构、现状和公共影响资料齐全后，才进入专业复核。

八项更新项目覆盖主脊识别、三庭接口、人工陪同、清权导览、企业服务、模型共测、蓝绿节点和全球活动归还；分期是讨论顺序，不是建设承诺。
