# Formal Narrative

“京张共创环”把创新带拆成一条公共学习回路：看见问题，做一个小而可退的原型，听到不同人的反馈，再决定保留、修改、暂停或归还。三层范围不是三个开发承诺，而是三种证据尺度；三处重点区不是封闭园区，而是验证、转译、采用三个动作。

这份 narrative 与 `proposal.md`、`metrics.json`、九个 GeoJSON 图层、A3/A0 图纸和两个离线 HTML 入口一起构成可替换包。当前官方边界、强度、权属、道路、市政、遗产和服务容量均按缺口处理；正式资料到位后，应先替换几何，再重算指标和图版，最后由专业人员复核场景门槛。它没有把概念表达写成已批准、已实施或可直接施工的结论。

正文中的 source、standard、depth、data、metric 标记指向机器可读证据，`compliance_matrix.json` 把公告和任务书要求拆到可查阅产物。视觉入口不依赖网络，常规服务与人工兜底始终与 AI 辅助并列；这使方案即便暂停某个模型，也仍然是一个可阅读、可讨论、可归还的公共空间提案。
