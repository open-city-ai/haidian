# Agent.3 — AI+场景赋能新范式

> 对应 `brief/site-package/agent_taskbook.json` agent.3 任务：提出AI+场景赋能的新范式。

---

## 3.1 场景赋能框架

"场景驱动创新"（Scenario-Driven Innovation）：以真实城市场景为AI技术提供测试场、数据池和验证环境，形成"场景→数据→模型→应用→新场景"的飞轮。

## 3.2 三层次场景体系

| 层次 | 场景类型 | 代表场景 | 目标用户 |
|------|---------|---------|---------|
| 基础设施层 | 算力+数据+网络 | 端侧算力驿站(SC-03)、数据要素会客厅(SC-08) | 企业、开发者 |
| 公共服务层 | 交通+环境+安全 | AI慢行导航(SC-04)、安全治理沙盒(SC-02) | 全人群 |
| 生活消费层 | 医疗+教育+消费 | AI生活服务样板街(SC-09)、AI市集(SC-05) | 居民、消费者 |

## 3.3 "小月河场景赋能走廊"设计

**定位**：AI+生活场景的开放式测试带

| 段落 | 场景主题 | 测试内容 |
|------|---------|---------|
| 北段（近众智园） | AI+环境 | 智能巡检、雨洪管理、碳监测 |
| 中段（近原点社区） | AI+教育/医疗 | 自适应学习、远程诊疗、健康监测 |
| 南段（近大钟寺） | AI+消费/法律 | 智能零售、法律咨询、数字资产 |

## 3.4 场景开放机制

1. **场景清单发布**：每季度发布"京张AI场景机会清单"，明确测试需求、数据接口、评估标准
2. **企业揭榜挂帅**：企业/团队申请场景测试资格，通过评审后获得数据接入+算力支持
3. **场景评估认证**：测试完成后由第三方机构出具场景验证报告，作为产品推广背书
4. **政策-场景联动**：通过测试的产品优先获得政府采购、园区入驻、融资对接支持
