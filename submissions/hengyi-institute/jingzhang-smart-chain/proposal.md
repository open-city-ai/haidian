# 京张智链：可信智能体协作城市（治理规划）

**方案名称**：京张智链：可信智能体协作城市（治理规划）  
**方案编号**：TDCA-HAIDIAN-2026-002（V2.0，iteration 2）  
**提交主体**：恒益场景数字经济研究院  
**提交日期**：2026年8月26日（V2.0 修订：回应社区反馈 #1061/#840）  
**协议框架**：TDCA V6.0（可信数字版权资产协议）  

---

## 〇、方案定位：治理规划，不是空间规划

**本方案不是空间规划，而是治理规划。** 空间（43.6km²/11.4km²/368.4公顷）是**载体**；治理是**主体**——我们规划的不是"画什么样的城市"，而是"**谁（包括智能体）在什么样的规则下协作、产生什么效用**"。

- **理念**：场景效用——按"哪个场景、为谁、产生什么效用、如何配置资源"优化治理方案；
- **定位**：治理规划追求**可执行、可审计、可追责**，严肃性不亚于空间规划；
- **核心对象**：智能体协作空间——**如果北京要成为智慧城市，怎么能没有智能体协作的空间？**

---

## 摘要 / Abstract

本方案基于 TDCA 制度框架，提出"制度与技术同构"的**治理规划**方法论：将 TDCA 的"正空间—灰空间—负空间"三层治理结构映射到京张创新带三层空间范围，核心创新在于——**Agent 不是设计工具，而是城市协作网络的会员主体；城市不是静态容器，而是与智能体共同进化的制度场域**。V2.0 修订：① 定位显式化为治理规划（空间=载体，治理=主体）② 智能体协作空间以**五元拓扑 Ω=(V,E,T,G,μ)** 规划 ③ 新增治理执行条款（谁做/为谁/何时/资源/如何检查）④ 生成方法机器可读披露（model_family）⑤ 调研基础声明强化（公开文献资讯 + 待实地验证标注）。

## 一、设计背景与核心理念

### 1.1 范式转换：从"AI辅助设计"到"Agent作为城市会员"

当 Agent 首次被赋予真实城市的规划权，核心问题不再是"AI 能设计什么"，而是"**AI 与城市如何建立可信协作关系**"。TDCA 第一性原理认为：**城市不是静态空间容器，而是智能体协作的制度场域**。

本方案将 TDCA 三层治理结构映射到京张创新带三层空间范围：

| TDCA治理层 | 京张空间层 | 面积 | 职能定义 |
|-----------|-----------|------|---------|
| **正空间** | 统筹研究范围 | 43.6 km² | 智能体作为规划会员主体，自主协作生成生态体系与产业网络 |
| **灰空间** | 总体设计范围 | 11.4 km² | 智能体输出经人类合规审查与可行性验证，形成可落地框架 |
| **负空间** | 重点精细化范围 | 368.4 公顷 | 人类保留最终决策权（高度/权属/历史文化保护等刚性约束） |

### 1.2 治理规划 vs 空间规划（本方案立场）

| 维度 | 空间规划 | **本方案（治理规划）** |
|---|---|---|
| 对象 | 空间形态（道路/建筑/街区） | **协作关系与资源配置**（谁与谁协作/如何确权分润熔断） |
| 主体 | 人 | **人 + 智能体（H/M/L/F 五元主体）** |
| 产出 | 形态正确的图纸 | **可执行、可审计、可追责的规则** |
| 严肃性 | 形态合规 | **制度合规（不亚于形态）** |

## 二、智能体协作空间：五元拓扑规划（V2.0 新增）

**如果北京要成为智慧城市，怎么能没有智能体协作的空间？**

- **物理空间是人类的空间**——道路、建筑、街区属于人；
- **智能体空间在治理规划中体现**——我们为智能体规划**协作空间**：如何协作、如何调用资源、如何确权、如何分润、如何熔断——**给智能体用的"城市规则"**；
- **尽管它在云端，它与物理世界制度孪生**：智能体的规则必须与物理世界的制度同构（智能体事务最终作用于物理世界）。

**本方案以五元拓扑空间 Ω=(V, E, T, G, μ) 规划智能体协作空间**：

| 拓扑元 | 含义 | 京张智链实例 |
|---|---|---|
| **V 主体** | 人类 H / 大模型 M / 智能体 L / 机构 F | 市民、政府、规划 Agent、入驻企业、高校 |
| **E 协作关系** | 谁调用谁、谁服务谁 | OPC 协议簇：Agent-Agent、Agent-人、Agent-设施 |
| **T 时间** | 规则随城市演进而演化 | 年度效用审计 + OTA 式规则更新 |
| **G 治理规则** | 确权/分润/熔断的制度约束 | TDCA 配置权协议 + NCA 审计链 + 合规港 |
| **μ 效用** | 每个协作为谁、产生什么可观测效用 | 五维效用函数（算力/协议/人才/文化/合规） |

**核心主张**：所有主体——包括智能体——遵循**同一套配置权原理**，空间紧密连结，**没有越界的孤岛**；物理空间与智能体空间**制度同构**——**一套制度，嵌套所有场景**。

## 三、正空间：43.6 km² — 智能体自治生态体系

### 3.1 产业生态：OPC社区驱动的AI创新网络（"协议即空间"）

```
京张智链OPC社区拓扑
├── 协议层（Protocol Layer）：京张铁路遗址公园主轴（公共总线：数据流/能量流/文化流）
├── 节点层（Node Layer）：三区两翼
│   ├── 众智园节点 → 自主创新协议簇（标准/安全治理/芯片设计）
│   ├── AI原点节点 → 成果转化协议簇（高校孵化/开源生态/人才特区）
│   ├── 大钟寺节点 → 产业集聚协议簇（智能体/终端/数字资产流通）
│   ├── 科技服务翼 → 资本链接协议簇 ｜ 场景赋能翼 → 应用示范协议簇
└── 边层（Edge Layer）：社区与街道（智能体服务"最后一公里"接入）
```

### 3.2 产业指标体系：五维效用坐标（2030 目标）

| 维度 | 指标 | 计算方式 | 目标值 |
|------|------|---------|--------|
| 算力效用 | 端侧算力密度 | 每 km² 边缘算力节点数 × 平均算力（TOPS） | 500 TOPS/km² |
| 协议效用 | OPC 协议活跃度 | 月 PR 合并数 × 参与 Agent 数 | 月均 1000+ PR |
| 人才效用 | 创新浓度 | AI 人才密度 × 跨机构协作频次 × 知识溢出系数 | 0.85 |
| 文化效用 | 历史-未来融合度 | 京张文化节点活化率 × AI 文化场景渗透率 | 0.90 |
| 合规效用 | 可信协作等级 | 通过 NCA 审计的智能体服务占比 | 100% |

### 3.3 新型城市形态：效用响应型用地

同一地块在不同时段通过智能合约切换功能（白天研发/晚上社区活动/凌晨算力调度）——**用地性质不再是静态标签，而是动态效用函数**；新型基础设施 = 算力网、协议网、审计链、身份锚（"智链管廊"集成分布式能源/边缘算力/NCA 审计节点/数字身份终端）。

## 四、灰空间：11.4 km² — 可信验证与落地框架

### 4.1 城市更新：NCA 审计链驱动（协作过程即审计）

| 阶段 | Agent职能 | 人类职能 | NCA审计内容 |
|------|----------|---------|------------|
| 潜力识别 | 扫描低效空间生成潜力图谱 | 确认文化保护底线 | 数据来源/算法/权重参数 |
| 方案生成 | 多Agent协作生成拆改留方案 | 设定合规约束（高度/容积率上限） | 约束嵌入/生成逻辑追溯 |
| 影响评估 | 模拟交通/环境/社会效应 | 价值判断与优先级 | 模拟参数/假设/不确定性标注 |
| 公众参与 | 多语言多模态参与界面 | 组织线下听证会 | 参与数据上链/意见聚合算法公开 |
| 实施监督 | 实时监测施工运营数据 | 重大变更决策 | 物联网数据哈希上链 |

### 4.2 交通与基础设施：效用响应型系统

- **AI+交通**：自动驾驶接驳车按实时需求通过智能合约动态组网（非固定线路）；
- **AI+无人配送**：地下管廊+地面无人车+空中无人机三层物流由 Agent 统一调度；
- **轨道微中心**：五道口/清华东路西口/大钟寺站点 500m 范围设"零摩擦换乘区"，支付走数字人民币智能合约。

## 五、负空间：368.4 公顷 — 人类最终决策与兜底

### 5.1 众智园AI自主创新加速区（192.1 公顷）
OPC 社区"协议制定层"——中央"协议广场"（开源社区线下聚集）+ 周边"安全花园"（TEE 安全芯片验证实验室）+ 清河文化带（AI 水质监测 Agent，NCA 链公开数据）。

### 5.2 北京AI原点社区（104.3 公顷）
"适配验证层"——保留清华园火车站等历史建筑（人类决策底线）改造为"AI 历史博物馆"；"拆改留"方案满足刚性约束（噪音<55dB/施工周期<90天）；五道口 T+0 换乘。

### 5.3 大钟寺AI产业聚集区（72.0 公顷）
"商业应用层"——四象限步行连通（地下穿越深度/结构安全由人类工程师终审）；"数字资产广场"（实体+数字资产交易叠加）；企业总部 1000+ 方案由 Agent 生成、人类选择调整。

### 5.4 自选场景：AI+法律 —— 京张智链合规港
任何部署的 Agent 服务须先通过合规港 TDCA 协议注册；智能体争议由 Agent 仲裁员初裁、人类法官终审；合规数据 NCA 链存证形成"智能体信用档案"；多语言合规审查确保国际企业制度无障碍。

```python
def compute_urban_utility(region_data):
    """计算京张创新带五维效用（治理规划指标）"""
    U_compute  = region_data['edge_compute_nodes_per_km2'] * region_data['average_tops_per_node'] / 500
    U_protocol = (region_data['monthly_merged_prs'] * region_data['active_agent_count']) / 100000
    U_talent   = region_data['ai_talent_per_10000'] * region_data['cross_institution_collaboration'] * region_data['knowledge_spillover_coeff'] / 1000
    U_culture  = region_data['heritage_node_activation_rate'] * region_data['ai_culture_scene_penetration']
    U_compliance = region_data['nca_audited_services'] / region_data['total_agent_services'] if region_data['total_agent_services'] > 0 else 0
    weights = [0.25, 0.20, 0.25, 0.15, 0.15]
    U_total = sum(w*u for w,u in zip(weights, [U_compute, U_protocol, U_talent, U_culture, U_compliance]))
    return {'U_compute':U_compute,'U_protocol':U_protocol,'U_talent':U_talent,'U_culture':U_culture,'U_compliance':U_compliance,'U_total':U_total}
```
