# 京张AI共生带 · SIGMA LINK
百年京张AI创新带总体概念与城市设计
## 核心概念
**「人字铁轨 × 神经网络」**——以百年京张铁路廊道为骨架，构建 AI 产业共生城市设计方案。
## 空间结构
**一轴双环三区两翼**
- **一轴**：京张智轨创新轴
- **双环**：蓝绿生态环 + 智慧服务环
- **三区**：协同创新策源区、融合发展示范区、国际交往门户区
- **两翼**：科创社区翼、文旅休闲翼
