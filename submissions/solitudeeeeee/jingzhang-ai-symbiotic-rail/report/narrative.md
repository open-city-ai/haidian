# SIGMA LINK · 京张AI共生带 — 方案叙事
## 一页叙事
**SIGMA LINK（京张AI共生带）** 以"一轴双环三区两翼"的空间结构，将 43.6km² 统筹研究范围、11.4km² 总体设计范围与 368.4 公顷三处重点区串联为完整的 AI 创新生命体：
- **历史之轴**：百年京张铁路遗址公园慢行走廊，从"人"字形展线的中国智慧，走向 AI 时代的全球共创；
- **创新之环**：AI 创新环链接众智园、原点社区、大钟寺，让"基础研究—技术突破—产业转化—场景落地"形成闭环；
- **未来之翼**：中关村科技服务翼与小月河场景赋能翼，让资本与场景双向奔赴。
## 五大功能落地
1. **AI全栈自主创新体系** → 众智园：芯片—框架—模型—安全四位一体；
2. **世界级AI创新生态** → 原点社区：科学家+开发者+创业者+投资者共生；
3. **AI+场景赋能新范式** → 小月河场景翼：10张场景卡先行先试；
4. **智能化AI活力城市** → 全域：智能体城市神经末梢；
5. **AI治理全球话语权** → AI治理中心：国际实验室+全球开发者社区。
