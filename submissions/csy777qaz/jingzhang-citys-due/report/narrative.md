# Package Narrative / 成果说明

京张·城市应得以 `geometry/*.geojson`、`metrics.json`、三张矩阵、`sources.json` 和 `assumptions.json` 为证据主链；proposal、五组中英图、visual HTML 与四套 PDF 从同一结构化数据派生。GeoJSON 优先于指标，指标优先于展示；任何不一致都应回到结构化数据修复后整体重生成。

The package is a conceptual, auditable design submission. It is not a statutory plan, approval, funding commitment or engineering conclusion.
