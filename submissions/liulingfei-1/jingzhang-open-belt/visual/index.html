每张场景卡包含用户与空间、AI 机制与人工复核、数据边界与失败退出；含建议 Owner、最小成功证据与红牌暂停/退出条件。统一状态：concept → simulation → limited_sandbox → human_review → professional_deepening/retired。

S01–S14 / T01–T06
S01 主线漫游

无障碍步行骑行提示，设备失效保留固定导视；无障碍体验官复核。

S02 PR 提案亭

居民提案公开可追踪，议题委员会确认优先级，无责任主体即 Hold。

S03 ISSUE 报修

故障报修状态公开，超时升级人工，窗口人员确认高影响答复。

S04 沙盒体验【产业验证】

机器人与配送限定路径，安全员现场接管、分时验收，停机退回封闭场。

S05 开源夜校

模型比较与提示实验，教师审核课程输出，未成年人数据不入训练。

S06 智能接驳

轨道-慢行-共享接续，优先解决下车后无障碍与照明，人工台兜底。

S07 城市仪表盘

公共数据可读展示，聚合指标可复算，数据 Steward 复核。

S08 隐私哨兵

感知设备边界提示用途与退出，独立申诉人复核，无提示即停用。

S09 遗产讲解

清权档案分层讲述，史料编辑逐条审校，来源缺失即撤下。

S10 绿色运维

植物识别与病害预警，专业人员决定处置，连续误判即停用。

S11 应急回滚

暴雨/断网/传感器失效安全降级，值守复核，不自动执法。

S12 荣誉墙

贡献者与成果透明记录，版本与证据链可追溯，展示默认去标识。

S13 多主体联锁【产业验证】

多运营商机器人让行遥停互认，技术委员会放行，不可复现即回滚。

S14 全球互操作周【产业验证】

跨模型工具语言互操作，联合评审与现场接管，越权即隔离。
