# 方案迭代记录

## v0.1 - 2026-08-08

**设计宪章冻结**

- 冻结主品牌「京张开源带｜JINGZHANG OPEN BELT（JZ·OPEN）」、副题「从自主铁路到开源城市」、空间母题 `TRUNK + COMMIT + PR + FORK + ISSUE` 与五状态服务生命周期 `Draft → Review → Merge → Release → Rollback`。
- 概念来源：1909 京张铁路（自主技术开源）→ 1988 中关村（产业开源）→ 2026 京张开源带（城市开源）。
- Logo 方向：铁轨分叉与代码分支同构的“人”字形（致敬詹天佑）+ 三色信号灯状态语言。

## v0.2 - 2026-08-08

**单一事实源**

- 采用仓库 provisional 场地与三处重点区，全部 polygon 披露 `provisional_rough` 精度限制。
- 生成 9 层设计几何：site_boundary、key_areas、land_use（11 分区全域覆盖零缝隙）、buildings、roads、green_space、public_space、constraints、phasing。
- 在 EPSG:4548 复算场地、建筑基底、绿地与公共空间指标，重点区工作面积与公告约值一致。

## v1.0 - 2026-08-08

**边界与术语修订**

- 删除“provisional 阻断正式内容评分”的过时话术；改为精度警示与官方资料到位后的整体复算要求。
- 固定 Human Gate：Issue 不等于立项，Sandbox 不等于批准运营，Merge 不等于政府采纳、采购、建设或上线。
- 增补 Agent.1—Agent.6 工作护照（角色、输入、冲突处理、人工闸门、评测证据）、八类风险治理登记与区域协同矩阵。

## v1.3 - 2026-08-08

**判断驱动重写（对标顶级方案）**

- 核心宣言升级为「城市问题进主线，AI 方案过评审，人做最终合并」；空间母题凝练为「1+3+2+N」；时间叙事扩展为 1909—1988—2026—2126。
- 全部 13 章以「本案判断」开头，先给设计判断、再给公共与产业理由、随后落到图层/指标/来源，最后公开未取得条件。
- 三区定位动词化：众智园=COMMIT 站场（提交验证）、原点社区=REVIEW 站场（评审转化）、大钟寺=RELEASE 站场（发布交换）。
- 14 张场景卡增加英文短名（TRUNK Walk / PR Kiosk / Issue Dispatch / Sandbox Trial…）；国际案例改为「机制参照 | 可证事实的本地转译 | 明确不可照搬」三栏表。
- Logo 方向具体化：双轨 + 45 度道岔构成开放“人”字，中央负形为“开”的门洞与站立人形；三色信号规范（炭黑/朱红/信号黄/信号绿）。
- 品牌五元素：总品牌 + 空间母题 + 五状态协议 + Human Gate 伦理底线 + 时间叙事。
