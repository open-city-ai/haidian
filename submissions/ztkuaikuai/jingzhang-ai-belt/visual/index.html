解耦原则 / The decoupling principle

每处回暖节点先满足遮蔽、挡风、座椅、照明与热水五项基本条件，在余热接口落地之前就能独立使用；余热接入只作为热源升级项，不是前置条件。

自检状态 / Self-check state

formal-review-ready 的门槛是：阶段为 formal、参赛者可控的四项复核无 error、且没有 result 为 fail 且 severity 为 blocking 的自检项。自检共 25 项，阻塞级失败 0 项，按此门槛本包状态为 formal-review-ready。两项结论仍为 unknown 而非 pass：约束几何数据缺口，以及官方数据发布后的整体重算承诺。unknown 不等于 fail，它表示所依赖的外部条件尚未公布因而无法核验；把它们写成 unknown 比写成 pass 更有价值，因为它们标出了这份提交真正的边界。

明示假设 / Declared assumptions

PROVISIONAL-SITE-BOUNDARYmajor

本包提交的总体设计范围边界来自仓库维护的临时粗略 polygon，不是官方红线。其复算面积 11,412,825.386 平方米与公告约 11.4 平方公里量级一致（偏差约 0.11%），但四至位置与形状精度均未知。

PROVISIONAL-KEY-AREASmajor

三处重点区域范围为临时矩形示意。复算合计 3,692,893.005 平方米，与公告 368.4 公顷偏差约 0.24%；但矩形形状明显不同于真实片区边界，单个片区的四至不可信。

MISSING-REGULATORY-CONTROLSmajor

容积率、建筑高度、建筑密度、绿地率、退线五项官方控制条件在公开场地包中均登记为 missing，本方案不给出任何替代数值。

NO-OFFICIAL-ROAD-REDLINEmajor

没有官方道路红线、断面与管线资料。roads.geojson 仅提交中心线，表达慢行与接驳组织意图，不生成 ROAD_AREA 面图层。

NO-CONSTRAINT-GEOMETRYmajor

constraints.geojson 刻意保持为空要素集合。文物保护范围与建设控制地带、控规控制线、道路红线、河道蓝线与市政管线均属锁定图层，目前没有可引用的官方几何来源。

BUILDING-SAMPLE-NOT-SURVEYmajor

buildings.geojson 的 20 个建筑基底是概念示意对象，用于表达界面、体量关系与拆改留方法，不是现状建筑普查，也不是总建筑规模。

RETAIN-RENOVATE-DEMOLISH-METHOD-ONLYmajor

本方案提出拆改留的判定方法与分类逻辑，并标注 3 处保留改造概念对象；但在缺少现状建筑、权属、结构安全与文保资料时，不给出任何具体建筑的拆除结论。

STATION-LOCATION-APPROXIMATEminor

大钟寺站、知春路站、五道口站的接驳位置为粗略示意，未使用官方轨道站点坐标与出入口资料。

NO-COMPUTE-LOAD-DATAblocking_for_quantified_claims

本走廊内数据中心与机房的装机容量、冷却方式、回水温度、年运行负荷与能效比均无公开可核验数据。本方案因此不给出任何余热回收比例、可回收热量或减排量数值。

NO-DISTRICT-HEATING-NETWORK-DATAblocking_for_quantified_claims

供热管网走向、管径、供回水温度、热源结构与现状热负荷均无可引用资料，热力接口位置只能表达为留白用地与待确认接口意向。

NO-OPERATIONAL-PERFORMANCE-DATAminor

AI 创新指数、人才密度、慢行可达性实测、活动参与度、场景使用频次等绩效指标需要运营数据持续校准，当前无法复算。

NO-GOVERNMENT-COMMITMENTblocking_for_statutory_use

本包为开源征集的概念建议与参考方案，可供专业团队深化研究。它不声称获得政府批准、审定控规、最终权属、最终建设规模或实施承诺。
