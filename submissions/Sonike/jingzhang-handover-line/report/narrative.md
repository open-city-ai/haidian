# 京张交接线：一份关于“谁在下一班负责”的城市设计

京张铁路留下的不只是线路，也是一套让复杂系统可靠运行的日常纪律：设备要巡检，问题要记录，职责要交接，异常要有人接管。AI进入城市之后，同样需要这样的空间纪律。

“京张交接线”以一条连续的蓝绿慢行地面串联三座交接场。北部众智园把研发能力交给验证；中央AI原点社区把验证结果交给开源协作；南部大钟寺把可用能力交给城市服务。两翼提供科技服务和公共场景支持，而投诉、维护、异议与停用原因沿原路返回研发端。

十二个AI场景不是技术橱窗。模型红队台、机器人沙盒、公共翻译台、无障碍副驾、维修可见驿、社区照护排班桌和口述史亭都回答同一组问题：用什么数据，谁负责，何时交给人，不用AI能否获得同等服务，失败之后怎样退出。人工接管因此不是一个隐藏按钮，而成为可以进入、辨认和使用的公共基础设施。

方案的图形语言来自铁路运维账簿与信号室。煤黑代表可审计责任，信号红代表必须停下并由人判断的阈值，电气青代表开放接口，米白代表可阅读的公共记录。四个公共地标——交接钟、公开交接桌、百年值班簿、零号接管亭——记录的不是流量和资本，而是维护、修复、有效异议与无障碍贡献。

“全球人工智能产业高地和朝圣地”在这里不是高度、企业数量或自拍背景，而是32个可复核、可回滚的设计对象，六个带RACI、KPI与接管SLO的试点包，以及一套允许提名、异议、纠错、撤回和匿名的荣誉记录。北纬社区、未来科学城、怀柔科学城、北京经开区与京津冀只通过资料和责任获授权的条件接口接入，不把协作意向写成既成事实。

所有面积和长度由临时边界在EPSG:4548中复算；所有法定强度、高度、道路、权属、市政和文保条件保持未知。方案愿意精确地表达自己知道什么，也愿意清楚地承认不知道什么。因为可信的AI城市，首先不是一座会自动回答的城市，而是一座知道何时把责任交回人手中的城市。
