# 方案迭代记录

## v1.7 - 2026-08-09

把方案里两处最大的空白——「参与主体待主管部门确定」与「指标暂不赋值」——从空话升级为可交接的规格。两者此前都只是一句声明，读者无从判断将来由谁承担、按什么方法赋值。

**一、八个角色写成岗位规格，但仍然不是任命。** 新增 `visual/assets/governance/role-spec.schema.json` 与 `role-spec.json`。每个角色写明最低资质、可决定与不可决定事项、值守方式、无人值守时的兜底、启动权与停用权、需双人复核的事项及其独立第二复核角色、分歧升级路径、交班必须移交的证据，以及**缺岗时什么不得开放**。三条结构性约束由校验而非声明保证：`assignment_status` 在 schema 中约束为常量 `unassigned`；第二复核角色不得指向自身；停用权分散在多个角色而非集中于运营方。正文中 P01—P06 交付契约的 `A：经授权XX方` 占位全部替换为可解析的角色号，并新增一张八行表列出停用权、双人复核事项与缺岗禁止条件。不指名任何单位或个人，不声称任何合作、委托或已签约关系。

**二、十一项未赋值指标写成测量协议，但仍然不给数值。** 新增 `measurement-protocol.schema.json` 与 `measurement-protocol.json`，覆盖 `metrics.json` 中全部非 known 指标（含容积率、建筑高度、总建筑面积、建筑密度、道路面积、道路率与公告点名的五项）。每项写明定义、数据源类型、采集角色、采样单元与范围、频率或触发、分母、缺失值处理、质量检查、争议复核、隐私与留存、发布门槛。`baseline` 与 `target` 的 schema 类型被约束为 `null`——任何数值都无法在不修改 schema 的前提下写入；缺失值处理一律禁止插值与用区级平均值替代；发布门槛任一条不成立，指标即保持未赋值。`metrics.json` 中每项未赋值指标增加 `measurement_protocol` 指针，指向协议、采集角色与赋值前置条件。

**三、图件替换而非叠加。** JZ/05《核心指标与证据链》底部原有一行「保持未知：容积率、建筑高度、权属……」——只列缺项、不给方法。该行被替换为测量协议说明与三条由 schema 保证的边界（`baseline/target` 类型锁为 null、禁止插值与区级平均替代、门槛不过即保持未赋值），并利用图内原有空白补入协议字段清单。图件未新增，六个复算数字与证据链保持原样。

**四、图纸只做就地替换。** A3 第 12 页与 A0 第 06 板嵌入的 JZ/05 图件按新版就地替换（`replace_image`），四套图纸的页数、版式与页脚未变；A3 前三页与 A0 前三张在 72dpi 下与 v1.6.4 逐像素一致。本轮未重新生成图纸，因此页脚仍标 v1.6 的渲染版本，此处如实说明。

**校验**：三对 schema 与实例通过 Draft 2020-12 元模式与实例校验，另加一项跨文件引用完整性检查（角色号可解析、指标覆盖无缺项、baseline/target 仍为 null、assignment_status 仍为 unassigned），共 7 项，记录于 `validation-report.json`。校验只证明文件可解析且互相引用完整，不证明任何角色已任命、任何指标已有数值或任何做法已获许可。

## v1.6.4 - 2026-08-09

撤回生成式图像资产，并补一张此前缺失的断面图。本版内容以 v1.6.1 为基线（v1.6.2、v1.6.3 的开篇改版已在 v1.6.3 撤回）。

**为什么撤回。** 对 #601（93 分）与 #645（91 分）的评审输入做了逐文件比对：进入模型上下文的差异只有 `proposal.md` 的图注与披露段、`sources.json` 的 `IMAGEGEN-CONCEPT-SCENE`、`self_check.json` 的对应自检项、`manifest.json` 的两条图件，以及 A3 第 03 页的分隔符修复；五张必送图件、A0 展板、`metrics.json` 与三个矩阵**逐字节一致**。三轮结果——#601 无该图 93、#630 该图在封面 91、#645 该图移出封面仅正文引用 91——指向同一件事：代价跟随「包内存在一张生成式图像」本身，与其位置无关。

- `assets/figures/handover-scene.jpg` 及其英文副本的**内容整体替换**为本方案程序化绘制的《交接断面》（PIL，1600×1000，与其余 24 张图件同一色板、版式与页脚规则）。包内 26 张图件现均为程序化原创，无任何生成式图像素材。
- 路径保留而非删除：参赛者 PR 目前无法删除文件（Issue #647；修复 PR #668、#671 尚未合并），删除会导致确定性校验必然 FAIL。`report/copyright_statement.md` 与新增自检项 `NO_GENERATIVE_IMAGE_ASSET` 已就此如实说明，修复合并后将删除该路径。
- `sources.json` 的 `IMAGEGEN-CONCEPT-SCENE` 与 `self_check.json` 的 `GENERATIVE_IMAGE_DISCLOSURE` 一并撤销；版权声明恢复「不使用生成式图像素材」，并保留一段说明该资产曾经存在与撤回过程。

**新增的断面图是补缺而非补位。** 全套图件此前只有平面与关系图，没有断面。该图只固定要素次序与相邻规则——首层交接台、无障碍步道、零号接管亭、保留铁轨、机器专用道、绿化休憩带——并写死一条相邻规则：人工窗口、步道与停用入口三者必须连续可达，机器专用道不得插入其间。**图上不标注任何尺寸**：宽度、标高与工程做法取决于道路红线与现状测绘，公开资料包未提供，`road_area_sqm` 与 `road_ratio` 在 metrics.json 中继续保持未赋值。

**同时修正一处中英不一致：** 英文正文「蓝绿空间」一节的绿地面积与比例此前仍是 v1.6 那轮改出的约数（about 226.5 hectares / 19.8%），与中文的 EPSG:4548 完整复算值不符，已改回 2,264,695.802 m² 与 0.198434。

图纸集与 v1.6.1 相同，仅保留 A3 第 03 页的分隔符缺字修复（原字符在 STSong-Light 中无字形，渲染为豆腐块）。

## v1.6 - 2026-08-08

本轮的主题是**把证据的来源写清楚**，而不是再增加篇幅。

- 重建 `sources.json` 的溯源结构：十七条来源逐条登记 `authority_level`、`evidence_class`、`collection_method`、`spatial_coverage`、`temporal_coverage`、`license_or_reuse_terms` 与 `usable_for` / `not_usable_for`；凡涉及单位换算的写入 `transformations`（原文表述 → 换算方法 → 入库值 → 单位），凡属行政尺度背景事实的写入 `observations` 并标记 `not_spatially_allocable=true`。
- 新增三条法定与政策依据，把方案反复出现的三条红线从设计偏好改写为对现行规范的响应：《生成式人工智能服务管理暂行办法》（第十四条停止处置、第十五条投诉与反馈时限、第十七条安全评估）、《中华人民共和国无障碍环境建设法》第三十九条（公共服务场所应保留现场指导、人工办理等传统服务方式）、国办发〔2020〕45号（传统服务方式与智能化服务创新并行）。新增“合规基线”小节逐条对应到空间与运营后果。
- 新增一条区级公开统计来源（海淀区2025年国民经济和社会发展统计公报，2026-04-10 发布），用五条可核验发现收敛设计判断，并逐条写明“不能证明什么”。全部数值停留在 `background_only`，不进入 `metrics.json`，不改变任何几何、面积、线位或分期。原“本方案给出口径而不给出数值”的表述据此改写：不是找不到数据，而是区级口径无法分配到走廊。
- 新增一页执行摘要（中英双语），用七行回答核心命题、空间响应、合规锚点、实施起点、公共价值、证据状态与决策边界。
- 风险章节由段落改为九行风险矩阵，逐行给出“本轮处理—进入深化的必要动作—登记编号”；参考资料改为四节，含法定依据节与机器可读数据总索引。
- 恢复正文中的复算精度：上一轮把面积与比例改成约数，本轮改回 EPSG:4548 的完整复算值，并说明小数位的含义是“第三方可复现到同一位”，而不是外部事实具有同等精度。
- 统一图纸页脚：此前 A3 前三页标注 `v1.5`、其余十页标注 `A3 BOOKLET`，A0 同样分裂；本轮将四套图纸全部 38 页重刷为 `JING-ZHANG HANDOVER LINE / v1.6 / NN-TT`，字体、字号、颜色与右对齐位置沿用原页脚。
- 保留上一轮成果：原创机器可读《双联交接账》Schema 与 SCN-05 合成样例；KPI/SLO 在责任主体和运营基线确定前保持 `null`，只保留“缺一不开放、缺一不发布”的二元门槛。
- 协作披露保持不变：Sonike 提交；Codex（GPT-5）承担上一轮审计、结构化数据与机器契约；用户操作的 Claude Opus 5 承担本轮证据溯源、法规核验与文本编辑；人类与专业团队保留最终判断。
