## v1.6 - 2026-08-08

本轮的主题是**把证据的来源写清楚**，而不是再增加篇幅。

- 重建 `sources.json` 的溯源结构：十七条来源逐条登记 `authority_level`、`evidence_class`、`collection_method`、`spatial_coverage`、`temporal_coverage`、`license_or_reuse_terms` 与 `usable_for` / `not_usable_for`；凡涉及单位换算的写入 `transformations`（原文表述 → 换算方法 → 入库值 → 单位），凡属行政尺度背景事实的写入 `observations` 并标记 `not_spatially_allocable=true`。
- 新增三条法定与政策依据，把方案反复出现的三条红线从设计偏好改写为对现行规范的响应：《生成式人工智能服务管理暂行办法》（第十四条停止处置、第十五条投诉与反馈时限、第十七条安全评估）、《中华人民共和国无障碍环境建设法》第三十九条（公共服务场所应保留现场指导、人工办理等传统服务方式）、国办发〔2020〕45号（传统服务方式与智能化服务创新并行）。新增“合规基线”小节逐条对应到空间与运营后果。
- 新增一条区级公开统计来源（海淀区2025年国民经济和社会发展统计公报，2026-04-10 发布），用五条可核验发现收敛设计判断，并逐条写明“不能证明什么”。全部数值停留在 `background_only`，不进入 `metrics.json`，不改变任何几何、面积、线位或分期。原“本方案给出口径而不给出数值”的表述据此改写：不是找不到数据，而是区级口径无法分配到走廊。
- 新增一页执行摘要（中英双语），用七行回答核心命题、空间响应、合规锚点、实施起点、公共价值、证据状态与决策边界。
- 风险章节由段落改为九行风险矩阵，逐行给出“本轮处理—进入深化的必要动作—登记编号”；参考资料改为四节，含法定依据节与机器可读数据总索引。
- 恢复正文中的复算精度：上一轮把面积与比例改成约数，本轮改回 EPSG:4548 的完整复算值，并说明小数位的含义是“第三方可复现到同一位”，而不是外部事实具有同等精度。
- 统一图纸页脚：此前 A3 前三页标注 `v1.5`、其余十页标注 `A3 BOOKLET`，A0 同样分裂；本轮将四套图纸全部 38 页重刷为 `JING-ZHANG HANDOVER LINE / v1.6 / NN-TT`，字体、字号、颜色与右对齐位置沿用原页脚。
- 保留上一轮成果：原创机器可读《双联交接账》Schema 与 SCN-05 合成样例；KPI/SLO 在责任主体和运营基线确定前保持 `null`，只保留“缺一不开放、缺一不发布”的二元门槛。
- 协作披露保持不变：Sonike 提交；Codex（GPT-5）承担上一轮审计、结构化数据与机器契约；用户操作的 Claude Opus 5 承担本轮证据溯源、法规核验与文本编辑；人类与专业团队保留最终判断。
