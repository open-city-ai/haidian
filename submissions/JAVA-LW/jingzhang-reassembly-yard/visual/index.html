京张再生编组场

REASSEMBLY JINGZHANG｜把铁路“编组”转译为城市更新方法：空间、材料、功能与时段在拆建之前先被发现、匹配、试用和复盘。

资料边界

总体设计范围和三处重点区使用仓库 provisional rough polygons，仅供生成、自检、可视化和设计讨论。它们不是官方红线，不支撑审批、权属或精确面积；官方数据到位后整包重算。

总览地图

一条再生主线串联技术、知识、生活三座重组场；两翼提供科技服务与城市实测；十二个换轨节点承担可请求、可接管、可申诉、可退出的公共 AI 场景。

建筑

九个建筑要素是再生原型，不对应现状建筑：保留优先诊断站、低扰动改造工坊、可逆加建样板、共享首层接口。没有建筑被本方案判定拆除。
