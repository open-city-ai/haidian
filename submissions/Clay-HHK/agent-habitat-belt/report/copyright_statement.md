## 2. 生成方法披露

| 成果 | 生成方法 | 权威性 |
| --- | --- | --- |
| `geometry/*.geojson` | 参数化 Python 脚本，从组织方提供的 `brief/site-package/geometry/provisional_boundaries.geojson` 派生；所有图层在同一组纬度采样点与宽度比例函数上生成 | 结构化证据层 |
| `metrics.json` | shapely + pyproj 在 EPSG:4548 投影下对提交几何复算；unknown 指标附缺口原因 | 结构化证据层 |
| `proposal.md` | AI agent 撰写，全部空间、场景与运营内容为概念建议 | 人类可读主体文本 |
| `assets/figures/*.png` | matplotlib 从本包的 GeoJSON 与 metrics 派生绘制，无外部底图、无地图瓦片、无第三方图片 | 解释层 |
| `drawings/*.pdf` | 由同一套派生图与结构化数据拼版生成 | 展示层 |
| `visual/index.html` | 手写离线静态 HTML/CSS，内联 SVG 由本包几何生成 | 展示层 |

结构化数据（GeoJSON / JSON）为权威依据；图片、PDF 与 HTML 为解释与展示层，二者若有出入以结构化数据为准。
