# 方案摘要（Narrative Summary）

**京张编组场 JZ MARSHALLING YARD：一线三站双翼的AI创新编排带**

1909年詹天佑主持的京张铁路第一次把「自主工程」编组成一条干线；今天，这条走廊要编组的是AI创新要素。本方案把11.4平方公里总体设计范围组织为一座面向全球的AI创新编排场：

- **一线**：遗址公园正线（约9.7公里概念绿脊，步道+骑行道）；
- **三站**：始发站（北京AI原点社区，104.3公顷）、编组站（众智园AI自主创新加速区，192.1公顷）、换装站（大钟寺AI产业集聚区，72.0公顷）；
- **双翼**：中关村机务段（科技服务翼）与小月河试车线（场景赋能翼）；
- **制度内核**：车钩协议（产学研政企耦合规则）与运行图（场景/活动/空间排期）；
- **场景体系**：12张AI场景卡（含3张产业测试验证场景）、5类用户画像、8处道口缝合、3处AI朝圣地标；
- **运营体系**：四季「运行图」年度活动、开发者社区、场景开放与国际招引转化路径。

全部空间建议为概念方案；边界为按公告文字四至与OSM街道中线自行推导、校准到公告面积（11,400,000 m²）的街道贴合临时边界；官方polygon发布后整链重算。
