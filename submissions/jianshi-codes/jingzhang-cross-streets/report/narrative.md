# 京张横街 / Jingzhang Cross-Streets

## 一页评审摘要

方案把43.6平方公里理解为一张城市网络，而不是一条纵向品牌带：京张公园承担南北公共骨架，清河与小月河承担蓝绿边界，八条真实横街承担校园—园区—社区—站口—水岸之间的横向连接。三大定位和五大功能通过三区两翼协同落到这张网络，八要素生态图谱同时说明空间载体、运营机制和边界。

11.4平方公里总体设计沿真实横街、公园曲线和水岸形成完整、非等宽的概念用地拓扑；三类有量纲剖面分别控制水岸研发、近校转换和四象限站城。众智园、AI原点与大钟寺各有独立首层平面、概念剖面、公众/后勤流线、日常/事件状态、地标构成和首批项目，不用三座雕塑替代城市设计。

15项项目按公共空间、合作租赁、法定工程三类权限实施。12张场景卡逐卡给出房间、频次/容量、验收和停止触发；三处贡献架、开发者社区、场景开放八道门和国际转化路径补齐长期运营。正式GIS、地块权属、FAR、高度、市政与工程资料仍待补齐，但它们触发整链替换，不构成停止设计的理由。完整叙事见 `proposal.md` / `proposal.en.md`；双语图件、A3/A0、九类GeoJSON、指标、来源、假设和逐项矩阵使用同一编号。
