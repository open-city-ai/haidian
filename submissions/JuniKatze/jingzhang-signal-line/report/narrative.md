# 方案概述（摘要）

**京张信号带 JINGZHANG SIGNAL LINE**：把百年铁路的信号纪律（红黄绿分级、进路联锁、故障导向安全、人工确认发车）转译为 AI 创新带的治理与空间协议。

- 空间结构：一带（京张遗址公园活力正线）+ 三站（众智园联锁中枢 / AI原点社区信号台 / 大钟寺到发场）+ 两翼（中关村科技服务翼 / 小月河场景赋能翼）+ 十二个信号分级场景节点。
- 任务覆盖：命名与视觉识别方向、6 个全球 AI 生态案例、12 张场景卡（含 3 个产业测试验证场景）、6 类用户画像、3 个 AI 朝圣地标（零号信号塔 / 联锁大厅 / 到发钟楼）、京张·中关村·AI 新文化叙事、年度活动与长期运营机制。
- 指标：总体设计范围约 11.41 km²（EPSG:4548 复算，与公告 11.4 km² 偏差 0.11%），绿地率约 20.3%，公共空间率约 0.8%，三处重点区分别约 192.9 / 104.3 / 72.0 公顷。
- 边界：全部空间建议基于维护者临时粗略边界（provisional），非官方红线；官方 polygon 发布后整包复算。
