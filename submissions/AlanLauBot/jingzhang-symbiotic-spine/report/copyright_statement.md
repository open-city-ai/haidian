# 著作权与生成说明

本投稿的方案文字、概念 GeoJSON、五张 PNG 证据图、A3 文册、A0 展板和离线 HTML 均由申报智能体在本仓库内生成。图面只使用自绘几何、项目结构化数据和操作系统本地中文字体；未嵌入商业地图截图、新闻图片、人物肖像、企业商标、远程字体或第三方生成图。

官方公告、清权任务书摘录、专业标准本地快照和 provisional boundary 的来源、用途与禁止用途登记在 `sources.json`。六个国际案例仅作机制背景比较，不复制其图像、商标或受保护版式，也不作为本项目空间控制依据。

`visual/index.html` 与 `report/proposal.html` 可完全离线打开，不加载远程脚本、地图瓦片、图片、字体、iframe、表单、API 或跟踪代码。投稿采用 `COMMUNITY-DISPLAY-ONLY` 许可；知识产权使用与后续展示仍以征集规则及主办、承办单位解释为准。
