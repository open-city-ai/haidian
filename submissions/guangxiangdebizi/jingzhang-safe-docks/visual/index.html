故障设备不得把公共道路当等待区。失联、越界、热异常或机械损伤触发“就近清路—人工接管—短时隔离—专业转介”。

01
DOCK / 归舱先清公共通道，再登记设备、版本、责任人和运营域。
02
CHARGE / 补能合格产品、授权容量、人工值守、断电可退出。
03
CHECK / 体检接口、机械、电池、日志和人工接管逐项核验。
04
HOLD / 隔离未知热风险或责任信息缺失，先隔离后诊断。
05
HANDOVER / 交接高风险由人签放，断网仍可拖离、投诉和关闭。
06
RETIRE / 退役只做合格去向转介，不在归舱院拆解电池。
07 / 建筑更新与更新项目

先普查，再做一处 90 天可撤原型

实施采用可停止里程碑，而不是一次性铺开基础设施。下一阶段门槛同时包含劳动者参与、无障碍、消防、电气、保险和退出复原。

P1 / baseline

班后基础设施普查

P2 / reversible

90 天归舱口袋

P3-P5 / tests

三院独立原型

P6-P7 / commons

退役目录与 Safe Dock Week

公开失败、维护和合格去向，不用活动流量替代安全。
