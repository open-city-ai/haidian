# 最后一盏灯：评审摘要

## 公共承诺

本方案把京张创新带定义为一条夜间基本服务与人工帮助连续网络。任何人无需消费、扫码或接受画像，即使断网，也应能找到可坐、可饮水、可如厕、可充电、可查询末班换乘并能向真人求助的节点。这里承诺的是可审计的服务连续性，而不是对绝对安全的夸大保证。

## 空间抓手

一条连续主线连接十二座分型灯站，并以三处首发原型建立不同能力：众智园的恢复测试庭验证离线降级、人工急停与恢复；AI 原点的不消费学习厅提供免费夜间学习、开源门诊与照护接力；大钟寺的末班车前厅提供等候、厕所、饮水、纸质地图、无障碍换乘和人工帮助。所有边界均为概念性 provisional geometry，official polygon 到位后必须重算。

## 治理与实施

每个试点都携带一张公开的“席签”，同时列明公共目的、运营者、数据保存期、模型版本与失效边界、人工决策点、等价非 AI 服务、暂停申诉入口和到期复审日。使用者、社区、创新、运维和生态代表拥有表决席，AI 只列席检索、模拟、翻译与归纳，不拥有最终票。

实施从三处原型与夜间服务基线开始，经权利预审、数字沙盒、小范围实测和公开复盘后，才决定采用、调整或下线。首期优先使用存量空间和可逆构件；任何永久工程、拆改留判断、交通组织和市政接口，均需在权属、文保、测绘和工程条件齐备后由专业团队深化。

## 证据入口

空间依据见 `geometry/`，可复算指标见 `metrics.json`，来源和假设见 `sources.json` 与 `assumptions.json`，合规、专业标准和设计深度证据分别见三张矩阵。中英文总览、五张核心图和两套图册共同构成离线可读的正式展示包。
