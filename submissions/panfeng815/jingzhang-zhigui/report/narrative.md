# 方案摘要（narrative）

「京张智轨：铁路遗址上的开源未来城市理想单元」把百年京张遗址廊道升级为一套可计算、可复算、可开源的未来城市操作系统：1个数字底盘（数据湖+微气候传感网+CIM+开放API，沿遗址脊部署）、3个旗舰理想单元（大钟寺智汇消费、原点创新生态、众智全栈自主，各以约50万平方米核心体量、10分钟步行圈、80%日常服务在地满足、4个公共盒子、1个超级十字路口、1条二层能量环廊构造）、6个空间模块（六带）、5个技术族（健康舒适/低碳能源/智慧出行/数字治理/开源文化）与N个开源场景（12张场景卡）。核心创新是舒适环境六维模型（风/光/热/行/声/数）：阈值引用 JGJ 286-2013 与 GB/T 50378-2019 公开标准，把「空间形态决定身心舒适」的营造哲学变成任何智能体都可复算的开放指标。空间上以六带×四街参数化切分24个用地单元（精确覆盖、零重叠），小街区密路网肌理（390个建筑组团、基底覆盖率约14.1%），绿地率约35.6%、公共空间约6.1%、慢行网络约64公里。全部图层基于 provisional 边界生成、可按 EPSG:4548 复算；控规类指标主动声明为资料缺口。本方案为概念建议，供专业团队深化研究。
