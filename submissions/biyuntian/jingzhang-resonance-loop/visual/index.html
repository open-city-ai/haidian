一条公共界面链：不让三核成为三个孤岛

清华园—东升镇—中关村—大钟寺被组织为六段可步行、可解释、可维护的连续界面。东侧学院路/铁路走廊与中部东西向快速路是需要谨慎衔接和复核的结构条件。

movement → explanation → bounded service

连续性优先于装置密度

相邻段的步行、无障碍、照明、人工入口与维护人均可核验时，有限服务才可出现；先让普通人能走、能懂、能停留。

跨线不作工程承诺

快速路、铁路、站口和路口的过街、交通组织与工程动作须在正式资料和专业审查后深化；概念图不替代审批依据。

品牌识别：双线同频

深铁蓝是铁路时间线，蓝绿色是公共验证线，琥珀色标出贡献与夜间公共服务。标志是概念资产，不替代法定导视或机构品牌。

identity concept

回响留存：数字服务留下什么

每项数字服务还须为街区留下不依赖账号、设备或算法持续运行的公共空间改善；无维护人、无人工入口或现场条件变化时不得扩容。

lasting civic return

通行回响

众智园测试庭留下遮阴、坐憩、纸质说明和人工答疑，即使展项关闭也可使用。

知识回响

AI 原点留下实体导览、贡献署名、公共工作台和撤回入口，不登录也能理解与参与。

维护回响

大钟寺优先留下静态导视、无障碍点、夜间提示和人工问询，保障高峰与离线状态。

天气—空间—服务照护环：蓝绿系统先服务日常韧性

AI+能源和 AI+公园运维不以装置数量定义。晴天先遮阴停留，降雨先排水避让，傍晚先照明与人工服务；低碳算力只以非实时、可解释方式进入现场。

sun · rain · evening

照护优先于展示

众智园保留遮阴、坐憩与低碳解释；AI 原点保留雨天实体信息与避让；大钟寺保留夜间导向、无障碍与人工问询。

不伪造工程或实时能力

没有管线、排水、防洪、供电、消防和权属资料时，不预设工程方法、容量或性能数值；展示数据不能冒充实时预警。

文化运营回路：四季都要回到现场

清华园—东升镇—中关村—大钟寺不是活动背景，而是“记忆—提问—共创—回响”的连续文化线。每季活动都须留下实体成果，并公开修订、暂停或保留的决定。

culture + operation

活动的可验证成果

春季留下离线路径图；夏季留下授权/署名与公共工作台；秋季留下静态导视与人工问询；冬季留下责任卡与维护清单。

不以热度决定扩容

缺少场地许可、人工值守、无障碍条件或明确维护人时，活动缩减或暂停；到场人数与传播热度不能替代复核。

四个文化节点：不只是活动时的打卡点

清华园、东升镇、中关村 / AI 原点和大钟寺各有不同的停留理由、公共叙事、低门槛参与和离线留存物。三种文化在同一条日常路径中轮流成为主角。

memory · question · contribution · return

轻量媒介，不制造数据负担

深铁蓝标记时间与路径，蓝绿色标记公共问题和人工入口，琥珀色标记贡献与夜间服务；以纸质、实体和人工为主。

公共界面不能广告化

不以连续布屏、统一扫码、企业广告、未经授权内容或无人化服务占据文化节点；文字与导览须经无障碍、版权和场地条件核验。

共振协议：三段验证、四个公共门槛

本案以“机制—原型—场景—证据—运营”闭合逻辑，将可理解、可选择、可接管、可复盘四个门槛用于校验 AI 服务能否进入日常公共空间。

可理解可选择

RP-03 人机共行商街

大钟寺 · 城市应用段

先改善过街、遮阴、坐憩、照明与静态导视，再叠加可解释提示。拥挤、误导、无障碍失效或隐私争议时切回人工系统。

可复盘人工优先

不把技术演示当作公共价值

每项服务都要回答：谁使用、在哪里获得人工替代、谁维护、什么情况必须暂停。服务可退回上一个验证段修订，不构成单向产业流水线。

概念性与专业前置条件

三段只对应临时重点区索引。实际位置、尺度、建筑动作及工程条件须在正式边界、权属、交通、市政、消防和文保资料齐备后深化。

三核一日：不同时间，不同的公共优先级

早高峰先保障通行与人工入口，日间再开放可解释协作，傍晚以人工复核收束。时段是概念性运行情景，不是营业时间或工程实施承诺。

daily rhythm + site receipt

每一时段都有离线底线

无手机、无账号或无算法时，普通人仍能通行、理解、停留并得到人工帮助。数字服务不能抢占主通道或替代静态导视。

以现场回执代替流量叙事

测试范围、授权/修订入口以及高峰/夜间人工服务状态仅以汇总方式公开；条件不满足即缩小、转人工或暂停。

可逆空间细部：不是一次性改造清单

遗址公园、近校界面与站城街角均先观察使用，再采用不阻断通行的临时构件，最后才决定是否进入专业深化。数量、尺寸、材料、造价与固定方式均留待核实条件后确定。

observe → place → review → hand over

四份可交接材料

现场观察表、临时布置图、人工服务责任卡、撤回/修订记录，比固定装置更早进入审查和公众沟通。

条件变化即撤回

积水、遮挡、疏散冲突、权利不清、拥挤、误导或隐私争议时，撤去临时物，恢复人工与静态服务。

不复制国外项目的尺度、资金或治理权限，只提取可被本地进一步核验的空间与运营机制。

先走读遮阴、坐憩、导向、雨天避让和无障碍断点；留下纸质路径图、问题卡与可移动坐憩。

退出：遗存、过街、消防或无障碍条件不清，停留在观察与人工导览。

R03—R04 中段

可信测试回响庭 / 开源知识前台

临时遮阴、纸质说明、成果卡与人工咨询，只在公共庭院和近校前台仍可日常使用时出现。

退出：主通道受阻、无人接管、权利或维护不清时，撤去展项并转线下人工服务。

R05—R06 南段

跨线安全缝合 / 站城日常门

高峰、雨天、夜间先核验连续性；仅补临时静态导向、无障碍停留点与人工问询。

退出：涉及道路/铁路工程或出现拥挤、投诉、安全风险时，恢复常态静态服务。

十二项微更新，不靠一次性建设取胜

从纸质导览、问题地图到说明台、权利咨询、夜间导视，每项都有首轮动作、协同接口、最小证据与回退动作。

先核验，后深化

空间交付卡是概念性公共证据框架。正式边界、交通、市政、消防、文保和权属资料未齐备前，不作工程承诺。
