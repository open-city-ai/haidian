# 方案迭代记录

## v1.0 - 2026-08-07

- 建立 formal 方案包：`proposal.md`（中文主体，16 章 / 约 2.37 万字）、`geometry/*.geojson`（9 个图层）、`metrics.json`（EPSG:4548 复算）、三大矩阵、五张图、A3 册子与 A0 展板、离线 `visual/index.html`。
- 总体概念「人字带 REN BELT」：取京张人字形展线的历史原型，一轴（已建成主轴）、两翼（要素翼与场景翼）、三折返点（三处重点区域）。
- 关键判断：京张铁路遗址公园 9 公里绿廊已于 2026-08-06 全线贯通，官方「三线织锦」中历史线与生活线已落地、创新线仍停留在概念层。因此本方案不重画绿廊，而是为已建成主轴补上创新线，把 43.6 平方公里的产业叙事收敛为 11.4 平方公里的可实施缝合动作。
- 用地单元 120 个对临时边界无缝全覆盖；里程标作为全带统一寻址单元，同时承担导视与治理反馈定位两个职能。
- 城市智能体治理独立成章，五个机制：场景公示牌（进入公共空间组件库与市政设施序列）、场景开放双轨流程（先孪生后街道 + 公共审议）、人工复核按后果可逆性分三级、里程标寻址反馈、agent 生成与人类最终判断的四层可复用知识结构。
- 回应任务书 agent.1–agent.7：6 个全球案例（含新加坡 Punggol ODP、蒙特利尔宣言）、12 张场景卡、四段式证据链（正文五类引用标注 / 三大矩阵映射 / 每要素五必填属性 / 每指标七必填字段）。
- 自检：deterministic / spatial / visual / professional 四项全部 PASS；advisory 评分 7 pass、1 needs-work（引用了索引外的公开政府与媒体资料，每条已在 `sources.json` 登记来源与使用限制）。
- 边界声明：`site_boundary.geojson` 为 provisional_constraint 临时边界，非官方红线，不得作为精确面积基准；官方 polygon 发布后整体复算。全部空间与运营内容均为概念建议。
