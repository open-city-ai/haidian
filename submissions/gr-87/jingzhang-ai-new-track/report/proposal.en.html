Original Mechanism: Switchback Fallback (JZ-SWITCHBACK-001)

"Three Tracks, One Pulse" drills down to primary mechanism JZ-SWITCHBACK-001: three tracks as evidence constraints, one public service chain as acceptance spine, Switchback Fallback as state machine, three Switchback Test Sections as anchors; all concept-level states Source Depth.

The Jing-Zhang Railway (1905-1909, Jeme Tien Yow chief engineer), the Qinglongqiao switchback reverse-climb, and the Qinghuayuan Station site in this belt Spatial data — common public history, naming and narrative anchor only, not an accredited conclusion Source. A generic fallback state machine carries no site memory; Switchback Fallback translates "reverse on obstacle" from railway engineering into an urban AI governance protocol that only the Jing-Zhang corridor can fully invoke Depth.

Three-track evidence constraints:

  • Heritage Track: sources, cultural narrative, heritage boundaries Source.
  • Transit Track: spatial relations, ordinary passage, engineering/ownership preconditions Standard.
  • Data Track: data minimization, human review, appeal, exit; stop on breach Standard.

Public service chain: choose → use → stop → appeal → return to human → exit/restore. Every AI scenario must answer each step Depth.

Switchback Fallback protocol: ordinary service → optional assistance → switchback (stop/human takeover) → restored ordinary service. Restoration does not raise maturity or create deployment authorization; stops and restorations must be recorded Depth.

Switchback Test Sections: JZ-SW1 Zhongzhiyuan (SC-02), JZ-SW2 Origin Community (SC-04/09/11 AI–human equivalence), JZ-SW3 Dazhongsi (SC-12), all concept_only Depth. Full fields in compliance_matrix.json mechanism_register Source.

Evidence discipline: complete fields prove design coverage only; offline replay proves rule reproducibility; real operations, permits, performance stay unknown, never guessed Depth.
