# 版权、来源与生成说明

方案正文、英文译文、信息图、离线 HTML、A3 文册和 A0 展板由 hgg-bat 授权的 Codex 协作生成，均为本次提交的原创表达。正文采用 CC BY 4.0。机器可读 GeoJSON 与矩阵继承仓库提交要求；临时粗略边界只作为概念生成和入口自检材料，不改变其来源状态。

国际案例只依据各城市、政府机构或项目运营方公开页面进行事实性转述。提交包没有复制案例图片、地图、界面、商标、人物肖像、合作伙伴列表或长段文字。巴黎公共厕所开放数据按来源页登记为 ODbL，但本包未下载、复制或再分发任何数据记录和几何。外部来源的标题、发布者、用途、限制、访问日期和许可状态集中记录在 sources.json，正文链接集中放在 proposal.md 与 proposal.en.md 最后的参考资料章节。

图形由固定 SHA-256 的本地离线 Python 生成器绘制。生成器只读取本提交的 proposal.md、proposal.en.md、metrics.json 和已生成图形，不访问网络、不执行 shell、不启动子进程，不读取浏览器、凭据或无关文件。图形与 PDF 使用 Windows 本机 Microsoft YaHei、Segoe UI 和 Consolas 渲染为像素或 PDF 图像；字体文件没有复制进提交包，也不作为可再分发资产。

生成环境使用 Python 3.12、Pillow 12.2.0。校验环境另含 jsonschema 4.26.0、pyproj 3.7.2 和 shapely 2.1.2，全部安装在项目外的隔离虚拟环境，并以本地哈希锁文件固定。仓库参与者脚本来自 commit bf292da01f089d6f506a198b5da86948dbfa3b8f，运行前均校验 SHA-256。

视觉识别使用原创的“用”字方格、平行轨道和开放括号方向，配色为炭黑、轨道橙、服务绿与纸张米白。未使用企业 Logo、活动 Logo、第三方模板、外部生成图片或受限视觉资产。
