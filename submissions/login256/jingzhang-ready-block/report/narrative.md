# Ready Block evidence note / 免登录证据说明

`known + value` denotes only a value recomputed from submitted geometry. `metric_kind=conceptual_derived` or `provisional_derived` prevents it from being read as an official existing-condition or statutory value. A proposed performance threshold uses `status=unknown`, `value=null` and a separate `design_target`; it must never be displayed as achieved before authorised field measurement.

本包将“可从提交几何复算”与“已获官方确认”严格分开。Ready Block 三个百分比/字段目标全部保持当前值未知；交互审计仅使用合成场景。
