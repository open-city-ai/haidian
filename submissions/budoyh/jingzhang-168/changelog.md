# 方案迭代记录

## v4.0 - 2026-08-11

### 大幅迭代摘要

- 完全撤下 v3 的“AI按表到站/城市站/72分支”主叙事，重构为独立概念“京张常在 / JING-ZHANG CITY ON”：先证明无AI公共基线，再允许受限增益，必须物理退场，最后只把可维护的公共红利留给城市。
- 建立 `BASE → BOOST → BLACKOUT → BEQUEST` 四态公共红利合同；十二项场景逐一登记普通服务、人工权责、允许/禁入数据、空间边界、物理拔线、删除/恢复证据、留城资产和维护人。
- 将三处重点区改造为三种“技术后生命”原型：众智安全红利场、AI原点开源红利工场和大钟寺日常红利客厅；形成一条公共基线脊、六处东西横缝、七类离线可用构件和十二个空间化场景节点。
- 新增严格机器协议 `unplugged-test.schema.json`、合成样例与离线 `unplugged-runner.js --check`。12份合同各执行7类分支，共84例：60条缺字段或禁入路径被阻断，12条普通完整路径进入授权前复核，12条退场路径进入红利复核；真实个人数据为0，现场绩效保持 `null`。
- 实施切片改为首12周九阶段：两周无AI基线、普通1:1样机、合成影子运行、授权增益、第8周城市退场日、红利与维护劳动审计、独立公众复核、保留/修改/拆除。G0—G7项目成熟度与C0—C7场景准入继续分离。
- 重建五张中英核心证据图、20页双语A3、7板双语A0和离线双语HTML。评审固定视窗前三页/板已覆盖公共承诺、总体总图、三座红利场、四态合同、退场日和84分支证据边界。
- 新增无自动播放、无音频、无片内文字的约34秒概念漫游及双语字幕/文字稿。三张GPT Image 2源图仅作本地裁切、调色、转码与编排，继续明确排除在空间、数字和工程证据之外。

### 86分反馈响应

- v3官方评审只公开总分86，未公开七维子分；本轮不虚构失分明细，也不通过重复堆料追分，而是同时重做原创命题、最小实施切片、公众权利、失败证据和固定视窗表达。
- 对比96分公开优秀方案后，保留“可定位、可停止、可复核”的高标准，但不复制 Token Block、Proofline、Human Hours、Civic AI Relay 或其他方案的名称、图像、协议、数据、几何与品牌。
- 本地 `84/84`、CI PASS、仓库 intake、正式评分与获奖继续严格区分。本版以七维均达到 exceptional 内容证据为目标，但不把模型评审的单次100分写成可保证结果。

## v3.0 - 2026-08-11

### 大幅迭代摘要

- 用官方现状纠正设计前提：京张铁路遗址公园已有建成开放段，公园名录载明免费、免预约、24小时开放。主命题从“增加公共开放小时”改为“公园全天开放，AI按表到站；AI可停运，公共路径不可停运”。
- 撤销 v2 的 `97.0 million m²·h/week` 头部数值。现状公园168小时事实不再外推至临时总体范围；设计区有效开放小时和平方时保持 `unknown`，待逐段现场验证。
- 将三处重点区重构为三种剖面不同的城市站原型：众智验证园、AI原点开放换乘厅、大钟寺城市公共终点站；每处均明确全天公共层、限时服务层、受控后勤层以及保留/修复/可逆新增动作。
- 重写十二项服务：北部产业验证、中部知识转接、南部日常公共服务；每项同时登记人工负责人、非AI等价、禁入数据、停止触发、复原动作、预期回执和非参与者影响。
- 新增可复现 `visual/assets/tabletop-runner.js --check`：对12份合同分别执行正常、缺人工、缺非AI路径、禁入数据、堵塞公共路径、停运后复原六类合成分支，共72例；脚本无网络/设备I/O，不使用真实个人数据，现场绩效保持 `null`。
- 新增八维 `risk.json`、`civic-timetable.json`、`station-prototypes.json` 和 `timetable-tabletop-evidence.json`；政策资料、空间争议、实施复杂度明确保留为高风险，不用视觉包装降低不确定性。
- 资料库扩展至北京规划、园林、文物、海淀更新、智能体AI政策、个人信息保护与全球公共AI透明机制等一手来源；OSM 412.5米差异只作风险披露，不替代或平移临时边界。

### 89分反馈响应

- 官方89分只公开总分，未公开七维子分；本轮不虚构失分结构，而是针对96分优秀方案的共同强项——现场冲突、最小可执行切片、失败证据与清晰空间原型——补齐独立证据。
- 桌面PASS与现场成功、仓库接收、正式审批和获奖继续严格区分；目标是满足七维5/5内容合同，不能承诺评审模型单次必得100。

## v2.0 - 2026-08-09

### 改动摘要

- 保留“京张168：把一周还给城市”与 `m²·h/week` 核心命题，把静态叙事升级为可校验的周运行协议：三时区、六预约区段、七时间构件、十二场景节点与八状态机共用唯一 ID。
- 新增 `first-168h` 九段相对时钟、三权分离治理、十个待确认角色、九个项目 RACI、G0-G7 项目成熟度门、C0-C7 场景准入门及停止、归还、审计回执；没有依据的预算、容量、SLO 和成效指标保持 `unknown`。
- 将 12 张场景卡逐一绑定空间、受影响与非参与者、最小数据、非 AI 等价服务、人工责任、暂停权限、复原计划和证据产物。
- 重建 23 项任务矩阵、6 项标准矩阵和 15 项设计深度矩阵，消除 `agent.1` 至 `agent.6` 使用同一组证据的模板化映射。
- 完整迁移至 proposal v2 与 bilingual contract v1：中英文正文、五张证据图、HTML、A3 文册和 A0 展板保持同构与等义。
- 将旧版五张生成式插画退出核心证据层。新版核心图由 GeoJSON、metrics、协议和矩阵确定性派生；GPT Image 2 只生成无文字概念体验图并逐资产披露。

### 采纳反馈

- 采纳维护者对旧版完整英文对应物缺失的 CI 提醒，补齐严格双语显示层和 manifest 语言映射。
- 采纳 PR #802 审阅与共享规则 #793：四张经人工复核、确认没有可读字符的中性概念图在 manifest 中逐项声明 `text_free: true`；该字段只关闭双语资产歧义，不把概念图提升为空间、数字或工程证据。
- 采纳高分同侪方案可审计方法中的共同原则：每项场景必须落位、权责必须分离、首个最小切片必须可验收、工程深化必须有可撤回闸门。
- 采纳专业视觉审阅：五张核心图独立讲清空间、协议和证据；A3/A0 不再是五张全页栅格图的重复装订。

### 暂未采纳或待复核事项

- 未复制 Token Block 的令牌协议、Proofline 的智证线语法或任何同侪文字、图像、几何、数据与品牌；本案继续以“公共时间权、周运行图与按期归还”作为独立机制。
- 未生成 FAR、建筑高度、道路红线、拆除量、工程线位、投资金额、已落实主体或已批准日程。official polygons、控规、权属、现状、文保、市政、消防、雨洪和运营资源到位后再重算与深化。
- `97.0 million m²·h/week` 仅是临时设计几何乘设计开放目标的诊断值，不是现状绩效、法定指标或扩张目标。
