# Copyright and data statement

This package uses public repository materials and repository-registered provisional geometry only. No personal data, non-public planning documents, commercial basemap, satellite imagery, unauthorised photograph, or uncleared external generative asset is included. All figures and dashboard graphics are locally rendered from the submitted GeoJSON, metrics and written concept.

All routes, nodes, capacities, speeds, operating windows and phases are conceptual recommendations. Provisional boundaries are not official redlines or survey results. Display is for community review under the repository contribution terms; later publication or implementation requires rights, privacy, accessibility, safety and statutory review.
