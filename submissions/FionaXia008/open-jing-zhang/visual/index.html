方案概述

核心概念：以开源协作精神重新诠释京张铁路百年自主创新史，提出「开源京张」品牌体系，将 43.6 平方公里创新带设计为 Git 分支模型驱动的城市级开源项目。

一句话：世界上第一座用 git 建造的城市。

叙事线：1909年詹天佑开源了铁路技术 → 1980s中关村开源了代码 → 2026年海淀开源了一座城市。三次开源，同一条轴线。

交通慢行：以开源铁道主轴为脊梁，构建贯穿南北的步行骑行道（Pull Request 长廊），连接三区两翼所有公共空间节点，形成 15 分钟生活圈。

蓝绿公共空间：京张铁路遗址公园（165.9 ha）和小月河蓝绿廊道（154.4 ha）构成全域蓝绿骨架，绿地率约 28.1% [metric:green_ratio] [metric:public_space_ratio]。
