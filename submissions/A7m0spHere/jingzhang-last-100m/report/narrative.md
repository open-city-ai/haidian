# 京张交付界 / JING-ZHANG LAST 100

v0.3 把最后一百米作为人、货、服务人员与机器共同使用的城市公共接口，以安全、无障碍、人工否决、公开申诉和可撤回为底线。总体形成一条人优先服务主脊、六条东西支线、三条重点区内部环和十二个接口事件庭。

三处重点区采用不同空间原型：众智园是受控测试院，AI 原点社区是多入口共享院，大钟寺是分时站前界面。L100 接口事件号连接空间、责任、人工接管、停止条件和年度复盘；它不授予路权，不进行信用评分，也不替代许可。

全部空间使用临时边界，派生指标置信度为 medium。方案不是自动驾驶专网、朝圣活动路线或“一带三核”换名，不推导拆迁、容积率、道路红线、权属或工程可行性。现场体验、劳动、安全和环境成效在基线建立前保持 unknown。
