Governance Ledger · SWITCH Interlocking Protocol

All scenarios run under an executable state machine: green to run / yellow to slow (manual sampling) / red to pause (manual takeover, decommissionable); transitions require human sign-off, retirement is terminal; quarterly red-light withdrawal drills. Principles: service equivalence, vulnerable protection, red-card review right, data minimization, human final review. Machine-readable protocol: visual/assets/switch-protocol.json.

State machine: YELLOW →(pilot passed)→ GREEN →(anomaly)→ YELLOW →(red event)→ RED →(remediation sign-off)→ YELLOW →(evaluation)→ RETIRED; red never goes directly to green.
