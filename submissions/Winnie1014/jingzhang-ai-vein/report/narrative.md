# Formal Narrative

本投稿包为“京张智脉：百年铁路走廊的AI创新再生”——面向百年京张AI创新带城市设计国际方案征集的可评审双语概念方案。

- **总体概念**：以京张遗址公园为历史与公共空间主轴，以众智园AI自主创新加速区、北京AI原点社区、大钟寺AI产业聚集区为创新锚点，构建“一带三核、多点场景、蓝绿慢行复合环”的空间组织。
- **任务响应**：agent.1 命名与总体结构、agent.2 全球案例与八类机制、agent.3 十二张场景卡与六类画像、agent.4 公共空间与朝圣地标、agent.5 文化融合叙事、agent.6 运营与转化体系均在 `proposal.md` / `proposal.en.md` 成文。
- **事实边界**：三层范围与三处重点区均使用 provisional 粗略边界（`official_boundary=false`），面积与比例由提交几何在 EPSG:4548 下复算，官方红线/控规/道路/权属/建筑/文保/市政/公共设施九类缺口在 `assumptions.json` 逐项登记并说明重算触发条件。
- **证据链**：Geometry、metrics、compliance/standard/depth 矩阵、自检结果与图件/HTML 交叉一致；`self_check.json` 与 `manifest.json` 由工具重生成。

Geometry, metrics, compliance matrix, drawings, and visual/index.html remain cross-checked deliverables. Bilingual versions (`proposal.en.md`, `visual/index.en.html`, `drawings/*.en.pdf`, `assets/figures/*.en.png`) are equivalent translations of the same proposal.
