# Formal Narrative（方案概述）

本方案提出总体概念「**智脉共生带 ZHIMAI — The Symbiotic Pulse Belt**」：把1905年詹天佑自主修建京张铁路的「自主精神」与当代AI开源共创对齐——"From the first self-built railway to the first self-built intelligence."

**空间组织：一带三核、两翼协同、多点场景、蓝绿复合环。**
- 三核：众智核（众智园AI自主创新加速区）、原点核（北京AI原点社区）、商智核（大钟寺AI产业聚集区）。
- 两翼：科创翼（中关村科技服务翼）、体验翼（小月河场景赋能翼）。
- 蓝绿复合环：以京张遗址公园活力带为骨架，叠加清河创新廊、公共空间节点与慢行体系。

**主体成果：** 命名与视觉识别系统、6个全球创新生态对标案例、10张AI场景卡、3个产业测试验证场景、5类用户画像、3个AI朝圣地标（詹天佑坐标 / 开源成果贡献墙 / 智脉原点装置）、三层递进文化叙事、全球AI活动体系与长期运营机制。

**数据与合规：** 用地分区覆盖率为 1.0，绿地率约 31%，公共空间比例约 3.8%，均由几何在 EPSG:4548 复算。FAR 与建筑密度因缺官方控规列为 unknown。边界与三处重点区为 provisional，仅用于展示与自检，非官方红线；正式红线发布后需整体复算。所有空间建议均为开放共创建议，不构成政府审定结论。
