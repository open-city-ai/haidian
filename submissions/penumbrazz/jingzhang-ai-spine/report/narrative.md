# 方案摘要（narrative）

## 京张道口带：AI与城市百年平交实验场

京张铁路1905年开工、1909年建成，是中国人自行勘测、设计、施工和管理的第一条国有干线铁路。其城区段（西直门—清河）以"第一至第五道口"与城市平交——第五道口即今天北京人熟知的"宇宙中心"五道口。信号灯是城市最早的自动化决策系统；"道口"意味着规则、交汇与秩序。

**本方案提出：AI是新一代的"信号系统"，百年京张AI创新带就是AI与城市生活的平交道口——不回避、不隔离，而是规则化交汇。**

### 一带五口

- 北口·众智园：AI全栈×产业（编组场意象）
- 中口·AI原点社区：人才×创新（换乘站意象）
- 南口·大钟寺：智能体×消费（站城一体意象）
- 西口·中关村科技服务翼：资本×服务
- 东口·小月河场景赋能翼：场景×生活

每个道口 = 一套治理"信号规则" + 一个公共交汇空间 + 一组可感知AI场景。
