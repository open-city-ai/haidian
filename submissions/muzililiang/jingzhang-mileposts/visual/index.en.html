总览地图：里程标体系与空间结构

京张铁路沿线曾有真实的里程碑，丈量中国人自主创新的第一段里程。本方案把「里程」重新发明为「里程碑」：

  • 物理里程标——沿京张遗址公园主轴设置九个主题里程站（公共空间装置）；
  • 数字里程标——开源里程碑协议，项目/模型/测试达成节点即点亮，与 GitHub Milestone 同构；
  • 文化里程标——1909 京张铁路 → 中关村 → AI 新文化的百年时间线。

九站对应九公里：K0 西直门门户 → K1 大钟寺智能经济站 → K2 四道口缝合站 → K3 知春路场景站 → K4 五道口·零点里程碑（AI 原点社区）→ K5 清华东路开源站 → K6 六道口教育站 → K7 学知园全栈测试站（众智园）→ K8 北五环荣誉站。铁路里程自 K0 起量，创新里程自零点里程碑（0.0 km）起量——双零点叙事。
