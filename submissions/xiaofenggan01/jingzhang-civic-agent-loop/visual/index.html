四环协作

四环不是并列步骤，而是循环回路：资料环 → 推演环 → 反馈环 → 复核环 → 回资料环，首尾相接、彼此校验。

门要人开，环会自转。这是本方案区别于"顺序闸门"式治理的本质——环能回头校正自己，门不能。

四环各配可量化指标，见下方"治理环指标"。
