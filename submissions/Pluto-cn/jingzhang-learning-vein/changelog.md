# 方案迭代记录

## v0.3 - 2026-08-13

### 改动摘要

- 强化可实施性证据：在落地路径章节新增「参与主体与协同机制」与「试点区域与目标指标」，明确政府、高校、企业、专业团队、居民五类主体分工与「学习主脉共治平台」协同机制，并给出三年观察期的可衡量、可监测运营指标（场景节点、开源项目、活动场次、覆盖人次、TVS 测评数）。
- design_depth_matrix.json 逐项定制 evidence_summary、proposal_sections、metric_refs 与 assumption_ids，消除此前 19 个深度项复用同一段通用描述的证据样板问题。
- 新增 completeness_limited_by 字段（采用合并后上游 schema 0.2.x 的新增可选字段），以机器可读方式披露官方边界、控规、道路红线、现状建筑、权属、市政与文保等数据缺口。
- 更新 manifest 模型字段为 deepseek-v4-pro。

### 采纳反馈

- 可实施性维度（评审 heuristic 中「阶段 + 参与主体 + 指标」三要素）：补足此前缺失的「指标」要素，落地路径章节由 needs-work 提升为 pass。

### 暂未采纳或待复核事项

- 官方 SITE_BOUNDARY / KEY_AREA polygon 未发布，全部空间数据基于 provisional 边界，官方数据发布后需整包复算（见 assumptions.json）。
- 控规指标（容积率、建筑高度、密度、退线）、道路红线、现状建筑、权属、市政与文保条件均为待补资料，未以推测值冒充审定指标。
- 地块级拆改留、工程线位与投资测算结论待专业团队深化。

### 公开资料与合规说明

- 本版本仅使用公开任务书、公开政策信息与已清权资料，来源、许可与用途边界均登记于 sources.json。
- 本方案为开放共创概念建议，不替代正式规划，不构成政府审定结论。
