03 · Five Sub-Gates Mechanism

Each pass gate consists of five sub-gates. Any sub-gate failure freezes the service and returns it to the sandbox. Drawn from careline but flipped into spatial walk-tests.

core innovation
ComprehensibleCan a child/senior understand it?
ChoosableCan the user opt out?
SupervisedCan staff take over?
CorrectableCan errors be fixed on the spot?
ExitableCan the user one-tap exit & clear?
Failure action is the core: clearance becomes a spatial institution with consequences, not another governance promise. Each sub-gate failure has an explicit freeze / return-to-sandbox consequence.
