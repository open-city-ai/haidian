# The Pass Line / 京张放行线

> **One-line thesis**: Before any AI service may enter a street, it must first pass a live walk-test on site across four use scenarios — children, elderly, accessibility, and caregivers. **No clearance, no street.**

## One-Page Executive Summary

This proposal turns "clearing" (pass / clearance) into the spatial institution of the Jing-Zhang AI Innovation Belt. The Jing-Zhang Railway used a "switchback" (人字形) line to overcome the Nankou grade — the first time Chinese engineering turned "impassable" into "passable" as a physical answer. This proposal borrows that metaphor and turns the "passable / impassable" threshold for AI services entering public space into a walkable, testable, correctable, exitable on-site verification.

### Five Sub-Gate Mechanism (Core Innovation)

Each pass gate consists of five sub-gates, drawing from MichaelMi/careline's six care commitments but **flipped into spatial walk-tests** — not service-side declarations but on-site user verification [depth:ai_ecosystem_and_scenario_design]:

| Sub-gate | Question | Failure consequence |
|---|---|---|
| comprehensible | Can a 6-year-old / a 78-year-old understand what this service is doing? | Freeze |
| choosable | Can the user choose not to use it, or how much to use? | Freeze |
| supervised | Is a caregiver / staff member on site to take over? | Freeze |
| correctable | Can the user correct the service on the spot when it errs? | Freeze |
| exitable | Can the user one-tap exit and clear traces? | Freeze |
