# 著作权与生成说明

## 成果生成

方案名称、正文、数据结构、GeoJSON 设计层、五张核心图、离线 HTML、A3 文册和 A0 展板由 OpenAI Codex 在 2026-08-07 基于 `open-city-ai/haidian` 仓库公开或清权资料生成，并由同一脚本保持几何、指标和展示一致。贡献路径为 `submissions/kagura-yami/jingzhang-ai-commons/`。

## 外部内容与许可

- 未嵌入远程图片、商业地图底图、新闻截图、论文图像、人物肖像、企业商标或第三方插画。
- 五张 PNG 均由 Pillow 根据本提交 GeoJSON、metrics 和矩阵程序化绘制；PDF 由 ReportLab 生成。
- HTML 使用系统字体回退，不下载或打包外部字体。PNG 使用本机 Microsoft YaHei 渲染；PDF 使用本机等线字体的文档嵌入能力，字体文件本身不随投稿分发。
- 国际案例只引用机构官网文字入口，未复制其图片、品牌图形或页面设计。
- `proposal.md` 采用 `COMMUNITY-DISPLAY-ONLY` 提交通道；正式征集公告中的知识产权条款对主办方、承办方与应征人之间的使用另行适用。

## 边界与责任

全部空间结论均为概念建议。临时 polygon 不是官方红线、审批或精确面积依据；official polygon、控规和专业底数到位后应整体复算。AI 生成内容须由人类与专业团队最终判断，不构成法律、规划审批、工程、投资或运营承诺。
