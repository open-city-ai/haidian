# 叙事说明 / Formal Narrative

本叙事由结构化提交包派生，与 geometry、metrics、矩阵、图纸和 visual/index.html 交叉核对。

## 核心主张：第25小时·京张夜脊

青年负担得起的只有城市的空时——夜间、周末与换班间隙。本方案把大钟寺核心区与京张铁路脊建成一条「第25小时」公共脊：办公熄灯时夜脊亮起，AI 公共服务驿站 7×24 开放、人工按时刻表复核，**时刻表的缝隙 = 停办客运 = 有尊严的治理退出**（而非 AI 回退）。

## 结构

- 治理原语：时刻表协议（节点 × 时段 → 人工值守 / AI+复核 / 缝隙）
- 落点：大钟寺核心区（约 72 公顷，provisional 暂定边界）= 夜脊主段；南北两节点 = 卫星夜脊段
- 分期：Phase0 协议试点 → Phase1 大钟寺建成 → Phase2 卫星节点 + 成熟（maturity-first，以机制成熟度优先）
