# 方案摘要（narrative）

**百年一线·智启于人**：以京张铁路青龙桥“人字形”折返线为空间与精神原型，将百年京张AI创新带组织为“一线三站两翼多点”——南北京张绿轴（开发者散步道）与东西小月河蓝绿走廊交汇成“人”字骨架；众智站（全栈创新与AI治理）、原点站（从0到1的原点生态）、钟站（智能原生新业态）三站承载五大功能；中关村科技服务翼与小月河场景赋能翼提供要素与场景支撑；AI原点纪念碑、贡献者站台荣誉墙、开源灯塔三座朝圣地标锚固创新带的精神坐标。

总体设计范围约11.4平方公里内布置33个用地单元（完整覆盖、无缝无叠），科研用地约325公顷为主体，配套约215公顷住宅、约185公顷商业与约50公顷战略留白；绿地率约20.5%、公共空间率约12.8%、绿道约10.8公里。12张AI场景卡（含3张产业测试验证）、12项更新项目与三期概念分期支撑长期运营。

全部边界为仓库 provisional 临时 polygon（非官方红线），容积率/高度/密度等控规指标标记 unknown 待确认；本方案为概念建议与参考方案，供专业团队深化。
