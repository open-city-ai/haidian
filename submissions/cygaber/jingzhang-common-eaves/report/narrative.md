# 共檐京张 / JINGZHANG COMMON EAVES

“共檐”不是一座贯通九公里的巨型屋顶，而是一套把园区、校园、企业与社区门口改造为公共基础设施的最小协议：P0 公共前檐无需注册，P1 预约共享最小用数，P2 受控测试可以物理停机，P3 安全内核不被迫开放。空间结构为“共同前庭、三檐、六缝、十二间、两翼”。

三处重点区分别承担验、创、用：众智园验檐把高风险测试放进可控缓冲；AI 原点创檐把科研成果变成公众可理解、创业者可使用的服务；大钟寺用檐让模型在进入商业与社区前接受公开问询。六道横向缝合把纵向遗址公园从景观走廊转为组织之间的可达共同前庭，十二间服务房间对应十二张含风险、人工复核、隐私与回退规则的场景卡。

方案只使用仓库公开资料和注明用途的官方背景来源；未取得的 official polygon、控规、道路红线、权属、现状建筑、文保、市政与公共服务底数均明确登记为缺口。所有指标从 GeoJSON 在 EPSG:4548 下复算，适合作为开放讨论的专业证据包，不构成政府审定结论。
