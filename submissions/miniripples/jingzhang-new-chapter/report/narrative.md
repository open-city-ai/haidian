# 京张新章方案叙事摘要

“京张新章”以“轨痕·智脉”为总体概念，将京张铁路遗产、公共绿廊与面向未来的城市 AI 基础设施组织为一套可讨论、可复核、可迭代的城市更新方案。

本提交使用约 11.41 平方公里的临时总体设计边界作为空间复算基底，并将 24.5 公顷清华园核心示范区明确标注为参赛者提出的概念设计范围。核心区建筑规模 38.5 万平方米、容积率 1.57、绿地率 38% 和公共开放空间率 42% 均为设计目标，不是法定红线或已审批控制指标。

方案通过五张中英文核心图件、双语 A3 文册、双语 A0 展板、GeoJSON 图层、指标与合规矩阵，以及原生 Canvas 2D 离线交互页面共同表达。三处重点区域采用 provisional constraint，待正式边界、测绘、权属、市政和文保条件发布后重新复算。

AI 场景覆盖具身智能测试、开源协作、微气候调节、边缘算力、无人物流、AR 遗产漫游、自动化创客工坊、Urban Agent 仿真、智能照明和韧性防汛。所有涉及公共数据和城市运行的场景均坚持数据最小化、人工复核和授权使用，不替代规划审批或公共决策责任。
