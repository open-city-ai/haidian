# 方案迭代记录

## v2.0 - 2026-08-12

- 将第一阶段的概念与证据板，深化为“总体母图—街区肌理—重点区平面/剖面—公共首层—运营门槛”的城市形态表达。
- 明确众智园维护院、AI原点交接院、大钟寺交换院三类空间原型。
- 建立十二处同班驿的 S/M/L/XL 非指标性面积带、昼夜四班运营脚本与 G0—G4 可逆实施门槛。
- 增加责任主体类型、相对 CAPEX/OPEX、KPI、SLA 与停用条件；坚持不做个人评分、情绪识别和隐蔽追踪。
- 新增原创生成式概念封面与重点场景表现，均声明为概念合成而非现场或官方证据。

### 待后续核验

- 官方边界、控规、权属、建筑、消防、交通、市政、文保与真实班次需求仍缺失；所有面积带和点位均不得视为审批数据。
- 第三阶段须在真实数据与付费劳动者共创基础上，替换临时几何并完成专业专项校核。

## v3.0 - 2026-08-12

- 将众智园维护院从总体原型深化为 90 天可逆试点包：五个可移动空间组件、D01—90 分阶段节奏、四班启用模板和撤场机制。
- 明确试点只在 G1 现场核验后以非生产性维护演示、带薪学习、人工交接和申诉服务启用；不认定任何具体地块、建筑、投资或施工方案。
- 建立去标识当班记录、公开月度摘要、独立复核及个人评分/情绪识别/隐蔽追踪等停用红线。

### 第三阶段待核验

- 众智园的正式边界、可用建筑、权属、消防、用电、交通、无障碍和真实排班条件仍缺失；本试点包不构成实施授权，任何启用以专业核验和参与者付费共创为前提。

## v3.1 - 2026-08-12（本地深化包）

- 新增 G1 现场核验清单：七类核验域均要求可核验证据、责任角色与通过/暂停结论；任一缺项或失败即不安装、不开放。
- 新增付费共创工作坊包：以五类参与角色、五步共创脚本、书面确认的报酬/工时/数据规则和可交接输出组织 G0。
- 新增可打印当班记录模板：以服务、交接和修复为单位，不记录姓名、绩效、情绪、精确位置或生产性工单。
