# Copyright and Attribution Statement

## Base spatial data

Road, railway and park geometry in `geometry/` is derived from **OpenStreetMap**, retrieved through the
Overpass API on 2026-08-09 (`osm_base` 2026-05-31T22:37:44Z) for the bounding box
S 39.939 / W 116.3397 / N 40.0265 / E 116.3553, and reprojected to EPSG:4548 for all length and area
computation.

**© OpenStreetMap contributors. Data available under the Open Database License (ODbL) 1.0.**

Use of OpenStreetMap as a bootstrap base layer is explicitly permitted by the organizer in
`brief/site-package/allowed_design_space.json` (`data_policy.may_use_osm_for_bootstrap_base_layers = true`,
`osm_requires_odbl_attribution = true`). No commercial map tiles were used as submission data.
OSM results are not registered into the central `data/source_registry.json`; the query, bounding box and
`osm_base` timestamp are recorded in `sources.json` so the extract can be reproduced.

## Boundaries

`geometry/site_boundary.geojson` and `geometry/key_areas.geojson` reproduce the organizer-supplied
`provisional_boundaries.geojson` unchanged. They are provisional substitute boundaries, not official
redlines, and are not a precise-area basis.

## Generated content

All narrative text, design geometry (patrol depots, charge docks, stitch links, land-use assignment,
building massing, phasing), figures, drawings and HTML were generated by the declared AI agent
(see `agent.json`) for this submission. No third-party imagery, typeface, icon set or template was
embedded. Figures are rendered with matplotlib using Noto Sans CJK (SIL Open Font License 1.1);
the typeface is not redistributed in this package — text is rasterised into the PNG and PDF outputs.

## Offline guarantee

`visual/index.html` and `visual/index.en.html` embed every image as a base64 data URI and contain no
CDN reference, remote map tile, external font, script, `fetch`, `XMLHttpRequest`, `WebSocket`,
`EventSource`, `iframe` or form. They open correctly with no network connection.

## Cited public documents

Public documents cited in `proposal.md` (National Railway Administration, Ministry of Finance,
Beijing Municipal People's Congress Standing Committee) are referenced by title, article number, publisher
and URL in `sources.json`. Only statements explicitly present in those documents are quoted; no
interpretation is presented as an official conclusion.
