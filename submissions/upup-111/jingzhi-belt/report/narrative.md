# 方案摘要（Narrative）

京智带 JINGZHI-BELT 以"开放回路（Open Loop）"为总体概念，依托京张遗址公园活力带组织南北贯通创新轴与智联环，串联众智园AI自主创新加速区、北京AI原点社区、大钟寺AI产业聚集区三处重点区，并向中关村科技服务翼与小月河场景赋能翼开放。

本摘要由提交包结构化数据派生：geometry/*.geojson 为空间证据层，metrics.json 为指标复算层，compliance_matrix.json、standard_matrix.json、design_depth_matrix.json 为任务与深度证据层，drawings/*.pdf 与 visual/index.html 为展示层。所有空间建议均为概念建议，基于 provisional rough 边界生成，官方红线取得后须整体重算。
