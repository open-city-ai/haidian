# 方案迭代记录

## v0.4 - 2026-08-11

### 改动摘要

- 修复一致性漏洞：正线文化节点从绿地脊内切出 `0803 文化用地`（约 12.5 ha），正文与 `land_use.geojson`、`metrics.json` 完全一致；用地单元由 17 增至 24。
- 指标体系扩展：新增用地分类面积（1401/0802/0804/05/0701/0803）、`key_area_count`、`phasing_area_sqm` 等已知指标，以及 `road_area_sqm`、`total_floor_area_sqm`、`floor_area_ratio`、`building_density` 待正式数据补齐的 unknown 指标（共 28 项）。
- 前置"核心概念与差异化机制"章节：签名机制 PR 三循环（Public Review → Pilot Run → Merge）+ 从概念到实装的深化路径表。
- 补京张铁路历史基线表（1905—1909 詹天佑、人字形展线、京门支线、2016 清华园停运、2019 京张高铁、遗址公园）。
- 场景卡 12 张全部增加运营主体列与空间节点引用；三区两翼回路机制表与北京政策锚点；命名体系增加五支线双语代号（Compute/Origin/Market/Capital/Life Branch）。
- 来源登记扩展至 19 项（新增京张铁路历史、遗址公园、京张高铁公开背景资料）。

### 采纳反馈

- 基于两批共 10 条随机同行方案对比：补差异化机制命名、历史叙事、政策锚点、表格密度、运营主体列、可转化性路径。
- 基于"最终由 AI 打分、政府审定后实装"的评审背景：强化机器可验证证据、实装深化接口与一致性。

### 暂未采纳或待复核事项

- 官方 SITE_BOUNDARY / KEY_AREA 多边形未公布（Issue #846 披露临时范围与建成公园 0% 相交的空间不确定性）；全部几何为 provisional，官方资料到位后须全量重算并重新生成图纸、HTML 与指标。

### 公开资料与合规说明

- 本版本仅使用公开任务书、公开政策与清权资料，不包含个人隐私、未授权图纸或未授权商标字体；所有空间结论为概念建议，不构成政府审定结论。
