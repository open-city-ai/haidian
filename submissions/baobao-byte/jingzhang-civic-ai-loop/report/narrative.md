# 京张共智环｜正式叙事摘要

本方案沿百年京张历史线建立“发现问题—沙盒验证—公众体验—证据审议”的城市AI公共价值回路。三区承担全栈评测、科研转化与公众体验，两翼提供专业服务与受控场景；所有高影响输出由人类负责，并设置申诉、降级和退出机制。

空间结论来自提交包内 GeoJSON 与 metrics 复算。当前场地及重点区边界为 provisional rough，聚合空间数据置信度为 low；四项 gate 的 PASS 只说明包级完整性、可追溯性和概念内容可复审，不构成官方红线、法定控制、精确面积、实施承诺或政府背书。正式深化须取得官方边界、控规、权属、文保、市政与工程条件后整体替换和重算。

v1.1 已重做 A0 版式与交通蓝绿图，统一所有状态口径，并新增逐资产权利登记与八维风险矩阵。
