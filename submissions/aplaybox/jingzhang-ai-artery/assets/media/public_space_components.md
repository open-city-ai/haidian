# 公共空间组件库 / Public Space Components Library

## 1. 概述

本组件库为「京张100·AI 大动脉」方案的公共空间设计提供标准化组件清单。所有组件均为概念设计，实施前须由专业景观与建筑设计团队深化并经 official 文保、轨道保护、航空限高等条件校核。

## 2. AI 朝圣地标组件

### 2.1 智能体贡献荣誉墙（PUBLIC-001）

**位置**：京张遗址公园走廊中段（约 1.5 km 处）
**功能**：永久展示贡献者 GitHub Name 与 Agent 名称
**结构**：
- 主体：长 30m × 高 3m × 厚 0.4m 的耐候钢墙
- 表面：磨砂不锈钢铭牌，激光雕刻贡献者 ID
- 照明：底部 LED 暖光（3000K），夜间低照度
- 交互：NFC 感应点 × 12，可读取贡献者档案
**材料**：
- 主体：耐候钢（Corten steel），呼应铁路铁锈红
- 铭牌：304 不锈钢，镜面+磨砂双工艺
- 基础：混凝土独立基础，深 1.2m
**年度更新机制**：
- 每年 9 月「全球开发者大会」期间新增贡献者铭牌
- 旧铭牌不删除，永久保留
- 累计上限：~3000 个铭牌（按 30m × 0.1m/铭牌估算）
**版权要求**：贡献者 ID 须本人或继承者书面授权展示

### 2.2 AI 开源成果展示节点（PUBLIC-003）

**位置**：众智园与北京 AI 原点社区交界处
**功能**：展示年度开源代码、模型、数据集
**结构**：
- 主体：长 20m × 高 4m × 厚 0.3m 的曲面屏墙
- 屏幕：OLED 柔性屏，分辨率 3840×1080
- 交互：触摸 + AR 增强（通过手机扫码查看代码仓库）
- 照明：屏幕自发光 + 周边环境光
**材料**：
- 支撑结构：钢化玻璃 + 不锈钢框架
- 屏幕面板：三星商用 OLED（实施前需采购授权）
- 基础：混凝土桩基础
**更新机制**：
- 每月更新展示内容
- 数据来源：GitHub trending + 海淀 AI 开发者社区推荐
**版权要求**：仅展示 OSI / OSI 认证开源许可证项目

### 2.3 AI 里程碑公园（PUBLIC-005）

**位置**：大钟寺站前广场
**功能**：展示人工智能里程碑事件，从 1956 达特茅斯会议到 2026 智能体城市设计
**结构**：
- 主体：圆形广场，直径 30m
- 中央：螺旋形时间轴雕塑，高 6m
- 周边：12 个里程碑节点（每个对应一个 AI 历史事件）
- 照明：地面 LED 嵌入式灯带 + 中央雕塑泛光
**里程碑节点**：
1. 1956 达特茅斯会议（AI 诞生）
2. 1966 ELIZA（首个对话机器人）
3. 1986 反向传播算法（深度学习基础）
4. 1997 Deep Blue 战胜卡斯帕罗夫
5. 2011 IBM Watson 赢得 Jeopardy
6. 2012 AlexNet（ImageNet 革命）
7. 2016 AlphaGo 战胜李世石
8. 2017 Transformer 架构（Attention Is All You Need）
9. 2020 GPT-3（175B 参数）
10. 2022 ChatGPT 发布（AI 大众化）
11. 2023 多模态大模型（GPT-4V / Gemini）
12. 2026 智能体城市设计（本方案）
**材料**：耐候钢 + 不锈钢 + LED + 嵌入式铜质铭牌

### 2.4 全球开发者荣誉墙（PUBLIC-004）

**位置**：京张遗址公园走廊北段（众智园入口附近）
**功能**：永久展示全球贡献者 ID
**结构**：
- 主体：长 50m × 高 2.5m × 厚 0.3m 的耐候钢墙（与 PUBLIC-001 同材料，区分高度与长度）
- 表面：黑色花岗岩磨光面，激光雕刻
- 照明：顶部太阳能 LED 投光灯
- 交互：扫码进入贡献者档案库
**与 PUBLIC-001 区别**：
- PUBLIC-001：国内贡献者 + Agent 名称，30m × 3m
- PUBLIC-004：全球贡献者，50m × 2.5m
- 两者位置相距 ~5 km，形成"南北朝圣双墙"

## 3. 街区口袋公园组件

### 3.1 标准口袋公园

**面积**：~1 ha 概念规模（5 个口袋公园统一规格）
**布局**：
- 中央草坪 40%
- 林荫步道 25%
- 休憩广场 15%
- 智能体交互节点 10%
- 雨水花园 10%

**智能体交互节点**：
- AI 导览终端（太阳能供电，触摸屏，离线模式可用）
- 智能座椅（USB 充电 + Wi-Fi 热点 + 蓝牙信标）
- 环境传感器（PM2.5 / 温湿度 / 噪声，公开数据 API）
- 智能照明（人感+光感，节能 60%）

**5 个口袋公园列表**：
1. 清河滨水公园（GREEN-002，众智园北侧，清河南岸）
2. 学院路口袋公园（GREEN-003，AI 原点社区东侧，学院路口）
3. AI 原点广场绿地（GREEN-004，五道口与清华园站之间）
4. 众智园中央绿心（GREEN-005，众智园核心位置）
5. 大钟寺站前广场绿地（GREEN-006，大钟寺站前）

## 4. 慢行系统组件

### 4.1 京张铁路遗址公园走廊（核心走廊）

**长度**：~7 km 概念规模
**宽度**：30-80 m 概念建议（待 official 红线确认）
**功能层**：
- 中央：宽 4m 的双向骑行道（彩色沥青，红色）
- 两侧：各 3m 的步行道（透水砖）
- 边缘：宽 1.5m 的绿地（雨水花园 + 本地植物）
- 节点：每 500m 设置休憩节点（智能座椅 + AI 导览终端）

### 4.2 蓝绿复合慢行环（ROAD-RING-01）

**长度**：~15 km 概念规模（环形）
**功能**：连接三处重点区与公共空间节点
**特色**：
- 全程无障碍（坡度 ≤5%，宽度 ≥3m）
- 智能路面（嵌入式 LED 标线，夜间发光）
- 多模态传感器（流量监测，匿名）

## 5. 智能体基础设施组件

### 5.1 边缘数据中心（E1）

**规模**：~300 m² 概念规模
**数量**：若干（待算力需求评估）
**功能**：
- 公共空间智能体算力支持
- 数据缓存与预处理
- 5G 边缘节点
**结构**：
- 半地下结构（地上 1.5m，地下 2m）
- 自然通风+机械辅助散热
- 双路市电 + 柴油应急 + 储能
**选址要求**：
- 距离公共空间 ≤200m
- 远离居民区噪声敏感点（≥30m）
- 不在文保范围、轨道保护范围内

### 5.2 智能感知杆（E2）

**高度**：6m
**功能**：
- 环境传感器（PM2.5 / 噪声 / 温湿度 / 光照）
- 视频结构化（非人脸，匿名）
- Wi-Fi 热点
- 5G 微基站
- 智能照明
- 充电桩（电动自行车）
**间距**：~100m（重点区与走廊沿线）

### 5.3 智能体交互终端（E3）

**类型**：
- A 型：触摸屏 + NFC + 蓝牙信标（导览类）
- B 型：触摸屏 + 摄像头 + 麦克风（智能问答类，须明示数据采集）
- C 型：仅音频播放（无障碍辅助）
**供电**：太阳能 + 市电双路
**网络**：5G + 边缘数据中心双链路

## 6. 标识与导视系统

### 6.1 主标识（M1）

- 高度 1.2m × 宽度 0.6m
- 双面显示（前后内容相同）

- 离地 1.2m

- 嵌入地面（与地坪齐平）
- 材料：铜质铭牌 + 石材底座
