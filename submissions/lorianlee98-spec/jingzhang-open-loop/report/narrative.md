# 京张·共证线｜派生摘要

“京张·共证线 / Jing-Zhang Proofline”把百年铁路公共空间组织为研究、受限验证、日常公共价值与透明复盘的接力线。北部众智园承担 Trust & Test Garden，中部 AI 原点社区承担 Translation Commons，南部大钟寺承担 Civic Interface Exchange；中关村科技服务翼与小月河场景赋能翼形成资源和日常生活的双向接力。

每个候选 AI 场景必须具备最小数据、非数字替代、具名人工责任、投诉/退出和停用规则。当前边界与重点区 polygon 均为 provisional；所有面积、控规、交通、市政、文保、权属与工程结论须在正式资料到位后由专业团队复核。`proposal.md` 是唯一主体文本，本文件仅为派生摘要。
