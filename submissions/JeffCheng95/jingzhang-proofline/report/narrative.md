# 京张共证线摘要

“京张共证线 / Jing-Zhang Proofline”把京张遗址公园构想为 AI 从实验室进入真实城市之前的公共验证界面。众智园承担测试与安全治理，AI 原点社区承担开源复现与成果转化，大钟寺承担城市展示与国际交流；十二个场景必须通过目的公开、数据最小、公众可退出、结果可解释、人工可复核、故障可回退六项门槛。

方案以 provisional geometry 完成结构化 intake，不声称官方红线、控规、工程线位或实施承诺。正式边界到位后，所有设计图层、指标、图解、HTML 与 PDF 统一重算。权威证据顺序仍为 GeoJSON、metrics、矩阵、manifest 与 self-check，`proposal.md` 是唯一主体方案文本。
