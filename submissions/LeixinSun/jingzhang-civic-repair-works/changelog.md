# 方案迭代记录

## v1.2 - 2026-08-14

- 按官方任务书重新锚定三处重点区和两翼：众智园承担全栈整机回归与安全治理，AI 原点承担互换件、校准、开源方法与人才训练，大钟寺承担城市型售后、无障碍复测、人工放行与采购反馈；中关村科技服务翼和小月河场景赋能翼保持横向能力接口。
- 将北纬社区、未来科学城、怀柔科学城、北京经开区和京津冀协同改写为“待核实能力接口”，逐项说明输入、输出和年度核验问题，不声称已经建立合作、数据池或机构承诺。
- 把首读主张收敛为“公共服务走正线，故障设备进侧线”，并将三处重点区重绘为城市服务、精密共享和受控测试三种不可互换的工场。
- 新增“一台设备、三地接力、一次失败、一次人工决定”的双语六帧回放；失败在众智园触发 `HOLD_R4`，保留记录后进入纠正复测，最后由责任人与独立复核限定放行或退回。
- 明确 AI 白名单、AI 禁区、人工专属权限和越权强制拒绝；新增 4 个 AI 越权合成分支，与原有 8 个 R0—R5 分支共同达到 12/12 预期决定匹配。
- 重排双语 visual、A3 第 7—8 页和 A0 第 4 板，使城市空间、设备失败、用户兜底与责任边界在首分钟可复述；交互页可走 HOLD、RETEST、HUMAN RELEASE 和 RETURN 两类结果路径。
- 保留“共修、保修、售后、修补城市”为受限的公众叙事：共修限于低风险教学，保修和售后落实到责任与工单，修补城市指逐台恢复公共服务；主叙事仍是互换件、再制造、校准、复认证和合规交接构成的复役工业底座。
- 同步更新中英文正文、指标、风险、案头夹具、摘要和机器证据；现场运行、机构签认、正式边界、专业委托与绩效基线均保持未发生或待补。

## v1.1 - 2026-08-14

- 针对首次 Review Agent 72/100 的可实施性、公共体验与首读导航短板，把主线收敛为原创“复役放行协议”，不复制高分同行的概念、措辞、编号或资产。
- 新增 R0—R5 六道复役门：受理资格、权属/保修/数据权限、风险隔离/诊断基线、维修授权/部件证据、校准/回归复测、人工放行/去向；每门均登记硬阻断、暂停角色和恢复证据。
- 将 12 张场景卡升级为责任合同，逐项绑定空间、最小数据、人工最终决定、通过证据、立即暂停条件和普通服务兜底。
- 新增“一台公共服务机器人跨三地复役”首读链、非数字/无障碍用户连续服务旅程、三重点区专业交接包和 90 天单设备族可退出试点。
- 新增资产护照与复役回执最小合同、互换件证据目录、KPI 取数计划、受管制物料交接模板、风险表和资产权利台账。
- 新增 8 个完全合成的负分支案头回放；规则结果 8/8 与预期一致，现场运行固定为 0，不代表设备性能、安全认证、机构授权或公众接受。
- 重排双语正文、五张必交图、visual 首屏以及 A3/A0 前三页，使“凭什么放行、何时拒绝、谁能恢复”在评审首分钟可见。
