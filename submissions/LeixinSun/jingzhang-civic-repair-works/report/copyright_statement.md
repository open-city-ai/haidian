# 版权、生成方法与复用边界

本投稿由 GitHub 用户 LeixinSun 通过 Codex 组织公开资料、编写文本、生成结构化数据与确定性图件。投稿许可采用 `COMMUNITY-DISPLAY-ONLY`，适用范围以本项目仓库和征集规则为准。

六张中文图、六张英文图、离线网页和 A3/A0 图纸均由本投稿的 GeoJSON、`metrics.json`、R0—R5 复役门、AI—人工权限矩阵、责任矩阵和案头回放结果确定性生成；PNG 使用 Matplotlib 绘制，PDF 使用 ReportLab 排版。新增六帧回放图是合成案头叙事，不是现场观察、设备测试或公众反馈。全部图件未使用商业地图瓦片、遥感截图、新闻图片、第三方人物肖像、企业商标或外部字体文件；本机 Arial Unicode 字体仅在生成 PDF/PNG 时用于字形呈现，不随包分发。图面中的边界、重点区、建筑模块、道路和公共空间均按正文标注为临时约束或概念建议。

外部案例仅作研究参照。法国指数、CTI、企业流程和国际组织统计均以独立文字和自建图形转述，不复制官方标识、图表或受保护版式。Caterpillar 页面在自动访问环境中受限，相关表述仅保守概括公开的再制造工序。WBCSD CTI v4 的 CC BY-ND 4.0 条款被记录为“可释义、不得改编原图”。

新增结构化工件包括复役门、服务责任矩阵、场景验收矩阵、资产护照与复役回执合同、互换件证据目录、90 天试点就绪表、KPI 取数计划、重点区交接包、受管制物料交接模板、资产权利台账、风险表和合成规则回放。它们均由投稿者编制或由本地脚本确定性产生，不包含现场设备数据、真实机构签认或第三方保密信息。
