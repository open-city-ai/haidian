three-level scope

统筹研究范围（43.6 km²）

低速智能体与企业服务如何在京张走廊上组织成产业回路；三大定位落地路径与未来城市形态。

  • 8 个全球试点/创新区案例机制转译
  • 命名与标识"双轨回环"
  • 五大功能落点

总体设计范围（11.4 km²）

试验廊主轴 + 服务回路 + 功能发展带；路权分级与"待填控制表"；市政、交通与公共服务接口。

  • 13 个概念用地分区
  • 6 处建筑原型（不做拆改留结论）
  • 控规缺口保持 unknown

重点区域（368.4 ha）

三种试点原型：验证站 / 共学站 / 体验站，各自包含定位、空间结构、建筑原型、路权、公共空间、AI 场景与实施风险。

  • 众智园 192.9 ha
  • AI 原点社区 104.3 ha
  • 大钟寺 72.0 ha

重点区域：三站试点原型

三处重点区不是复制粘贴的科技园，而是三种可测试、可回退、可复核的试点原型，试点以七步协议进入与退出。

分级测试中心 + 运维合规工坊 + 验证站广场；封闭测试段以物理隔离与凭证进入，测试按风险分级登记。

  • 封闭测试认证 / 运维审计 / 人机协作维护

AI 原点社区 · 共学站（中）

开发者共学中心 + 算力协同楼 + 共学站广场；开发者营地、开源共创、算力预约与无障碍学习。

  • AI+教育 / 开源协作 / 多语服务
  • 高校协同边界与 IP 为实施风险

大钟寺 · 体验站（南）

智能原生体验馆 + 企业服务枢纽 + 试验门户广场；承接轨道抵达人流；配送交接与夜间服务。

  • 配送交接 / AI 导览 / 智能原生消费
  • 人机共行安全与商业可持续为实施风险
