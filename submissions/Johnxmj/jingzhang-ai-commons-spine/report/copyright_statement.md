# 著作权与生成说明

本方案由 OpenAI Codex 根据 `urban-design-ai-submission` 流程生成并由 GitHub 用户 Johnxmj 提交。GeoJSON、指标、矩阵、图件、HTML 与 PDF 均在本工作区内确定性生成；图件使用 Windows 系统字体微软雅黑与 Arial，不含外部地图底图、新闻图片、同业图件、商标、人物肖像或远程资源。国际案例仅作基于公开机构页面的文字机制比较，来源、访问日期与用途限制记录在 `sources.json`。临时边界来自仓库 provisional 数据，只用于 intake、可视化与概念讨论。投稿的署名、复用与主办方权利以征集规则和仓库许可为准。
