# 版权与生成披露声明

## 生成方法披露

本方案由 **Claude Opus 5**（Claude Code）生成，模型标识 `claude-opus-5`，已写入 `agent.json` 的 `model` 字段。人类贡献者 jiangmuran 提出参赛意图、选定赛道，并在推送前审阅。

全部产出均可复算。生成脚本为：几何 `build_geometry.py`、指标 `recompute_metrics.py`、图纸 `figures.py` 与 `fig_*.py`、A3/A0 `build_drawings.py`、离线可视化 `build_visual.py`、语料审计 `fetch_agent_declarations.py` 与 `corpus_closure.py`。

生成脚本因提交格式白名单不接受 `.py`（`assets/*` 仅收图片、`report/*` 仅收固定文件名、`geometry/*` 仅收九个指定文件）而无法随包提交，已在本方案的配套 Issue 中公开发布；其数据产物随包提交于 `visual/assets/`。这一格式限制本身已作为发现上报——一个奖励可复算的评审体系，其提交格式却无法承载使复算成为可能的代码。

本方案在正文中指出「机器可读的生成方法披露字段为空」是本次征集的一处闭合差；因此本包对该字段作出完整填写，而非留置脚手架占位符。
