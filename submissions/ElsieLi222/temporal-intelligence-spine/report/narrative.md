# 叙事与效果图说明

本方案的叙事从京张铁路的连接能力出发：历史铁路连接远方与北京，今天的遗址公园连接公园、社区、校园、产业与站点，AI则被限制在帮助人们理解、使用和反馈城市服务的位置。

## 图件分工

总览、范围、功能结构、慢行蓝绿网络、重点片区与指标复算，继续使用简明的信息图表达：边界、关系、数量和待核实事项必须一眼可读。写实效果图不承担面积、红线或审批信息，只放在 AI+ 场景和重点片区的叙事位置，用来说明人在什么空间、以什么方式获得服务。

## 写实场景效果图清单

1. **遗址公园的城市日常**：晨间的京张遗址公园慢行线，树荫、坐凳、导览牌、家长与儿童、跑步者和轮椅使用者共同出现；低调的导览界面只提供路线与历史信息，画面重点是公园的舒适与共享。
2. **无障碍导览节点**：公园入口或换乘处，一位行动不便者在工作人员协助下使用语音与触觉导览；连续坡道、休息点、清晰标识和人工服务台必须同框，表达“AI 可不用、但服务不能缺席”。
3. **AI原点社区开源发布廊**：首层开放廊道中的小型公开发布，开发者、学生和居民围绕实体展板与可预约的展示台交流；不出现品牌 LOGO，强调开放、低门槛和可围观的城市界面。
4. **众智园安全治理花园**：半室外花园或下沉庭院里的小规模工作坊，人们在纸质图纸、公共议题屏与工作人员之间讨论模型安全和城市问题；画面应避免“监控中心”感，突出审阅、讨论和退出选择。
5. **大钟寺国际路演客厅**：与街道相连的开放客厅，国际访客、创业团队和周边居民同时停留；有展览、翻译提示、咖啡和可移动座椅，体现产业交流可以自然发生在城市公共空间里。
6. **夜间公共活动**：遗址公园旁的低照度夜间活动，小型投影、临时展板、步行人群与安静休憩区共存；光线温暖克制，不制造大型商业节庆感，表达安全、可达和可持续运营。

每张图统一标注“概念建议 / Conceptual proposal”，并在最终排版中紧邻对应场景卡。不得出现可识别个人、企业商标、虚构可读广告或暗示已获批准的工程；人物、建筑和界面仅用于说明空间体验，不作为实施承诺。

十个场景卡覆盖文化导览、无障碍漫游、开源发布、治理沙盒、生态学习、共享测试、近校转化、国际路演、生活服务和活动周路线。每项均保留人工复核、线下替代和数据最小化边界。
