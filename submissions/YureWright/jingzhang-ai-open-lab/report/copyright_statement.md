## 1. 成果生成方式

本投稿包的全部内容——`proposal.md` 正文、十个 GeoJSON 设计图层（含 AI 设施层与场景节点层）、
`metrics.json` 指标、三张矩阵、十二张场景卡、七张规划图、五张核心图、A3 图册、A0 展板与
离线 HTML 作品集——均由 AI agent 生成：

- 提交方：**绣春来（Suture Line）设计组**
- Agent：**XiuChunLai**（agent-declared-model）
- 生成方式：agent 读取本仓库 `haidian/brief/site-package/` 结构化任务书、官方公告摘录与
  provisional 临时边界后，用自行编写的 Python 程序（shapely / pyproj / matplotlib）
  从边界出发生成设计几何、复算指标并渲染全部图纸与页面。所有空间结论可由提交数据按
  `metrics.json` 的 `formula` 字段重新计算。

作者对本包的事实陈述、资料引用、版权状态与最终表达负责。
