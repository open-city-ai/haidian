总体概念与空间结构

总体概念「京张红榜」JINGZHANG RED LIST (JZ-RL) 与空间骨架「一脊双廊三核三站」，及基于真实提交几何生成的证据总览图。

site_boundary + key_areas + roads

红榜三验与三层定位

机制：「红榜班次」= 公开测试（公测）+ 公榜公示（公开评价、排行与红黑榜信号语言）+ 公众评议与可回滚（公议）。三验信号灯（绿=通过 / 黄=复测 / 红=回滚）构成品牌视觉母题与评价语言。

三层定位：百年京张文化带 → 文化红榜（历史记忆与遗产价值公榜）；都市AI生活体验带 → 生活红榜（AI公共服务质量公榜）；AI融合创新带 → 产业红榜（模型、智能体、终端公开测评）。

一脊双廊三核三站

  • 一脊：京张遗址公园 9 公里绿色脊梁——慢行、历史、公共生活主轴。
  • 双廊：东廊 = 学院路—知春路「模型·人才」创新廊（科研教育为主）；西廊 = 大钟寺东路—荷清路「应用·生活」体验廊（商业生活为主）。
  • 三核：众智园·模型红榜核（AI全栈自主创新+安全治理+标准制定）；北京AI原点社区·开源红榜核（开源生态+成果转化+人才特区）；大钟寺·应用红榜核（智能体/智能终端/内容消费+数据要素+国际交往）。
  • 三站：清华东路西口站、五道口站、大钟寺站——轨道一体化红榜节点（站点位置为粗略定位，待核）。

五大功能与协同概念

AI全栈自主创新体系（众智园）；世界级AI创新生态（原点社区）；AI+场景赋能新范式（大钟寺+10张场景卡）；智能化AI活力城市（蓝绿慢行复合环+AI公共服务）；AI治理全球话语权（红榜评价机制+国际公议+年度红榜大会）。三区两翼以概念协同方式写入：两翼 = 中关村科技服务翼（要素全球化配置）+ 小月河场景赋能翼（场景开放），不落为法定边界。

征集周期（100天）≠ 实施分期。分期仅为本方案设计推进设想：一期 2026–2028 三核与红榜公共节点；二期 2028–2031 双廊更新与脊梁断点缝合；三期 2031–2035 全域网络与常态化运营。所有空间与运营构想均为概念建议 / 参考方案，不构成法定规划或实施承诺。
