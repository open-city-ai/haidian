京张令牌 · 百年京张AI创新带

一百年前，京张铁路被修出来是为了运东西。本方案主张：今天同一条线，应该用来跑东西。

多数AI片区方案把人工智能当作租户——划一块科研用地、加一个展示馆、挂一块AI园区的牌子。京张令牌把这条带本身当作产品：把9.6公里的遗址公园廊道整体做成一条持续运营、公众可预约的城市AI测试轨道——一条线、一套运行协议、一张预约表——沿线设三个"站"作为向城市开放的界面，设两个"道岔"接入更大的中关村肌理。

铁路语汇不是装饰，它同时是命名体系、运营模型和治理词汇：线有运营方和时刻表；站是公众上车的地方；道岔是另一张网接进来的地方；区间是被持续养护而不是一次建成的。这恰好是AI场景片区最需要、也最缺的纪律。

为什么叫「京张令牌 TOKEN BLOCK」。 这个词同时有三层意思，而这三层最后是同一层意思。

令牌（token）是AI模型消耗的单位——机器读写的最小颗粒。令牌也是十九世纪单线铁路真实使用的行车凭证：司机必须持有该区间的令牌才能进入，两端的闭塞机彼此电气锁闭，在令牌归还之前取不出第二枚，因此两列车不可能同时占用一个区间。这就是路签／路牌／令牌闭塞制度，也正是中国早期单线干线所属的技术门类——京张铁路正处在这个年代、这种行车条件之下。Block 补上第三层：闭塞恰好是这套独占纪律的铁路术语，而 block 同时又是城市的街区。

现在再看本方案真正提出的治理协议：你只有持有某段公共空间的预约时才能占用它，且在空间归还之前，下一个预约不会被发出。

这不是对令牌闭塞制度的比喻。它就是令牌闭塞制度本身，只不过被用在城市场景治理上而不是用在列车上。一件一百年前的行车安全器具，恰好就是今天一座城市向AI开放公共空间、同时又不失去控制所需要的那个机制——一枚令牌，一个区间，归还之后才发下一枚。

这正是本带不属于"给传统方案贴AI标签"的原因：它的名字、它的历史、它的标志和它的治理规则，是同一个东西。

以下所有空间建议均为概念建议、参考方案或可供专业团队深化研究，不构成法定规划、政府审定结论、实施承诺、投资安排或地块级拆改留结论。

统筹研究范围产业与未来城市研究

三大定位与五大功能，落在一条线上。 百年京张文化带就是主线本身；都市AI生活体验带是三个站上发生的事；AI融合创新带是两处道岔放进来的东西。五大功能不平均分布，而是各自锚在地理已经支撑的地方：AI全栈自主创新体系与AI治理全球话语权锚在编组场（S6），世界级AI创新生态锚在零公里站（S4），AI+场景赋能新范式沿全线展开并集中于下行道岔（S2），智能化AI活力城市锚在到发场（S1）与上行道岔（S5）。

三区两翼，合成一个回路。 协同被设计成一个闭合电路，而不是一张相邻关系图：研发能力从零公里站的近校界面策源，在编组场被固化为标准、评测与全栈自主，沿全线在测试轨道协议下公开验证，在到发场转化为产品与国际曝光，再由两翼反馈回来——中关村科技服务翼（S5）供给资本、知识产权、法务与要素全球化配置，小月河场景赋能翼（S2）供给真实的日常需求与真实用户。有反馈路径的回路，才是创新区与创新"系统"的区别。

八个全球参照，读机制而非读图像。 肯德尔广场说明校园边界被允许成为商业转化带而非缓冲带会发生什么；Station F 说明单一运营主体的集中度如何形成清晰的门户；伦敦国王十字知识片区说明历史基础设施可以承载研究机构而不沦为博物馆；首尔良才AI Hub 说明公共主导的单一目标AI地址；张江人工智能岛说明紧凑滨水集群如何把自身产业做成常设展；深圳湾说明服务设施密度才是真正的吸引力；涩谷 QWS 说明站城一体的开放会员制创新客厅；特拉维夫说明学术到创业的通道之所以有效是因为距离短。以上均为公开国际实践中的定性设计参照；本包不对其中任何一个作出定量陈述，不将其作为权威数据引用，也不用其论证任何数值目标。八者可转化的机制是同一条：缩短知识生产地与知识使用地之间的距离，并让这个距离被公众看见。

命名与识别：标志即平面。 本带命名为 京张令牌｜Token Block，其识别系统只有一个母题——一条被三处断口打断的实线。这个母题不是为了盖在方案之上而画的图形，它就是方案本身被压缩成一条线：三处断口是三个重点区域沿线的真实相对位置，线上方的两枚菱形是两翼。因此构成规则里有一条任何视觉改版都不得放松的硬约束——改变断口的数量或位置，改的不是 Logo，是方案。 命名体系把同一套铁路语汇延伸进导视：主脊上的里程标、站点处的站台边、两翼的道岔标，以及公示本线产出（发布、测试、结果）的到达板。导视被明确规定为实体、高对比、多模态，而不是一个App。本识别系统为供专业团队深化的方向建议，不是注册商标；未使用任何第三方字体、图像或标识 来源 标准 空间数据。

总体设计范围城市更新与控规深度城市设计

总体设计范围按一脊六段组织。脊是遗址公园廊道，做成一条连续的设计线位：在三个站处放宽、在区间处收窄——这个曲率与节奏读自运行逻辑，而不是作为造型施加。每段脊两侧各有一个西翼、一个东翼单元，取与该断面角色相符的用地代码，形成 18 个单元的分区，完整覆盖提交边界、无缝隙、无重叠 空间数据 指标 深度。

更新框架识别出沿线三类低效状态：东西向被廊道割断的移动、背对廊道的单一功能产业物流界面、以及首层不参与公共生活的站区。三个对策分别是：六条东西缝合线 指标、把两翼界面转向脊、以及三处站台广场 空间数据。

关于开发强度，本包在数据终止处停止。容积率、建筑高度与建筑密度记为 unknown 并写明原因，因为公开资料包中这些官方管控条件本身状态即为 missing 深度。本包能给的是一套在任何未来管控条件下都成立的相对体量意图：脊缘最低以保持廊道的天空与视线开敞，向外逐级抬升，最高体量退离历史线位，且不得沿线形成连续墙面 深度 标准。总建筑规模同样留空，而不是用假定容积率倒算 空间数据。

重点区域详细设计

三处重点区被刻意赋予不同的职能，而不是同一个创新园区的三个变体。它们的差异化本身就是设计。

S6 编组场 — 众智园AI自主创新加速区（指标）。 编组场是列车在开行前被编组与检查的地方。这里是全栈自主能力被组装、评测与认证的地方。更新抓手包括全栈研发组团、安全治理与评测实验室、标准与治理服务楼，保留一处现状产业建筑，并以自主创新展示馆把过程向公众打开 空间数据。其北端承担防护绿带，缓冲快速路与河道界面 指标。它的公共面——站台广场——让评测与标准工作可见而非隐蔽，这正是全球治理话语权真正需要的条件。

S4 零公里站 — 北京AI原点社区（指标）。 每张铁路网都有零公里标。这里是本带的原点，也是最公共的地址。西翼是近校界面的研发与转化，刻意做浅，让实验室到街道的距离足够短；东翼是社区服务与人才居住，让做事的人能住在回路里 指标。更新抓手为近校孵化器、开源协作实验室、人才公寓组团与原点社区服务中心。

S1 到发场 — 大钟寺AI产业集聚区（指标）。 到发场是货物抵达市场的地方。这里是本带的商业与国际交往端，与大钟寺站一体化，并围绕路口四象限步行连通组织 空间数据。更新抓手为智能原生消费街区、国际路演客厅、保留的智能终端企业总部组团与数据要素会客厅。

交通、轨道、市政与公共服务设施

交通策略建立在一个观察上：这条廊道的根本问题是南北连续、东西断裂。 设计接受并放大前者，修复后者。

南北向，主线慢行道贯通全脊，作为连续步行与骑行路径，同时是测试轨道的物理载体 空间数据。两侧支路环把机动车集散与地块出入从脊上移开。东西向，六条缝合线在站与道岔处横跨廊道 指标，三条站点接驳线承担轨道一体化 指标。路网总长 指标，其中慢行 指标 深度。

两条诚实约束：其一，道路面积与道路面积率为 unknown，因为红线宽度与断面未公开——没有它们，中心线长度无法换算为面积。其二，每条缝合线以何种方式跨越廊道（平交、上跨还是下穿）是本包明确不作答的工程问题；缝合线只被定位与论证，不被工程化 空间数据。

市政与新基建策略遵循同一套轨道逻辑：端侧算力、分布式能源与服务平台作为站场设备附着于三站两岔，而不是铺成均质网格——容量加在被使用的地方，也加在能被公开问责的地方。管线容量、排水、防洪、消防与能源负荷是深化前置条件，不是本包的结论 深度。

蓝绿空间、公共空间与城市风貌

脊同时是遗址公园、生态基底和测试轨道——一个空间、三重职能，这是本方案核心的空间经济性。绿地合计 指标，占提交边界 指标；公共空间合计 指标，占比 指标 深度 标准。连续性是控制性要求：绿脊全长不断，每处站台广场都是它的放宽，而不是另一个独立物件 空间数据。

四处AI朝圣地标与荣誉展示体系 指标。S4 的零公里碑是本带原点，也是贡献者与智能体名字被镌刻的地方——正是这场开源征集本身承诺的永久记录。S6 的信号所观测台把历史信号构筑读作一个观看评测与标准工作进行中的场所。S5 的开放道岔广场是本带的东西向公共客厅与国际交往面。S1 的到达板以列车到站牌的格式公开展示这条线产出了什么——发布、测试、结果。配合一套共享构件库（站台边、缝合线门槛、里程碑、展示板、信号元件），本带获得的是一套可识别的构件套件，而不是一个英雄式单体。

包容与无障碍是硬约束，不是加分项。 一个可预约的公共空间，只有在「预约永远不会变成谁可以使用这座城市的筛选器」时才是正当的。由此提出四条承诺，每一条都是场景协议的准入条件而非愿景表述。

其一，不设数字前提。本线上任何场景，都必须对没有智能手机、没有账号、没有App的人保持可用。场景若有数字界面，必须在同一地点、同一时段提供实体或有人值守的等效通道。一个拒绝使用AI的居民，不应因此失去任何东西。

其二，无高差连续。主线建议全长为连续无高差路径；六条东西缝合线中的每一条，两端接入都必须无高差，否则不计为一条缝合线。只对健全人成立的连续性不是连续性，只是一部分人的捷径。

其三，预约窗口有界且可撤销。一次预约不得整体封闭任何一处站台广场，不得在同一地点连续占用整日，并须公示到期日，到期后空间归还普通公共使用。居民保有常设异议通道，异议一经提出即暂停该预约并转入人工复核——可撤销性才是这套安排公平的原因，而不是它被公示过。

其四，人人可读。导视为实体、高对比度、多模态（视觉、触觉、听觉），使这条线能够被不读中文的访客、不带手机的老年居民、以及视障或听障者读懂。青年友好与儿童安全在两处道岔广场优先设计：座椅、遮荫与非正式聚集优先于通行效率 深度 指标 空间数据。

文化叙事。 三层文化被编织而非堆叠：百年京张工程遗产、中关村创新文化、AI新文化。串起它们的是同一件事——都关于让一条线运转起来：先是勘测与修建，再是向企业开放，如今是作为计算性公共设施被运营。而把三层真正缝在一起的那根线，就是令牌：司机带着穿过单线区间的那枚铜牌、管住计算机网络访问的令牌、以及AI模型读取的词元，是同一个观念在三个世纪里的三次现身——一个小物件，授予一份有边界的权利，并且必须归还。 一条继承了铁路的城市带，不必只继承它的形状，它可以继承它的纪律。 本包将铁路令牌制度作为广泛记载的公开铁路史用作设计参照；对京张铁路自身信号器具的具体史实，本包不作任何文献性断言——那需要官方档案来源。导视、标识与符号系统一致采用铁路语汇：脊上的里程标、站处的站台边、翼处的道岔标。历史事实按历史呈现，不被转化为装饰；不使用任何未经清权的肖像、商标、字体、图片或论文图像 深度。

首要风险是几何性的，本包选择披露而不是掩盖。 提交边界与重点区均为临时。若官方 polygon 存在实质差异，本包中每一个面积、比例与分区都会改变。缓解是结构性的：设计的承重落在次序与关系上，这些在边界修正后依然成立；且几何由可重跑的分区程序生成而非手绘，因此复算是一次重跑，不是一次重画 空间数据 深度。

专业深化前必须补齐的缺资料：官方红线与三处重点区 polygon；已批控规条件（容积率、高度、密度、退线）；道路红线与断面；现状建筑普查与权属；市政管线、能源、排水与消防条件；文物保护范围与建设控制地带；轨道站位与线位；公共服务设施基线。每一项均在假设清单中记为待专业确认，而不是被假定 来源。

主张边界。 本包中所有空间、活动、品牌与政策建议，均为概念建议、参考方案或可供专业团队深化研究的材料。本包不构成法定规划，不代表政府批准或背书，不确认实施、投资、土地权属、开发时序或审批结论，不给出任何工程可行性判断。

版权与数据。 全部内容由 AI agent 基于本仓库登记的公开与清权资料生成。未使用任何受限图件、未公开表格、企业专有数据或个人数据。未嵌入任何第三方商标、字体、图片、肖像或论文图像。图件由本包自身的 GeoJSON 与 metrics 派生；HTML 页面完全离线，无远程脚本、字体、瓦片、iframe、表单、API 调用或跟踪代码。细则见 report/copyright_statement.md 标准。
