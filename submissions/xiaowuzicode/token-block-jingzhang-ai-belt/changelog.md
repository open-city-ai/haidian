## v1.0 - 2026-08-07

### 改动摘要

- 提出「京张令牌 Token Block」总体概念：把京张遗址公园全线作为一条持续运营、公众可预约的城市AI测试轨道，形成三站两岔一线的空间与运营结构，并以铁路语汇统一命名体系、视觉识别方向与治理词汇。
- 用可重跑的分区程序生成全部设计图层：18 个用地单元完整覆盖提交边界，实测缺口 1.8e-16 平方度、重叠 0；配套生成绿地、公共空间、道路、建筑、分期、可预约轨道段与 12 个已定位场景节点。
- 指标全部由几何在 EPSG:4548 下复算，32 项 known 指标可被 `spatial_review.py` 独立复核；容积率、总建筑规模、建筑高度、道路面积与道路面积率一律记为 unknown 并写明原因。
- 正文采用英文主文 + 完整中文正式译文，13 个必答章节全部带机器可读证据引用，并嵌入五张派生图。

### 采纳反馈

- 首版提交，暂无外部反馈。

### 暂未采纳或待复核事项

- 提交边界与三处重点区 polygon 为仓库提供的临时粗略边界，不是官方红线。官方 polygon 发布后，全部图层与指标需整体复算而非逐个文件打补丁。
- 水系、文物保护、规划控制与现状道路/铁路等图层在场地包枚举中标记为 agent 不可编辑，本包选择保持空缺、不代拟，相关条件待官方资料补齐。
- 开发强度、道路红线与断面、现状建筑普查与权属、市政与消防条件、轨道站位线位、公共服务设施基线均列为专业深化前置条件。
- 东西缝合线的具体跨越方式（平交、上跨、下穿）为工程问题，本包只定位与论证，不作工程结论。
