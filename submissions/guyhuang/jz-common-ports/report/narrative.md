# v0.2 评审导航与自评底稿

本文件不是规划审批文件，也不替代 `proposal.md`、GeoJSON、PDF 或四道机器门禁。它只帮助评审快速核对：v0.2 是否把概念、空间、AI 治理、公共利益和实施证据连成同一套可追踪成果。

## 一句话命题

**京张接口公地 / JZ COMMON PORTS** 把百年铁路遗产转译为一条人人可进入、质询、申诉与退出的 AI 公共接口。核心不是再造一条“科技展示带”，而是建立一份可撤回的公共契约：

`REQUEST → DOCK → SANDBOX → HUMAN REVIEW → PUBLISH / RECALL`

这套语法同时约束一脊三港两翼十二接口、十二张场景卡、六态护照、三项 90 日试点、十个实施包、品牌 `{JZ}` 与版本变更记录。

## 不得被分数掩盖的限制

1. `SITE-001` 与三个重点区均为主办方许可的临时粗略几何，不是法定红线或地块坐标。
2. 15 个建筑面是可逆“程序载体包络”，不是现状测绘、拆改留或建筑审批结论。
3. FAR、总建面、高度、道路红线、停车、市政/能源/算力/消防容量、文保范围、正式预算/报价、保险限额与真实实施主体均为待确认；XS/S/M 数值只是参与者低置信规划包络。
4. 15 项离线任务及 15 项反事实只证明治理策略对显式合成输入的可复现响应，不代表现场性能、社会效果、法律合规或模型安全认证。
5. 24 场次现场共测和五项阈值是预登记未来工作；在授权、无障碍场地、人工等价、同意、独立公众席位、保险与保护措施到位并产生真实复核证据前，不得标记为通过。
6. PDF 以可打印视觉表达为主；无障碍等价版本由 Markdown 与离线 HTML 提供，不宣称 PDF 已完成 Tagged PDF 专业认证。
