## 5. 字体、软件与嵌入

最终冻结使用 Python 3.12.13、ReportLab 4.4.9、Pillow 12.2.0、pypdf 6.10.0、Poppler/pdfinfo 26.05.0 与 Node.js v26.7.0。生成链为“结构数据 → 中英正文 → 双语图 → 离线 HTML → A3/A0 PDF → Poppler 全页渲染/文字/字体检查 → manifest 哈希 → self-check”。离线协议 runner 仅使用 Node.js 标准库，schema、脚本与持久化输出一并交付。

PNG 与 PDF 构建使用 macOS 系统安装的 `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`；PDF 只嵌入所用字形的子集，字体文件本身不随投稿分发。本声明不授予该字体的再分发权；任何重新导出者须在自己的运行环境中核对许可或使用有适当许可的替代字体。浏览器页面使用系统字体栈，保持离线和跨平台后备。
