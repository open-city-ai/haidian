# 著作权与生成说明

本投稿的中文正文、英文标题与传播文本、九类 GeoJSON、JSON 矩阵、ALS Stack 机器可读架构、Life Letter JSON Schema 与合成示例、五张核心图、A3 文册、A0 展板和离线 HTML 均由 GitHub 用户 `seanSaxcy3` 以“共生之城 UrbanSymbiosis”名义，在 OpenAI Codex 辅助下针对本次开源征集原创生成。空间图形仅以仓库清权的 provisional boundary 为临时约束；案例页只进行事实性文字概括和机制转译，不复制外部照片、地图、界面、Logo、论文图、模型权重、训练数据、设备图纸或受保护素材。

本方案未使用外部视觉生成 skill，也未引入外部生成图像资产。核心图件、HTML、A3 文册与 A0 展板均由原创构建代码以本投稿自身的 GeoJSON、metrics、JSON 矩阵、文本和设计图层为输入在本地派生；临时构建脚本不进入提交目录。英文文本、图件、HTML 和 PDF 语言副本均为同一原创中文源文本与同一组本地结构化数据的翻译或排版派生，不改变方案主张、指标、证据引用或空间图层。

外部案例、官方公告和专业标准的来源、访问日期、用途与禁止用途见 `sources.json`。所有第三方商标仅作为机构名称的文字识别，不构成合作、背书或授权暗示。

`visual/assets/example-water-letter.json` 明确为协议演示用合成记录，不含本地水质观测、个人信息或敏感物种位置，也不能支持污染、达标、生态成效或运营结论。`visual/assets/als-stack.json` 与 `visual/assets/life-letter.schema.json` 是概念性开放接口说明，不代表系统已经部署、模型已经训练或通过性能测试。

许可字段 `COMMUNITY-DISPLAY-ONLY` 服从本仓库征集与展示规则。方案为开放共创建议，不替代正式规划，不构成政府审定、采购、投资、实施或工程可行性结论，也不得被解读为主办方、海淀区政府或任何其他政府部门对作者、品牌、技术路线或方案的官方背书。
