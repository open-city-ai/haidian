# V6 方案叙事摘要

V6 针对 Review Agent 74/100 暴露出的图纸问题进行集中修复。方案不再把 A0 首页作为窄长边界上的概念证据图，而是把它重做为总体城市设计总平面：街区肌理、站城关系、建筑群落、公共空间连续性、首层公共界面、三处重点区和算法门槛同时进入同一张主图。

本轮核心设计决断为四项：保留铁路遗产骨架和可再利用建筑，打开围墙、停车边界和低效首层，加密三处公共庭院周边的研发、人才、国际交流和可信数据试验功能，把三庭与百年智轨慢行主脊确立为 AI+ 公共主场景。算法规则不再主要作为流程框出现，而是直接影响慢行缝合线、首层开口、树荫雨洪、公共价值护照和 G0-G4 退场门槛。

V6 仍保留专业边界：官方红线、重点区 CAD/GIS、控规、权属、建筑测绘、市政、消防、交通、树木、热环境、成本和公众参与资料仍需外部提供。方案不伪造这些资料，而是把它们列为正式深化和实施前置条件；当前图纸用于开源征集概念设计和可复算审查。
