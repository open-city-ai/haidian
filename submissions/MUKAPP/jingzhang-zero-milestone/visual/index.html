核心概念

双重原点命名（铁路 0 公里 + 程序员 0 索引）贯穿全部空间组织。

命名与双关

京张铁路 0 公里起点在北京北站（原西直门站）——中国人自主修建的第一条干线铁路的“第 0 公里”；程序员从 0 索引数组，AI 建立在 0 和 1 之上。主名称“零号里程碑 / ZERO MILESTONE (ZM)”，副题“京张AI原点带”。

零索引轴

创新带组织为一条零索引轴：从南端 Km 0.0 到北端 Km 6.0，每个节点用“铁路公里标 + 计算机索引号”双重编号，形成一轴七节点、三带两翼的空间结构。

三区两翼

三个重点区对应接口段 / 原点段 / 加速段（大钟寺 / 五道口 / 众智园）；两翼为零成本要素翼（中关村科技服务）与零门槛场景翼（小月河场景赋能）。

五段创新生态

策源（0）—验证—开源—体验—治理，与三区两翼一一对应；每个节点带状态：0=待启动、1=运行中、-1=已回退。

可寻址城市

城市公共空间组织成可寻址的数据结构——节点有 Km 索引、状态、责任主体与生命周期；规划成果从静态图册变为可复算数据包（GeoJSON → metrics → 三矩阵 → 可读文本）。

零时 Zero Hour

年度活动品牌：零点发布（元旦零点全球成果发布）、春之开源共创周、夏之受控测试季、秋之成果发布周、冬之治理评议周。

更新判定机制

“限期试点—年度评估—扩大或回退”：绿灯服务稳定开放；黄灯试点明确期限、测评与人工复核；红灯试点到期评估、整改或退役，设备可拆除、数据可回滚。

三层范围

三层范围共用同一套“零索引”语言，把从产业战略到街区设计的传导变成一条可寻址、可编号、可追溯的轴线。
