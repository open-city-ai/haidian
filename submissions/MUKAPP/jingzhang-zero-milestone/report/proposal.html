零号里程碑：京张AI原点带城市设计

ZERO MILESTONE · Jing-Zhang AI Origin Belt。京张铁路的 0 公里起点在北京北站（原西直门站）——这是中国人自主修建的第一条干线铁路的"第 0 公里"；程序员的世界从 0 开始计数，AI 建立在 0 和 1 之上。本方案把创新带组织成一条零索引轴（Zero-Indexed Axis）：从南端 Km 0.0 到北端 Km 6.0，每个节点用"铁路公里标 + 计算机索引号"双重编号，让百年铁路的里程碑语言成为 AI 时代的公共寻址语言，让每一次创新都从"0 公里"重新出发。

本方案的全部空间、活动、政策、招商、投资与分期均为开放共创概念建议、参考方案或可供专业团队深化研究的材料，不替代正式规划，不构成政府审定结论，不代表任何地块拆改留、道路红线或工程实施结论 来源。方案在官方 SITE_BOUNDARY 与三处 KEY_AREA 精确 polygon 尚未取得时，使用仓库维护者登记的临时粗略边界生成；所有几何均为 official_boundary=false、geometry_role=provisional_constraint，只能用于生成、展示、讨论与包内自检 来源 来源。official polygons 发布后，须依次替换 site boundary、key areas，重做 land use、buildings、roads、green/public space、phasing、metrics、五图、HTML 与 PDF。

执行摘要（七行） 1. 核心命题：京张铁路 0 公里与程序员 zero-indexing 是同一件事——每次技术革命都从 0 重新计数；创新带因此成为一条零索引轴。 2. 空间响应：一轴七节点三区两翼；三处重点区分别成为接口段（大钟寺）、原点段（五道口）、加速段（众智园）。 3. 文化锚点：Km 0.0 起点门、Km 3.0 AI 原点石、Km 4.0 清华园第一站台、智能体里程碑林，与征集方"Milestone 碑刻"纪念体系直接呼应。 4. 实施起点：近期先做 Km 3-4 原点-清华园核心段与零索引导视系统，再向南北扩展。 5. 公共价值：零门槛体验（无 App 也可用）、无 AI 等价路径保底、每个节点可申诉可回退。 6. 证据状态：全部几何为 provisional；空间指标可由包内几何用 EPSG:4548 复算到同一位。 7. 决策边界：所有空间与运营建议均为概念建议，不构成法定规划与政府审定结论。

命名、Logo 与三区两翼回路

主名称为"零号里程碑"，英文为 ZERO MILESTONE（简称 ZM），副题"京张AI原点带 / Jing-Zhang AI Origin Belt"。命名逻辑取自双重原点：京张铁路的 0 公里起点在北京北站（原西直门站），是中国自主铁路的"第 0 公里"；而程序员从 0 开始索引数组，AI 的一切都建立在 0 和 1 之上。把创新带组织为"从 0 编号的节点序列"，等于把百年铁路的里程碑语言与计算机的零索引语言合并成同一套公共寻址系统——每个节点都有 Km 编号，每个公共空间都有索引地址 来源 标准。

命名体系下设四类要素：

  • Km 节点（索引站）：Km 0.0 起点门 → Km 1.0 大钟寺接口站 → Km 2.0 知春路要素站 → Km 3.0 五道口原点站 → Km 4.0 清华园第一站台 → Km 5.0 众智园加速站 → Km 6.0 北门站；编号即地址，导视即索引。
  • 两翼（支线）：中关村科技服务翼 = "零成本要素翼"（资本、知识产权、算力、数据、合规接口）；小月河场景赋能翼 = "零门槛场景翼"（场景沙盒、公共体验、生活服务）。
  • 里程碑（地标）：0 号里程碑、AI 原点石、清华园第一站台、智能体里程碑林，构成可逐年增长的"碑刻系"。
  • 零时刻（活动）：年度"零点时刻·全球 AI 发布周"等运营品牌。

Logo 方向取"一枚立在轨枕上的 0|1 里程碑"：碑身正面是铁路 0 公里刻度，背面是二进制 0 与 1，底座两条轨枕线象征京张铁路与中国自主创新的历史轨距；零既代表铁路起点的 0 公里，也代表 AI 的 0/1 与程序员的零索引。VI 主色为京张铁灰（遗产）、海淀蓝（创新）与信号橙（面向未来的警示与活力），提供高对比、触觉与中英图文并置版本；不使用企业商标、人物、铁路现成标志或未经授权字体 标准。

三大定位被转译为三条带：百年京张文化带 = 零号时间轴（从 1905 年的 0 公里起算的遗产叙事）；都市AI生活体验带 = 零门槛体验带（无 App、无账号、无 AI 等价路径保底）；AI 融合创新带 = 从 0 到 1 创新带（idea 0 → product 1 的创业隐喻）。五大功能分别落在：众智园的全栈自主与治理验证（加速段主场）、AI 原点的世界级创新生态与开源体系（原点段主场）、大钟寺与小月河方向的 AI+ 场景与智能原生消费（接口段与场景翼）、整条零索引轴的智能化 AI 活力城市、中关村科技服务翼的要素全球化配置。三区不是三个孤岛：公共问题向北进入研发验证，失败与改进意见向南回到城市生活，两翼提供要素与场景，构成闭环 来源。

区域创新协同：原点接力

任务书要求体现与北纬社区、未来科学城、怀柔科学城、经开区及京津冀的创新协同 来源。本方案把协同组织为一条原点接力（概念建议）：未来科学城与怀柔科学城承担基础研究与源头创新，是接力链的"策源端"；一带之内，众智园完成全栈验证（加速端）、AI 原点完成开源转化（原点端）、大钟寺完成体验与消费放大（接口端）；经开区与京津冀城市群承接制造化与规模化落地，是"放大端"；北纬社区作为带上的生活配套与人才中转节点。接力的规则沿用零索引语言：成果在下游节点"从 0 重新计数"前，必须在上游节点完成验证与清权；失败的试点就地回滚，不向下游转嫁风险。区域协同只表达机制方向，不构成任何跨区投资、政策或实施承诺。

规划方法创新：可寻址城市

任务书规划创新性维度要求对综合规划内涵、空间产业融合、国土空间规划创新提出有价值思路 来源。本方案的回答是：把城市公共空间组织成可寻址的数据结构——每个节点有 Km 索引、有状态（0=待启动，1=运行中，-1=已回退）、有责任主体、有生命周期。规划成果从静态图册变为可复算数据包（GeoJSON → metrics → 三矩阵 → 可读文本），任何数字都能回到几何、公式与假设；设计结论（概念层）与法定控制（控规层）始终分栏，法定指标缺依据就保持 unknown，官方数据到位即触发整包重算。这不是数字孪生式的实时镜像，而是可复算、可审计的规划方法 深度。

三处重点区以三座节点站组织，共用"五问门槛"：每个 AI 场景进入前都要回答"为谁服务、使用什么数据、谁来复核、失败如何退出、公共收益如何留下" 深度。三处临时 polygon 的包内复算面积分别约 192.9 万㎡（众智园）、104.3 万㎡（AI 原点）与 72.0 万㎡（大钟寺），合计 指标，与公告公开的约 192.1 / 104.3 / 72.0 公顷接近，说明临时位置的量级合理；official polygon 到位后以官方边界重算 空间数据 至 空间数据。

5.1 众智园加速站｜Km 5.0｜AI 全栈自主验证区（约 192.9 万㎡）

众智园承担"AI 全栈自主创新体系与 AI 治理全球话语权" 来源。空间结构为"清河界面—加速中轴—科研单元"：清河一侧组织低碳创新廊 空间数据（概念位置），中轴设加速广场 空间数据，两侧为科研用地 空间数据 与商业服务 空间数据。加速门按三级组织：虚拟评测 → 受控实验室 → 真实街区试点；每个试点有期限、有测评、有人工复核、有退出通道，对应"从 0 到 1"的创业隐喻。建筑以 AI 研发与孵化器为主 空间数据，概念基底不表示现实建筑；对外交通、清河界面与跨环路节点需待道路红线和工程条件确认 深度。实施风险主要是 official polygon、控规指标与清河蓝线未到位 深度。

5.2 AI 原点站｜Km 3.0｜近校开源社区（约 104.3 万㎡）

5.3 大钟寺接口站｜Km 1.0｜智能原生体验区（约 72.0 万㎡）

大钟寺承担"智能原生新业态"与城市入口、国际交往 来源。空间结构为"站前四象限—文化体验片—商业服务环"：接口广场 空间数据 设多语导览、AI 权利说明与人工服务；文化用地 空间数据 组织智能原生内容与数字资产展示，商业用地 空间数据 承载消费与商务，站前绿带复合规划绿地与公共活动。轨道接驳只提出四象限步行连续、非机动车有序停放和清楚换乘的方向性策略，待道路红线、客流、出入口和市政资料核验。所有体验场景均以"可选择、可退出"为底线：不使用 AI 仍可获得基本服务，高影响判断回到人工。
