# 京张协议 V0.5 简明叙事 / Jing-Zhang Protocol V0.5 Brief Narrative

## 中文

“京张协议”把百年京张 AI 创新带理解为一套可见、可测试、可申诉、可回滚、可持续更新的城市公共协议，而不只是 AI 产品和展示空间的集合。BUILD → TEST → LIVE → LEARN/UPDATE 构成能力进入城市社会的责任回路，AI City API 与京张 AI 城市公约把身份来源、数据目的、能力边界、人工复核、非 AI 备选、申诉补救、互操作及退出机制写入公共界面。

空间上，三个生命周期段与知识研发、公共绿脊、公民接口、日常服务四类界面带交叉，形成 12 个可复算概念单元；三处重点区域分别承担能力生产、受控社会测试和日常服务验证。12 个场景节点、3 个产业验证场景、7 类协议接口和 3 个公共地标均与空间载体、用户角色、实施依赖及人工复核机制建立对应关系。

V0.5 是本地 `ready_for_review` 正式包，包含双语方案、离线 HTML、五组双语分析图、中英文 A3 文册与 A0 展板，以及完整来源、假设、指标、空间图层和审计矩阵。空间证据仍采用明确标注的临时粗略边界，法定开发强度、道路、权属、市政和文保条件继续保持待正式资料补齐；本成果不是官方红线、审批结论、工程承诺或已部署系统，也尚未推送或创建正式 PR。

## English

The Jing-Zhang Protocol treats the Centennial Jing-Zhang AI Innovation Belt as a visible, testable, contestable, reversible and continuously updated civic protocol rather than a collection of AI products and showcase spaces. BUILD → TEST → LIVE → LEARN/UPDATE forms an accountability loop for capabilities entering urban society. The AI City API and the Jing-Zhang AI Civic Protocol make provenance, data purpose, capability limits, human review, non-AI fallback, appeal, interoperability and retirement legible at public interfaces.

Spatially, three lifecycle segments cross four interface bands - knowledge and R&D, public green spine, civic interface and everyday service - to create twelve reproducible concept cells. The three key areas respectively support capability production, bounded social testing and everyday-service validation. Twelve scenario nodes, three industry-validation scenarios, seven protocol interfaces and three civic landmarks are each linked to a spatial carrier, user roles, implementation dependencies and human-review safeguards.

V0.5 is a local `ready_for_review` formal package containing paired Chinese-English proposals, offline HTML, five bilingual analytical-figure pairs, Chinese-English A3 booklets and A0 boards, and complete sources, assumptions, metrics, spatial layers and audit matrices. The spatial evidence still uses clearly labelled provisional rough boundaries; statutory development controls, roads, ownership, utilities and heritage conditions remain pending official inputs. This is not an official redline, approval, engineering commitment or deployed system, and it has not been pushed or opened as a formal PR.
