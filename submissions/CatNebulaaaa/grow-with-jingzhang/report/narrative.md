# 视觉哲学：共长测绘 / Measured Commons

“共长测绘”将城市理解为由不同世代持续使用、维护和更新的公共空间系统。图面通过轨迹、树冠、雨水、停留活动和建筑阴影表达空间关系，以分析图层和生活场景相互校核。线型、视角和留白均服务于信息层级，确保总体结构清晰、局部关系可读、证据来源可查。

形式语言提取京张铁路双轨和城市年轮两组要素。双轨建立方向、尺度和时间连续性；年轮转化为遮阴环、雨水花园、围合座椅及年度公共贡献标记。两类要素贯穿总体结构、三维构造和版面节奏，在延续场地历史线索的同时，形成统一、可识别的空间系统。

色彩体系由铁路墨蓝、纸张白、叶绿、雨水青和公共橙构成。墨蓝用于结构、边界和证据层，叶绿与雨水青表达生态过程，公共橙标记人工服务、公众反馈和应急接管节点。材料优先选用再生砖、浅色木构、穿孔金属、透水铺装和具有触感的耐久表面，并通过统一的光照和尺度控制保持图面一致性。

构图采用“总体结构—空间关系—实施重点”三级阅读层次。总体图突出京张创新发展轴和三处重点片区；鸟瞰图呈现蓝绿系统、建筑和移动网络的协同关系；人物视角以轮椅使用者、儿童家庭、学生、维护人员和长者作为空间尺度基准。文字集中标注方向、数值、空间关系和建设任务，其余信息通过光影、密度、路径和人物活动表达。

视觉成果按数据性质分层标注：工作范围采用低对比虚线，OSM 与气候数据作为背景分析，生成式人物场景标注为设计意向，Blender 体量标注为概念模型。版面通过线型、颜色和注释区分规划依据、现状分析、设计方案及实施衔接要求，形成层次清晰、依据明确的城市设计表达。
