## 文化叙事基调：起点与远方

京张铁路当年从北京城出发，往西北方向的崇山峻岭而去，是那个年代"走向远方"最具体的物理路径——起点在青龙桥，终点望向张家口乃至更远的塞外。今天这条铁路遗址所在的走廊，恰好又是清华、北大、中科院环绕，AI人才和创新最密集的地带。"起点"这个词现在有了双重含义：

- **历史起点**：中国人自主修建铁路的起点（詹天佑与青龙桥站，"人"字形铁路的工程智慧诞生地）
- **未来起点**：中国AI原生城市实践的起点（"北京AI原点社区"这个名字本身就在呼应"起点"）

"远方"不是模糊的浪漫化词汇，而是具体的坐标——铁路当年通向的是国家边疆和更广阔的经济腹地；今天AI创新带要通向的"远方"，理解为AI技术从园区走向真实城市治理、从北京走向全国乃至全球的辐射路径。

情感基调是面向未来的、进取的、开放的，而非怀旧或纪念碑式的沉重感。

## agent.1 命名与Logo

### 正式名称：新轨启程

英文对应：New Tracks, New Journey / Departure on New Rails

"新轨启程"四字里，"新""轨""启""程"各司其职——"轨"承载铁路基因，"新"点出创新属性，"启程"是最自然顺口的动作意象，直接呼应"起点与远方"的母题。

### Logo 视觉概念

以单一起点（对应"北京北站"，走廊的历史起点节点）为核心，向外发射若干条渐变连接线，这些线本身沿真实地理路径延展、转折，共同勾勒出走廊的轮廓——线条兼具"铁轨"与"数据流/神经网络"的双重意象。

基于四个真实坐标点（北京北站→大钟寺→清华园站→五道口）的等距投影换算，走廊呈现出明显的转折走向：从北京北站往西北拐向大钟寺，再几乎正北直上清华园站，然后往东北拐向五道口——这个"之字形"转折与詹天佑"人"字形铁路的工程智慧形成视觉呼应。

**注**：正式提交前需替换为仓库 `data/source_registry.json` 提供的官方地块边界GIS数据，当前版本为四个地标点连线的估算路径。

## agent.2 生态案例（中关村主线，共6项）

1. **中关村AI大模型企业总部集群外延**：总部留在中关村核心区，沿走廊设面向公众的AI体验中心/发布厅，让企业内部技术首次面向市民开放。

2. **政策沙盒2.0**：把中关村已验证成熟的科技政策，结合AI治理这一新命题，在走廊做二次试验，如AI企业注册绿色通道、数据跨境流动试点。

3. **孵化器毕业生承接带**：为中关村孵化器（车库咖啡系、清华科技园等）"毕业"后被迫外迁的团队，提供走廊沿线较低成本的承接空间。

4. **公共算力中枢**：由中关村科学城管委会牵头，在走廊节点（如清华园站）落地面向中小AI团队的公共算力/公共数据集平台。

5. **AI从业者社区化居住空间**：走廊沿线居住空间改造为"AI从业者社区"，嵌入技术交流、内推信息共享等定制化服务。

6. **中关村会展成果常设展示窗口**：把中关村论坛等发布的重点成果，以常设展陈形式留在走廊沿线，形成创新成果的常年展示窗口。

## agent.4 朝圣地标（共3处）

### 1. 起点纪念柱（北京北站段）
呼应Logo里发射起点的"点"，柱身刻有"新轨启程"名称及京张铁路历史铭文。游客可在此"打卡出发"，扫码获取数字"启程证"，串联后续地标形成集章式体验路径。

### 2. 人字轨迹广场（大钟寺/清华园段）
用真实的"人"字形铁路工程原理（詹天佑八达岭段折返线设计）做可供人行走体验的地面装置，用不同材质地面铺装还原折返轨迹的比例缩小版，让游客亲身感受当年"折返爬坡"的路径逻辑。

### 3. 远方之窗（五道口段，走廊末端）
朝向西北方向（真实指向青龙桥/张家口方向）的镜面或框景构筑物，游客可透过特定角度"看向"京张铁路历史上真正通向的远方，作为整条走廊体验的收束仪式点。

## agent.6 长期运营机制

### 治理结构：管委会主导
中关村科学城管委会牵头设立**"新轨启程·编组站"**，作为常设运营机构，统筹沿线空间调度、算力配额分配、展陈内容审核。

### 企业联盟型
沿线入驻的AI企业（涵盖独角兽到一人公司）组成联盟，按实际使用的空间/算力资源分摊运营成本，换取编组站内的资源调用权和公共展示窗口曝光。

### 年度迭代机制
结合中关村论坛，每年更新一次常设展陈内容和企业名录，保持内容不固化，适应AI产业极快的迭代速度。
