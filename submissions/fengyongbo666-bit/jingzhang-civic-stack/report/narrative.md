# 京张城市开源栈｜成果摘要

“京张城市开源栈 / JINGZHANG CIVIC STACK”以百年铁路记忆为公共坐标，把约 11.4 平方公里总体设计层组织为一条公共脊柱、三个城市栈、两翼混合织补和十二个 AI 场景端口。北部“模型年轮”验证模型与具身智能安全，中部“第一提交站”连接科研成果与社区，南部“智能体议场”连接智能体经济与公共协商。

方案的核心创新不是增加设备，而是把城市写成开放协议：最少数据、高风险转人工、无设备同权、明确申诉、阈值暂停、可验证退出。六类人才画像进入设计审查，三处贡献者地标与年度 City Merge 运营形成长期文化；十二项更新工作均绑定责任、成本等级、进入闸门和停止条件。

当前公开资料缺少官方精确边界、法定控规、现状建筑、权属、交通、文保和市政底表。所有临时几何均显式标注 provisional，容积率、高度、拆除量等保持 unknown；官方数据到位将触发九个图层、全部指标、五张图、HTML 和两套 PDF 的全包复算。自检通过只说明提交包内一致、可复算、可审阅，不等于审批或可直接建设。
