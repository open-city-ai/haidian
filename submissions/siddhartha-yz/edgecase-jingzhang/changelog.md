## v1.5 - 2026-08-12

### 改动摘要

- 将中英文离线场景筛选器的十二条“人工退路 / 停止条件”从 JavaScript 位置数组迁入各自 `EDGE-01`—`EDGE-12` 场景卡的静态 HTML。
- 禁用 JavaScript 时仍可阅读完整安全契约；后续重排场景卡时，退路内容也不再依赖数组下标而可能错配。

- 静态解析可在两个 HTML 中分别找到 12 个场景、12 个 `<details>` 和 12 条退路，且不再存在 `fallbacks` 位置数组。
