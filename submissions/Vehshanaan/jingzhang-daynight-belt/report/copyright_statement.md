## Generated-asset pipeline / 生成管线与依赖

- No external fonts, icons, images, maps, tiles, scripts, or APIs are required. 图件与文档未使用任何外部字体、图标、图片、地图瓦片、脚本或 API。
- Figures are rendered programmatically with Matplotlib using system fonts; PDFs are rendered with ReportLab using the built-in STSong-Light CID font; HTML pages are fully offline static files. 图件由 Matplotlib 程序化绘制（系统字体）；PDF 由 ReportLab 内嵌 STSong-Light 生成；HTML 均为完全离线的静态文件。
- Spatial data is produced by deterministic Shapely/Pyproj geometry scripts in EPSG:4548; metrics are recomputed from the package's own GeoJSON. 空间数据由确定性 Shapely/Pyproj 脚本在 EPSG:4548 下生成；指标由包内 GeoJSON 复算。
