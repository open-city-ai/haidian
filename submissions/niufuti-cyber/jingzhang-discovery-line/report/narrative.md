# 运行证据索引｜Runtime Evidence Index

## 阅读边界｜Reading boundary

本文同时登记包内入口与留档源指纹。三态记录、负向检查、M01 模型轮和整线降级已有最小脱敏副本随包；其余来源只在项目档案中保留指纹，仅持有正式包的读者不能独立打开或复核。所有记录只证明桌面合成推演、机制检查或文本生成调用，不证明真实复测、现场运行、批准、授权或实施。

This document registers both package entries and archived-source fingerprints. Minimal redacted copies of the three-state record, negative checks, M01 model round, and whole-line downgrade are included in the package. The remaining sources are represented only by fingerprints retained in the project archive and cannot be opened or independently verified by a package-only reader. All records establish only desktop synthetic replay, mechanism checks, or text-generation calls—not real retesting, field operation, approval, authorization, or implementation.

## 来源可用性｜Source availability

`availability` 只使用四个值：`bundled` 表示来源或可复核副本随包可开；`external_public` 表示来源发布在公开地址，但未嵌入本包，离线包不保证实时连通；`workspace_only` 表示证据只在项目档案留存，仅持包读者不能独立复核；`unavailable` 表示当前没有可供复核的包内副本、公开入口或项目档案入口。

`availability` uses only four values: `bundled` means the source or a reviewable copy opens from the package; `external_public` means the source is published at a public address but is not embedded, so the offline package does not guarantee live reachability; `workspace_only` means evidence is retained only in the project archive and cannot be independently checked by a package-only reader; `unavailable` means no reviewable package copy, public entry, or project-archive entry is currently available.


“十卡全体 / all ten cards”指 `G01 / W01 / R01 / R02 / M01 / H01 / H02 / E01 / C01 / C02`。
