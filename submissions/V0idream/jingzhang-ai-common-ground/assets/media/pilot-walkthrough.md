# TG-PILOT-01 静音体验 / Silent Walkthrough

## 用途 / Purpose

这段 18 秒静音动画解释 72 平方米可撤离校译单元怎样从普通服务、隔离校译、影子平行、公众校样走到采纳、重译或退场。它是 V3 的原创概念故事板，不是现状录像、建筑漫游、公众参与记录、运营绩效或实施承诺。

This 18-second silent animation explains how the 72 sqm removable proofing bay moves from ordinary service through isolated proofing, shadow service, and public proofing to adoption, retranslation, or retirement. It is an original V3 concept storyboard—not site footage, an architectural walkthrough, public-participation evidence, operating performance, or an implementation promise.

## 完整字幕 / Full transcript

1. S0 普通服务基线 / Ordinary-service baseline: AI 关闭，纸质、人工、无障碍路径先运行。
2. S1 隔离校译 / Isolated proofing: 只使用公开或合成问题，输出不面向公众。
3. S2 影子平行 / Shadow parallel service: AI 建议只给人工复核，普通窗口仍是主通道。
4. S3 公众校样 / Public proof: 六门全部通过后才向公众展示，并提供八项城市校样回执。
5. 人工接管与申诉 / Human handoff and appeal: 120 秒是未实测概念目标，未达标即返回重译。
6. S4 采纳、重译或退场 / Adopt, retranslate, or retire: 只允许限量采纳、返回重译或拆除 AI 层。
