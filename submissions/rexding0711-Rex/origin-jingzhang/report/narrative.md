# 原点京张 · 方案叙事摘要

## 一句话

一百年前，詹天佑用「人字形」折返线让中国人自主设计的第一条干线铁路翻越了八达岭；一百年后，原点京张用「一公里创新服务圈」让全球 AI 创业者翻越从实验室到市场的最后一公里。

## 核心概念

**原点京张 Origin-JZ**：京张铁路是中国工程自主的原点，AI 原点社区是中国智能时代的原点，一带是原点的集合——一条铁路遗址上生长出的 AI 创新服务带。命名体系呼应 git origin、坐标原点 (0,0) 的 AI 开发文化。

**一公里创新服务圈**：沿京张遗址公园组织创新服务前台网络，任何 AI 团队步行一公里内触达「政策/场景/数据/合规/投融资/活动」六位一体服务，覆盖从基础研究、产业孵化到资本服务的全链路。

**Meta-Agent 可编程城市范式**：城市空间从「静态 PDF」演化为「可计算、可迭代的代码库」。Origin Node 动态生长算法（S_node = α·D_dev + β·P_compute + γ·F_git）根据开发者密度、算力负荷与开源活跃度动态配置服务节点等级。

## 空间结构（v2）

- 46 个概念地块全覆盖无缝隙，全部绑定海淀生态锚点（智源研究院/海淀数据特区/北京人工智能公共算力平台/清华北大）
- 119 栋建筑体量程序化生成（塔楼 24/板楼 49/院落 46）
- 6 个三级全功能前台 + 14 个二级社区协同站 + 一级微节点
- 三锚点 1km 步行圈直接覆盖约 56%，其余由节点网络补充
