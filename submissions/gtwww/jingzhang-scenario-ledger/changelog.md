回应 PR #4368 的 AI Agent 评审（`request-changes`，七维加权 70.0/100）。逐条对应其「必须完成的下一步」六项。

### 1. 修复 HTML 方框缺字（评审：表达完整度 2/5，阻断项）

**根因**：`report/proposal.html`、`visual/index.html` 及英文对应页的字体栈全部是 `PingFang SC` / `Microsoft YaHei` / `Hiragino Sans GB` 等 macOS/Windows 专有字体，在不含 CJK 字体的环境中全部回退失败，中文渲染为方框。在 macOS 上开发无法暴露该问题。

**修复**：随包内嵌 Noto Sans SC（SIL OFL 1.1，允许嵌入与再分发）子集为 base64 WOFF2，覆盖四个页面实际使用的全部字符；同时保留完整的系统字体回退栈作为双保险。因 CSP 禁止外部字体，采用内嵌而非外链。

- 子集体积 122.3 KB（源 1.1 MB），四页各嵌一份
- 逐页校验：`visual/index.html` 339 字、`report/proposal.html` 848 字、两个英文页共 14 字，**缺字均为 0**
- 构建顺序固定为 生成 HTML → 注入字体，避免重新渲染覆盖

### 2. 修复图纸方框、中英混排与标题重叠（评审：表达完整度）

- **英文图残留方框**：`F(size, bold, en=True)` 使用 Arial 渲染中文字符所致。改为中英统一使用 PingFang（含完整拉丁字形），杜绝任何 tofu。
- **中英混排**：五处三元表达式写反，英文版显示 `□□ / How to read`、`□□ / Land use` 等含中文的串。已改为英文版纯英文。
- **标题压住右上品牌区**：新增 `fit_size()`，按实测品牌区宽度自动缩放标题与副标题字号。
- `board()` 签名改为中英副标题分离，消除英文版显示中文副标题的问题。
- 全部 10 张 PNG 与 4 个 PDF 已重新生成。

### 3. 六个全球案例补齐可追溯书目（评审：风险与合规意识 3/5）

六条来源逐项登记进 `sources.json`，含发布者、标题、发布或访问日期、稳定链接、所支持的具体事实、许可说明与限制。媒体报道类标注 `background_only`，机构与政府材料标注 `needs_review`。

**同时修正一处事实表述**：原文写「多伦多 Sidewalk Toronto 垮在数据治理与公众信任」，将伴随争议表述为终止原因。经查证，其公开终止理由是疫情下经济不确定性使 12 英亩项目难以在不牺牲核心内容的前提下实现财务可行（2020-05）；数据采集与监控争议是全程伴随的公共事实，二者不构成本方案可以断言的因果关系。正文已改为分别陈述，并明确说明本方案借用的是「规则应当先于部署公开」这一判断，而非「因数据问题导致失败」这一论断。King's Cross 亦限定为 2019 年该次人脸识别事件，不构成对该开发主体现状的评价。
