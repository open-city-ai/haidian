# Formal Narrative · 京张令牌带 / The Token Line

Derived summary of the structured AI package.

## 概念

以1909年京张铁路单线运营的"路签"制度为原型——列车凭物理路签进入区间，是铁路史上最早的"访问控制＋区间授权"治理原型——转译为AI时代的可信通行秩序：模型调用凭API令牌、数据进入凭沙箱授权、城市智能体动作凭场景级权限。

## 空间结构：一带一网三签两翼

- 一带：京张遗址公园活力带（The Line）
- 一网：蓝绿公共空间网＋智能感知网（The Network）
- 三签：众智园·签发所 / 原点社区·验签台 / 大钟寺·路签场（Issuer / Validator / Market）
- 两翼：中关村科技服务翼（要素）＋小月河场景赋能翼（场景）

## 任务覆盖

agent.1 命名/Logo · agent.2 8个全球案例＋要素机制 · agent.3 12张场景卡（3个测试验证）＋6类画像 · agent.4 三签广场＋5类朝圣地标/荣誉节点 · agent.5 钢轨·中关村·比特三层文化叙事 · agent.6 四季活动＋路签制运营闭环。

## 边界与指标

总体设计范围约11.41 km²（provisional 复算）；绿地率13.9%、公共空间比例2.0%、建筑密度17.5%（均为临时设计模型值，EPSG:4548）；容积率与建筑高度待官方控规条件。官方边界发布后按 assumptions.json 复算路径统一重算。

Geometry, metrics, compliance/standard/depth matrices, drawings, and visual/index.html remain cross-checked deliverables. See self_check.json for the four-gate report.
