# 方案迭代记录

## v0.4 - 2026-08-22

- 将“创新服务与共享配套”的机器可读用地代码由误用的 `05` 修正为项目最新枚举中的 `0904`；明确代码修正不构成法定用地认定或调整建议。
- 增加北京市公开规划事实与 2026-08-22 冻结的 OpenStreetMap 城市背景参照，生成中英文真实城市关系图；背景数据不参与红线、面积、建筑量或绩效计算。
- 为 G05 零号门建立 ALT-A / ALT-B / ALT-C 三方案同任务比选，以五道空间硬门确定性裁决为 1 淘汰、1 退修、1 深化；新增验证脚本和审计结果。
- 深化 ALT-C 单侧外挂门的概念 1:50 平面、剖面、无设备通道、人工视线、急停距离和独立撤场路线；所有尺寸仍是待现场核验的设计输入。
- 增加同人员、同场地、同时段的无 AI 基线，并把首 100 天拆成五个可验收工作包；现场验证记录保持为 0，不把概念结果伪装成踏勘或实施成果。
- 图纸扩展为十五组双语核心图，并同步重建离线评审页、A3 手册、A0 展板、报告与机器可读清单。

## v0.3 - 2026-08-16

- 将智能体任务书显式组织为“三大定位、五大功能、三区两翼、十二门”的总纲；两翼采用中关村科技服务翼和小月河场景赋能翼，并明确均为概念性服务网络。
- 新增原创中英文标志与视觉身份系统，统一门牌、导视、无障碍路径、开放日历、活动品牌、状态符号和荣誉碑刻的视觉语法。
- 把六个全球案例整理为“机制转译 / 不外推内容”比较，并以土地、空间、产业、资金、人才、算力、数据、场景八类资源建立本地生态闭环。
- 深化 G05 零号门、G07 水尺门、G09 开门钟三座代表节点，增加概念平面、剖面、人工接管点与白天—夜间—降雨—活动—故障五态序列。
- 新增原创人本概念场景与离线五态交互，清楚标注其不是现场照片、现状证据、官方效果图或实施承诺；交互不联网、不采集数据，并保留静态后备表达。
- 图纸扩展为十二组双语核心图，A3/A0 版面同步更新；OGP-12 治理核心、暂定边界和未知法定指标披露保持不变。

- 保留暂定边界、未知法定指标与未获审批的明确披露，不把设计协议表述为现实开放、建设承诺或政府背书。
