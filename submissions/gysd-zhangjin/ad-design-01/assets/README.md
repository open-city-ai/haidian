## 使用方法

1. **解压这个模板**到你本地电脑
2. 打开每个文件夹里的 `图片放置说明.md`，看这个文件夹需要放什么图
3. 把你本地已有的图片，按说明里的**文件名**重命名，放进对应的 `images/` 文件夹
4. 没有的图可以先空着，后续用md文档里的AI绘图提示词生成后补进去
5. 填一下根目录的 `图片素材清单.csv`，标记哪些图有了
6. 整个文件夹打包上传

## 图片命名统一规则

- 格式：`序号-主题-内容.png`，例如 `01-纪念碑-日景正面主图.png`
- 有多张同类型的加后缀：`01-纪念碑-日景正面主图-01.png`、`01-纪念碑-日景正面主图-02.png`
- 统一用 **PNG**（带透明底/高质量）或 **JPG**（照片类）
- 分辨率不低于 **2048px**，海报主图建议 300dpi
- 文件名**不要用中文特殊符号**，用中文+数字+短横线即可

## 必传 vs 可选

|类型|是否必传|说明|
| ---- | ---- | ---- |
|proposal.md|✅ 必传|完整总方案|
|10个分类md文档|✅ 必传|各主题详细方案|
|主视觉海报（至少1张）|✅ 建议传|广告设计赛道核心产出|
|纪念碑效果图（至少1张）|✅ 建议传|方案重点亮点|
|京小张IP形象（至少1张）|✅ 建议传|IP是方案核心|
|其他效果图|⭕ 可选|有就传，没有用文字描述+提示词代替|

## 注意事项

- 所有效果图均为**概念示意**，不代表官方施工图、实景照片
- 图片里如果有文字，确保和方案文案一致
- 不要把 brief/、data/ 等公共资料文件夹混进来
- 不要修改其他参赛者的文件
