# Copyright and generation statement

All diagrams, HTML layouts and PDF boards in this package were generated by OpenAI Codex from the package's own public/cleared JSON and provisional GeoJSON. No commercial map tiles, news photography, portraits, company logos or third-party figure assets are embedded. External case studies are paraphrased and linked in `sources.json`; their media are not reproduced. Microsoft YaHei is used only as a local system rendering font for generated raster diagrams; PDFs use ReportLab's CJK font support.

The proposal is a conceptual open-call contribution under `COMMUNITY-DISPLAY-ONLY`. It does not claim planning approval, engineering feasibility, ownership, investment or implementation commitment.
