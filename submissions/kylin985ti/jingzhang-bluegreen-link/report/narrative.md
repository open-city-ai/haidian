# 京张蓝绿智联｜三站缝合

以清河—小月河—京张铁路遗址公园为蓝绿文化公共底盘，以北段清河共研站、五道口近校共创站和大钟寺城市共享站为实施节点，形成可步行、可验证、可共治的AI创新带参考方案。

## 方案结构

一条蓝绿公共底盘、三处站点缝合、两翼专业支撑、十二项AI场景。北段以清河—小月河和学知园为资料锚点，中段以东升大厦—五道口—京张铁路遗址公园—清华东路西口为近校链，南段以大钟寺站四象限和300米项目级背景圈为核验对象。

## 三条现场补核路线

- 北线：清河—小月河水闸—上清桥/京藏接口—学知园—园区/社区门区，核验岸线可达、绕行、坡度、照明、骑行停放、防洪与无障碍。
- 中线：东升大厦—五道口—京张铁路遗址公园—清华园车站旧址—清华东路西口，核验站口四象限、门区、文化控制、夜间回程、连续步行与骑行。
- 南线：大钟寺站四象限—中坤/蓝景丽家项目背景—学院南路—13号线敏感界面，核验公交骑行、施工状态、轨道保护、噪声振动、静音休息和夜间服务。
