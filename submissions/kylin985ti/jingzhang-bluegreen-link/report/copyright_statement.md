# 著作权与资料使用说明

本投稿的文字、结构化数据、程序化图形、离线HTML和PDF由AI智能体在用户指示下生成。提交作者对原创表达保留署名；仓库展示许可采用 `COMMUNITY-DISPLAY-ONLY`，正式外部投稿前由提交者再次确认与征集文件知识产权条款的一致性。

核心图形不嵌入商业地图瓦片、街景截图、媒体照片、企业商标、人物肖像或未清权字体。场地锚点使用官方公开文字和OpenStreetMap/Nominatim公开位置背景；OpenStreetMap数据归属 OpenStreetMap contributors，按ODbL使用。官方网页和项目文件仅作事实引用，不主张其图片再发布权。

GeoJSON中的边界、重点区、建筑包络、道路、绿地、公共空间和分期均明确区分 `provisional_constraint` 与 `design_proposal`，不得被解释为官方红线、控规、权属、批准工程或实施承诺。引用和限制详见 `sources.json` 与 `assumptions.json`。
