# 京张开放接口：从证据到公共端点

以三层范围、连续公共接口和三种差异化端点，把AI创新转译为可复核、可拒绝、可停用、可重算的城市设计与实施框架。

> 概念设计与临时几何；不是法定红线、测绘、施工图或政府承诺。
