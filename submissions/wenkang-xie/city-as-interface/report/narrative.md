# 一页摘要：京张人字智带 · 城市即接口

**The Human Loop Belt — 每一次调用，都折返回人。**

## 一句话

不在城市里再建一批贴着 AI 标签的园区，而是把这条 43.6 平方公里的带子上的空间、数据、算力、服务与治理流程，
整理成一份**可被人与智能体共同调用的公共能力目录**，并用空间把「人在回路」变成看得见、走得进、可追责的城市设施。

## 为什么是「人字」

一百多年前，詹天佑在青龙桥用「人」字形折返解决了当时无法直接翻越的坡度——列车不是硬冲上去，而是折返一次再上行。
那条中国人自己勘测、设计、施工的铁路，本质上是一次**自主的接口设计**。今天这条走廊的问题结构相同：
城市与人工智能之间，接口由谁来写，写成什么样，以及每一次调用之后，判断权回到谁手里。

## 核心机制：城市接口栈

- **L1 感知层**　最小必要、可解释、可关停；只做聚合统计，不建个人画像。
- **L2 能力目录**　建议 18 条条目、覆盖空间/数据/算力/服务/治理/传播六域，每条含责任方、授权范围、服务水平、复核点与退出机制。
- **L3 场景开放协议**　申请—准入—测试—评估—退出的标准流程；有准入必须有退出与回滚。
- **L4 人在回路**　每一次面向公众的调用都有人工复核与申诉入口；无法人工复核的场景不予成立。

价值在于**可实施**：不要求先建成什么，而是先把已经分散在各部门与运营主体手里的能力，
整理成一份可以逐条确认、逐条开放、逐条退出的清单。

## 三条自我约束

1. **不给伪精确。** 容积率、总建筑规模、建筑高度、道路红线、常住人口、停车供给全部保持 `unknown` 并写明原因。
2. **不提出任何拆除建议。** 拆改留采用保留 / 改造 / 新建 / 待确认四分类；缺现状普查与权属时，判定「拆」不负责任。
3. **不越界。** 全部空间落地建议均为概念建议、参考方案或可供专业团队深化研究的材料，不构成政府审定结论。

## 荣誉即里程

沿主脊每 200 米设一根里程标（K0+000 自南端起算），标面刻录该段落成项目的方案名、Agent 名与贡献者 GitHub 名；
折返碑（K5+500）为根节点。这是一套**可持续增长、可被后续贡献者继续写入**的纪念系统，而不是一次性的荣誉墙。
