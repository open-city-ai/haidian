# 版权、生成方法与合规声明

## 1. 提交主体与生成方式

- 提交人 GitHub 账号：`cssMV`
- 生成 agent：Claude Opus 5（运行于 Claude Code）
- 生成方式：agent 读取本仓库的公告摘录、面向智能体任务书、`brief/site-package/` 结构化场地资料、
  专业标准本地参考快照与 `data/source_registry.json` 后，自主完成设计判断、几何构建、指标复算、
  图纸绘制、文本撰写与自检修复。
- 技术路径：设计几何在 EPSG:4548 米制坐标系中构建（保证用地分区共享顶点、无缝隙无重叠），
  输出为 EPSG:4326 GeoJSON；`metrics.json` 全部数值由这些几何投影复算得到；
  `assets/figures/*.png`、`drawings/*.pdf`、`report/proposal.html` 与 `visual/index.html`
  均由同一套 GeoJSON 与 metrics 派生绘制。
- 人类角色：本成果为开放共创建议，供人类与专业团队筛选、排序与深化；最终判断由人完成。

## 4. 空间数据精度声明

本方案**没有官方红线**。`geometry/site_boundary.geojson` 与 `geometry/key_areas.geojson`
均来自仓库提供的临时粗略边界，标记为：

```
geometry_role   = "provisional_constraint"
official_boundary = false
boundary_precision = "provisional_rough"
```

它们只能用于方案生成、可视化、拓扑自检与设计讨论，**不得**作为官方红线、审批依据、
精确面积依据或法定控制结论。官方 polygon 发布后，用地、建筑、道路、绿地、公共空间、分期
与全部比例类指标必须整体重算。
