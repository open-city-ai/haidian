# 版权、来源与生成资产声明

本声明适用于 `jingzhang-ai-export-belt` 提交目录全部资产。

## 原创资产

- 中文与英文方案正文、摘要、命名体系、Slogan、场景卡、人物卡、项目清单与图件文案由 Codex 基于用户清权的 DeepSeek 前置研究重写和编辑。
- “启航线＋城市档案四格印＋三座母港”视觉系统、图形构成、色彩系统、站点符号和公共空间组件方向为本方案原创。
- 五张中英主图、离线 HTML、A3/A0 图册与方便查阅版 PDF 使用本地确定性绘制流程生成；没有调用在线地图瓦片、远程字体、外部图片库或第三方图标库。
- GeoJSON、指标、矩阵和 manifest 以征集仓库官方 scaffold 与校验脚本为结构基础，本方案负责内容重构、字段补充和证据映射。

## 字体

- 中文位图渲染使用 macOS 系统自带 `STHeiti Medium.ttc` 与 `STHeiti Light.ttc`。
- 英文位图渲染使用 macOS 系统自带 Arial 字体。
- PDF 页面以本地渲染的图像形式嵌入，不分发独立字体文件；离线网页使用系统字体栈，不加载远程字体。

## 数据与事实来源

- 官方公告、智能体任务书、site package、专业标准本地快照和 source registry 的出处、用途与限制见 `sources.json`。
- 临时边界来自仓库维护者提供的 `provisional_boundaries.geojson`，只用于生成、可视化和入口自检。
- 海淀产业、三处重点区域、遗址公园和铁路历史事实只作相邻判断依据；不会被扩展为官方红线、审批、招商、投资或工程承诺。
- 国际案例由用户清权的 DeepSeek 前置研究汇总，本方案只迁移可验证机制，不复制第三方图纸、图片、商标、文字表达或空间作品。

## 未使用资产

本提交包不包含外部照片、人物肖像、企业商标、在线地图底图、OSM 瓦片、付费图库、未授权图标、第三方方案图纸、跟踪脚本、远程 API、私密数据和个人轨迹。

## 使用状态

本成果用于百年京张 AI 创新带城市设计开源征集和相关评审展示，许可标记为 `COMMUNITY-DISPLAY-ONLY`。公开、商业、实施或再授权范围须继续遵守仓库、组织方和原始来源条款。方案状态为参赛概念建议，不代表入选、审定或已经实施。
