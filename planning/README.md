## 已锁定的核心主张(2026-08-09)

**Concept C —「第25小时 / The 25th Hour」(时间隐喻)**

青年负担得起的只有城市的「空时」(夜 / 周末 / 换班间隙)。把大钟寺核心区 + 京张铁路脊建成一条**「第25小时」公共脊**:办公熄灯时它亮起,AI 公共服务驿站 7×24,人工复核按时刻表值守,**时刻表的缝隙 = 治理退出条件 / 非 AI 回退**。

- **主锚赛道**:3 青年友好公共空间(蓝海)
- **横跨**:7 AI+公共服务 · 6 城市智能体治理(风味)
- **治理原语**:时刻表协议(Timetable Protocol)——节点 × 时段 → {人工值守 | AI+复核 | 缝隙} → 回退/退出,与基准 `life-letter.schema`「触发/回退/退出」三元同构,且是铁路 DNA 原生语汇(时刻表 = 铁路语)。
- **落点**:大钟寺核心区(`PROV-KEY-003`,南,72ha)= 夜脊主段;铁路脊北节点(AI 原点社区南缘)+ 南节点(西直门外腹地)= 卫星夜脊段。空间动作 = 脊缝再生 + 轻量插入,**不拆建**。
